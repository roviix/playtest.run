playtest
广场控制台安装

一条命令，把你手上这个能玩的版本放到别人面前，
然后知道他们玩成了什么样。

给用 AI 写小东西的人、Game Jam 参赛者、独立开发者、创意编码作者。产物是浏览器里跑的东西，观众是具体的人——朋友、测试者、评委、学生。

playtest ./dist                # 上传导出目录 → https://xxx.playtest.run 和一张二维码
playtest 5173                  # 把正在跑的本地开发服务器接出去，链接长得一样
playtest ./dist --backend 3000 # 静态文件上传，/api 和 WebSocket 穿隧道回你的后端
  • 玩家不注册、不装东西
  • 手机扫码就能玩
  • 不登录也能发，24 小时
  • 不运行你的代码，只分发文件

玩家点开之后

1
先看到一页「某某 邀请你试玩《作品名》· v7」和一个「开始」按钮。这一下点击解锁了浏览器的音频，也是会话的起点。
2
进入作品。.wasm、预压缩的 .br、Godot 4 需要的跨源隔离、断点续传——引擎导出物最容易白屏的地方，边缘替你配好了。
3
你在控制台看到的不是仪表盘，是点名册：几个人打开、几个人进到游戏、停留多久、在什么设备上报了什么错、说了什么。

现在的状态

已经能用：上传、隧道、静态加后端的混合模式、门禁页、点名册、可选的 playtest.js（加一行 <script src="/_playtest/sdk.js"></script> 就有 JS 错误、加载用时、自定义事件和一个反馈按钮）、广场（--public 与 --seek）、版本回滚。

刚接上、还在真机验证：GitHub 登录（playtest login；登录前发的作品会一起归入账号、不再 24 小时后失效）。还没做：自己挑链接名字、口令与邀请名单、自定义域名。做不到的地方命令会明说。

不登录也能用：每次运行拿到的是 24 小时的匿名链接；控制台里粘上 ~/.config/playtest/config.json 里的令牌就能看结果。

安装

一个单文件，macOS（Apple Silicon 与 Intel）、Linux（x86_64 与 arm64）、Windows 各一份，在 GitHub Releases 下载。私测阶段仓库是私有的，链接只有受邀的人打得开；macOS 第一次运行若被拦，在「系统设置 → 隐私与安全性」里放行一次（还没有签名与公证）。

# macOS / Linux：解开、放进 PATH、发一个
tar -xzf playtest-*.tar.gz && sudo mv playtest-*/playtest /usr/local/bin/
cd 你的导出目录 && playtest .
玩家看到的东西全在 *.playtest.run 上；登录、令牌、控制台只在这个域名下。我们从不运行你的代码，只分发文件和转发连接；不记玩家 IP，不收集位置。数据默认保留 90 天。
