# 中国开发者原话：网页作品、Demo、小游戏与试玩反馈

调研日期：2026-09-07

## 结论先行

1. **“把刚做完的东西发给一个具体的人看/玩”是真需求。** 最直接的原话不是“我要发布平台”，而是“怎么把项目打出来一个 html 链接发给别人”“localhost 只能自己看”“体验版没有评委微信号怎么办”。它同时出现在 Cocos 求职作品、Claude Code/Trae 小项目、比赛 Demo 和本地手机预览中。
2. **但在传统国内游戏开发者社区里，“上微信/抖音小游戏并获得流量”比“发一个 Web 链接”更显性、更高频。** Cocos 社区的大量讨论围绕软著、备案、审核、广告和没人玩；纯 Web 分享帖存在，但明显更零散。因此，“具体邀请”适合作为 AI 创作者、Jam、作品集和早期原型的楔子，不能据此声称它比小游戏发行拥有更大的国内市场。
3. **方便简洁是第一位，且竞争对象常常不是另一家托管，而是“算了，不发了”或“录个视频”。** 切浏览器、注册、配域名、等部署足以让人放弃；Cocos 帖里有人直接建议录屏发 B 站。`playtest.run` 若不能显著短于录屏/网盘，就没有成立空间。
4. **大陆可达问题成立，微信“是主渠道”尚未被本轮证据证明。** itch.io 有明确阻断测量；Vercel、GitHub Pages、Cloudflare Pages 有晚间打不开、二十多秒、不同运营商结果相反等原话。微信群、微信扫码、体验二维码反复出现，但没有公开数据证明目标人群的大多数试玩打开来自微信。
5. **“知道结果”有需求，但证据更强的是“没人玩、反馈散、远端加载坏”，不是“我要完整分析平台”。** 最小的打开数、来源、设备、加载完成/失败、JS 错误和一句话反馈有直接价值；漏斗、热图、复杂画像没有找到足够原话支持。
6. **曝光/测试者供给是不能忽略的相邻痛点。** 多位开发者不是缺链接，而是“根本没人玩”“每天十几个人”“日活不过两位数”。这支持保持 M4 边界，但也意味着只交付链接未必能达到 `DESIGN.md` 的 T3；分享卡片、邀请流程、与现有 Jam/社群的衔接可能比建设公开社区更合适。

## 方法、口径与限制

- 共执行 **50 次中文 WebSearch**，覆盖 V2EX、Cocos 中文社区、TRAE 官方中文社区、indienova、机核、B 站、itch.io 支持区、GitHub、知乎及平台官方文档；另有 **15 个候选原页成功直接抓取**。后续 WebFetch 服务连续失败的页面，只在搜索结果已直接显示帖子正文时引用。
- 本文列出 **80 条主题编码记录**。同一段原话可能同时说明两个主题，因此频次是“证据记录数”，不是 80 个独立受访者，也不是用户需求占比。
- 引号内只放本轮工具结果中实际显示的网页原文。省略相邻内容时使用“……”；没有看到日期、点赞、浏览或回复数时明确写“没查到”。
- V2EX 的“回复/浏览”是整个主题的数据，不等于某一楼的互动；Cocos 的赞数按页面显示的主帖或楼层赞数；B 站按页面展示的播放、赞、投币、收藏、分享记录。
- 不登录、不进 QQ/微信群、不注册账号，因此无法读取封闭群聊、即刻和小红书登录后内容。知乎、微信开放社区、Steam 中文群也没有获得足够可核验的目标用户原话；不能把“没搜到”理解为“没有需求”。
- 搜索中出现了大量无作者经历、无可核验来源、措辞高度模板化的 SEO/AI 文章；它们未进入主要结论。平台官方文档只用于核对规则，不冒充用户声音。
- 这是一轮**目的抽样的质性调研**。来源偏技术社区和愿意公开发帖的人；无法代表全部大陆游戏开发者。

**规则核对与冲突：**

- Cocos 同一讨论中，多人纠正“个人不能上微信小游戏”：个人可以上部分类型，但类目、支付和资质受限。这说明**“个人完全不能上”并不准确**。
- 国内服务器上的非经营性个人网站通常可以走 ICP 备案；“ICP备案”不等于“ICP经营许可证”。商业运营、用户内容平台、支付、游戏版号又是更高一层要求。
- 因此 `DESIGN.md` §5 的“不落大陆”仍有充分产品理由，但建议未来文案不要写成“个人网页游戏依法一律不能上线”，而应精确说明：境内节点会引入主体、备案、内容责任与平台化运营义务，和产品的匿名临时发布模型冲突。

## 意外发现

1. **视频是最危险的替代品。** 对求职作品、比赛 Demo 和早期展示，开发者会直接录屏发 B 站/抖音。视频牺牲交互，却绕开服务器、网络、浏览器兼容和评委操作失败。产品文案不能只比较 Vercel/ngrok，还要回答“为什么不录视频”。
2. **AI 工具正在吞掉通用发布。** TRAE 已有产物分享，Vercel 与编辑器联动，社区又出现 MyVibe、VibeShare。`playtest.run` 不能把“上传静态目录拿链接”当长期差异；游戏响应头、大陆路径、同一链接上传/隧道切换、版本与结果才有防守空间。
3. **分享链接本身也需要版本语义。** TRAE 用户抱怨链接失效、只保留首次快照、修改后不更新。这直接支持 `DESIGN.md` 的不可变版本 + 稳定 slug，但也提示门禁页必须清楚告诉玩家当前版本，不能让“同一链接”变成缓存不一致。
4. **“没人玩”比“不会分析”更靠前。** 许多开发者已经上架三个平台，仍只有十几人或零人。如果 T3 不达标，原因未必是发布摩擦，也可能是没有测试者。曝光生态是相邻需求，但不等于现在就做发现页。
5. **小游戏个人主体并非完全不能上。** 微信、抖音都存在个人路径，只是支付、类目、软著、备案和审核受限。把对手描述成“必须公司、完全做不了”会失真。
6. **Jam 的 Web 默认性低于直觉。** BOOOM 要求下载包，WebGL 是可选；CiGA 用 GmHub 统一作品页，但创作者仍传播下载链接。`DESIGN.md` 所说“引擎导出的静态目录占多数场景”在国内 Jam 上尚未被本轮数据证明。
7. **GitHub 登录会直接威胁首次 60 秒目标。** 对技术用户，GitHub 是自然账号；对大陆网络和 AI 新手，OAuth 卡住就会中断流程。匿名 24 小时链接不是锦上添花，而是对该风险的关键兜底。
8. **微信既是渠道也是故障环境。** 原话同时出现“vx 二维码”“微信群”和“微信直接不跳转”。微信占比应实测，不应从中国用户身份直接推导。

## 三个创始人判断

### 1. “方便简洁、使用体验好，是第一位的”

**强支持。**

- 用户反复把问题压缩成“一个 html 链接”“一句 `/publish`”“不要切浏览器”“二维码发微信”。
- 放弃点非常早：部署流程一断就放弃；AI 产物只留在 `127.0.0.1`；求职作品干脆改录视频。
- 这里的“体验好”不仅是 CLI 参数少，还包括：首次免登录、链接稳定、国内首开快、微信能开、远端失败可解释、更新后不会拿到旧快照。

### 2. “是否要建立用户反馈、曝光、后续孵化机制或生态”

**反馈支持；公开曝光/孵化暂不支持进入 v0.1。**

- QQ 群、问卷和论坛求试玩说明反馈需求真实，且当前链路碎片化。
- “没人玩”说明测试者供给真实存在，但做公开发现页会把产品拉到 M4，与 itch/TapTap/小游戏平台竞争，还引入更重的内容治理。
- 更合适的顺序是：先把邀请、版本归因和反馈做完整；提供好看的微信分享卡、二维码、邀请名单和可导出的反馈；若 T3 长期低，再验证“受控测试者池/与 Jam 社群合作”，而不是先建广场、榜单或孵化器。

### 3. “是否要提供数据分析，让开发者知道哪里流量好、哪里有问题”

**支持最小结果层，不支持通用分析平台。**

- “本地 8 秒，线上半分钟”“朋友二十多秒”“不同运营商打不开”直接支持来源、设备、加载完成率、资源失败和 JS 错误。
- “没人玩”“每天十几个人”支持独立打开人数和回访数。
- QQ 群/问卷支持一句话反馈和版本关联。
- 没找到足够原话要求热图、复杂漏斗、用户画像或长期增长看板。`DESIGN.md` §3.4 的轻量边界是对的。

### 综合判断

- 国内开放 Web 游戏作者**不为零，且在 AI 小作品、作品集、Jam、Godot/轻量引擎和 playable ads 中形成若干集中场景**。

- 对 `playtest.run` 更现实的定位不是“中国 Web 游戏发布平台”，而是“任何浏览器可运行原型的最快私测路径”；将 AI 小应用、互动作品和 Jam Demo 一并纳入，才能扩大入口。

## 最后回答

### （a）“发给具体的人玩”与“上小游戏平台”，哪个需求更真

**两者都真，但人群和时刻不同。**

- 对 AI 创作者、Jam 参与者、求职作品和早期原型，具体邀请更即时：原话直接指向朋友、客户、招聘方、评委和自己的手机；他们要的是几秒拿链接，不是运营。
- 对 Cocos 社区里的职业/副业游戏开发者，上小游戏平台更高频、更有经济动机：软著、备案、审核、广告、买量与“没人玩”的讨论远多于纯 Web 托管。
- 所以不能回答成“具体邀请在国内整体上比小游戏平台更大”。更准确的是：**它是一个被正式发行工具做得很差、但跨多个小人群重复出现的前置时刻。** 这足以做楔子，是否足以做独立生意仍要用 T2/T3 验证。

### （b）“第一批用户在大陆、微信是主渠道”站得住吗

- **大陆优先：站得住，前提是获客确实从本轮这些中文 AI/Jam/引擎社区开始。** 境外托管可达性、国内穿透免费档、备案和小游戏体验版都构成具体摩擦。
- **微信主渠道：方向合理，但证据不足以升级为事实。** 微信群、`vx` 二维码、小程序体验码大量出现；同时微信也会拦截或不跳转外链。本轮没有打开来源占比数据。应继续把它写成假设，并以 T5 实测；不要为了微信假设提前增加微信登录或小程序壳。

### （c）国内做开放 Web 游戏的人多不多

- **相对小游戏/原生，不多；绝对数量不明。**
- Cocos 的公开强信号属于微信小游戏，不是开放 Web；Web 导出使用率没查到。
- Godot 中文社区有数千兴趣关注、数百核心小组量级信号，但 Web 导出占比没查到。
- BOOOM 2025 有 277 个作品，规则仍把 Windows/Mac 包作为必交、WebGL 作为可选；Web 占比没查到。
- 这意味着不能用“国内 Web 游戏开发者很多”作为立项前提；应该用 20 人私测里的真实上传类型、第二次发布率和每版打开人数来决定市场是否成立。

## 对 playtest.run 的含义

### 支持 `DESIGN.md` 的发现

1. **M1/M2 的摩擦真实：** 手机测试、给朋友/客户/评委看、localhost 只能自己看，都有直接原话。
2. **一条命令与匿名首发链接必要：** 登录、域名、部署和 GitHub OAuth 都会中断；匿名 24 小时链接保护首次体验。
3. **大陆可达是有效楔子：** itch 阻断有测量，Vercel/GitHub Pages 的不稳定有跨年份原话。
4. **玩家零安装、零登录正确：** 比赛和朋友试玩都在追求“直接体验”；体验员名单已经被抱怨。
5. **轻量结果层正确：** 远端慢、白屏、不同设备坏、没人玩、反馈散，支持打开/设备/来源/加载/错误/一句话反馈。
6. **版本与稳定 slug 有价值：** TRAE 的旧快照、链接失效说明“同一链接更新”必须有清楚版本语义。
7. **内容域与品牌域分离必要：** 免费托管域被滥用、微信不跳转和整域风险不是理论问题。
8. **不先做完整分析平台正确：** 没有足够用户原话支持热图、复杂漏斗或增长套件。

### 与 `DESIGN.md` 冲突或证据不足

1. **“引擎导出的静态目录占多数场景”未被国内 Jam 证据支持。** BOOOM 默认下载包、WebGL 可选；需要私测记录真实产物类型。
2. **“微信是分发主渠道”仍是假设，不是结论。** 有大量场景线索，没有打开占比。
3. **“GitHub 在大陆基本可用且开发者都有”过于乐观。** OAuth 超时、认证卡住和临时访问事故会破坏首次流程；AI 新手也未必已有 GitHub。
4. **“小游戏必须企业主体”若作为对外比较会失真。** 个人可上部分微信/抖音小游戏；真正差异是审核、体验员、备案、类目、支付和正式发行成本。
5. **“国内 Jam 多用 itch”需要更新。** 本轮看到 CiGA 用 GmHub、BOOOM 用机核自有游戏库；itch 仍用于海外 Jam 和个人镜像，但不能概括国内 Jam 默认。
6. **只做交付可能解决不了 T3。** “没人玩”比“发不出去”更常见；如果用户没有测试者，再快的链接也不会得到 5 次打开。
7. **“知道结果是护城河”方向成立，付费意愿未成立。** 用户要反馈和故障信息，但没有直接证据表明会为这一层持续付费。

### 建议先改什么（只写建议，不直接改 `DESIGN.md`）

1. **把首批定位收窄为三个可招募群体：** TRAE/Claude Code 做浏览器小作品的人、国内 Jam 参与者、需要发 Web 作品集/早期 Demo 的 Cocos/Godot 作者。不要泛称所有独立游戏开发者。
2. **把“微信主渠道”降级为待测假设：** 文案写“为微信分享优化”，产品验收仍要求微信真机可玩；是否主渠道由 T5 决定。
3. **把 GitHub 登录风险写进首次流程：** 匿名链接必须在任何登录之前成功；GitHub OAuth 失败要有清楚错误和重试，不能让 M1/M2 卡死。
4. **v0.1 优先静态上传和终端二维码，隧道保持可用但不预判占比。** 公开原话更强地支持“产物拿链接”，游戏专用隧道需求仍要靠 T4。
5. **门禁页做成可测变量。** 用户追求零跳转，门禁页又承担音频手势、版本、举报和会话起点；私测比较“每 24 小时一次”与“直接开始”对启动率的影响。
6. **结果页先回答四个问题：** 有没有人打开、是否开始、是否加载完成/报错、反馈说了什么。来源细分到微信/二维码/直接链接即可；暂不扩展通用流量分析。
7. **不要现在做公开发现页；先补“把邀请发好”。** 优先分享卡片、二维码、短说明、口令/邀请名单、反馈导出。若 T3 低且访谈明确说缺测试者，再试受控测试者池或与 Jam 社群合作。
8. **定价先访谈，不从云服务器价格直接推导。** 当前可见锚点是十几至百元/年，且免费偏好强；v0.1 免费、等用户主动问价的策略合理。
9. **把竞争对手列表加上“录视频”和“AI 编辑器内置分享”。** 前者是行为替代，后者会吞掉通用发布；两者都比另一家 Web 托管更接近真实选择。
10. **把停止条件继续放在核心位置。** Web 人群规模信号不足；T2、T3、T4、T5、T6 比继续做二手市场推演更能决定项目方向。
