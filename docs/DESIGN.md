# playtest · 产品推演与设计

> 一条命令，把你手上这个能玩的版本放到一群真的会来玩的人面前，然后知道他们玩成了什么样。

> 2026-09-07 起草，2026-09-09 按方向 B 重写。本文是唯一产品定义。推演过程保留在文中，因为每个结论都要能回答「为什么不是另一个」；
> 方向变了直接重写本文，不留 changelog。市场调研的证据在 `docs/research/`，真机记录在 `docs/spikes/`。
> 一张能一眼看完的图：`docs/whiteboard.html`。细节仍以本文为准。

## 0. 结论

先读这一节，其余各节是它的出处。

1. **起点是「没人玩」，不是「发不出去」。** 2026 年做一个能玩的东西边际成本接近零，拿到一条链接谁都免费给（Surge、Netlify、TRAE 内置分享），「知道结果」那一层竞品的免费档也有。中英文社区里最痛的一句话都是「没人玩」（`docs/research/`）。唯一没被商品化的东西是**真人**：愿意点开、玩五分钟、说一句话、下一版还来的人。产品站在这一样东西上。
2. **产品是一个地方，不是一根管子。** 我们叫它**广场**，对玩家它是一个「每天都有新东西可以试、点开就玩、不用注册」的去处；对开发者它是一群会回来的试玩者。管子（上传与隧道）没有降级——它是这个地方的供给侧，仍然是同一条命令、同一种链接、同一套对游戏有感的响应头；`playtest mcp` 让 AI coding agent 成为最大的供给管道。
3. **三个环，顺序不能反。** **邀请环**：每次发布产出一张可分享的邀请卡，卡把玩家带进来；**回访环**：玩过的人一键「有新版本叫我」，下一版发出去时他们收到通知；**注意力环**：有了回访，广场才有不为某一个作品而来的人，这时才有透明的推广位和测试者周报可卖。没有卡就没有玩家流入，没有关注就没有回访，没有回访广场就不是目的地，不是目的地就没有东西可卖。
4. **玩家首次零门槛；身份从行为里长出来，永不强制。** 第一次玩：不登录、不装、点开就玩。玩过之后自愿留下：留个名字（进开发者的点名册）、留个邮箱或允许浏览器通知（关注）。身份是设备上的东西先长出来，再由一条邮件链接带到别的设备上——不是注册出来的。开发者永远看不到玩家的邮箱，通知由我们代发。
5. **邀请卡是分发单位。** 一张带二维码的图，是门禁页在微信里的实体：微信对未备案域名不出链接卡片，而图片是微信里最自然的传播形态（群二维码、小程序码都是这么传的）。卡的口吻是「某某邀请你」，不是「你获得了」——它是邀请函，不是兑换券（§3.4 有硬线）。
6. **关注是留存原语。** v7 的玩家在 v8 发出去时收到一条通知，这是 itch 的 follow、Steam 的 wishlist、TapTap 的预约在所有游戏平台上反复验证过的机制，也是「第二版还有人来」唯一可靠的解法。
7. **广场是目的地，形态是「试玩俱乐部」，不是消费者大厅。** 免费流按时间排、只放开发者主动公开的、玩家没有账号也能翻；广场本身和每个作品都能「关注」（在栏上和门禁页上，不在卡上）；透明限位的推广位（每屏最多两个、永远标「推广」）；每周一封给关注者的周报。目标规模是几千个会回来的试玩者，不是百万 MAU——几千个回访的人就足以让每个开发者「发出去就有人」，而且在监管雷达下面。
8. **收钱卖的是「被看见」和「认真做测试」，不卖托管。** 推广位、多留几天、进周报，是开发者已经在 Fiverr 上花 200 美元买 7 个测试者的那笔钱；Pro 档卖固定链接、去角标、私密测试、结果留存。免费档硬上限、不产生账单。开发者讨厌为托管付钱，玩家不可能付钱，「为被看见付钱」是 itch、Steam、Product Hunt 都验证过的。
9. **五条物理约束不放。** 从不运行用户代码（Glitch、Replit 的死因）；每 slug 每小时熔断（SIMMER 的死因）；首次游玩零门槛（整个品类的共识）；不往作品画面里注入任何东西（社交层走门禁页与开发者自选的 SDK）；玩家域与开发者域分离（cookie 安全）。其余以前写成「不做」的——玩家身份、公开反馈、名次、推广、承诺有人来——是习惯，不是物理，本文把它们放开了，理由各在其位。
10. **第一批用户在大陆，边缘在香港，全球可用是底线；微信是分发渠道，不是浏览渠道。** 卡片和群在微信里传播，广场在系统浏览器和别的 App 里活。越火越容易被微信整域拦截是这条路上唯一没法用产品设计消掉的风险（§5），选择承担。
11. **开源不变**（§7）。CLI 与 SDK 宽松许可，边缘与控制面 AGPL 且可自托管；托管服务是生意。
12. **这是一个产品，不是一个实验。** 不设「T3 不到 5 就停」的停止条件；§8 里的数字是产品健康指标，用来调，不用来判生死。

**这一版推翻了上一版的三个判断**，理由写在 §9：把 2025 年那批平台的死因读成「有社区就会死」（实际死于跑用户代码、无熔断的账单和支付通道，没有一家死于发现页）；把「玩家零门槛」从「首次」外推成「永远」（切断了所有网络效应）；把「不承诺有人来」当成克制的美德（它是在用户最痛的地方退场）。

## 1. 起点：人和时刻

### 1.1 谁

供给侧四类人，痛点相近、工具不同：

- **用 AI 写小东西的人。** 拿 Cursor、Claude Code、TRAE 做出一个浏览器里能玩的东西——Three.js 场景、Phaser 小游戏、p5 草图、几个人联机的小房间、一个微型工具。抽样里近八成不是游戏，不认「试玩」这个词；手上常是一个 `npm run dev`；未必开终端，但一定在跟模型对话。**这群人同时是最好的试玩者**：今天做了一个东西的人，明天就是别人作品的观众。
- **Game Jam 参与者。** 48 小时做完，要上传给评委和别人玩。国外默认 itch.io（大陆整域屏蔽），国内 jam 用机核 BOOOM、CiGA 的 GmHub，多要求 Windows / Mac 包、WebGL 可选。
- **独立与业余游戏开发者。** Godot、Unity、Cocos、Construct、GDevelop、PICO-8、Twine、Bitsy……导出一个 Web 目录，想找人试。
- **创意编码与互动体验作者。** shader、生成艺术、WebXR、数据可视化玩具、课堂演示。

共同点：产物是浏览器里跑的东西；想要的是「现在就给你看」，不是「上架」；而且**多数人没有自己的观众**——「做了一个月，上了三个平台，没人玩」在中英文社区里都比「发不出去」更常见。

需求侧一类人，是这一版新加进来的一等公民：

- **试玩者。** 喜欢试新东西的人——开发者自己的朋友、jam 的评委、AI 编程社群里的同行、被一张卡吸引进来的路人。他们不想注册、不想装东西，但玩到好东西时愿意留一句话，也愿意知道「这个东西更新了」。

### 1.2 开发者的时刻

| 时刻 | 现在怎么做 | 哪里疼 |
| --- | --- | --- |
| **M1 · 手机上试一下**（开发中，自己一个人） | `--host` 后在手机上敲 `192.168.x.x:5173` | 手机和电脑不在一个网；WebXR、陀螺仪、摄像头、WebGPU、Service Worker 都要 HTTPS；Windows 防火墙拦端口；每天都发生 |
| **M2 · 现在发给朋友看**（几个人，几分钟） | 打包 zip；或临时部署 | zip 对方不会跑；部署要注册、要 git、要等构建，流程一断就放弃，最后录个视频了事；链接在微信里点不开或很慢 |
| **M2b · 让对方敢点开、想点开**（同一条链接，对方那一侧） | 发 exe / zip / 裸链接 | SmartScreen 拦 exe；钓鱼 PSA 教人只点 web build；免费隧道域名弹警告页、被公司和学校网络整域封；**微信里一条裸链接没有名字、没有封面、没有人味**，一张写着真人名字和作品名的卡才有人点 |
| **M3 · 找一批人测**（5–50 人，几天） | itch 加密码 + 表单 / Discord / QQ 群收反馈 | 不知道多少人打开、玩到哪、在什么设备上坏；收回来的是「挺好玩，有个 bug」；反馈对不上版本 |
| **M3b · 手上有版本，没有人**（一个人，反复发生） | 发到群里、r/playmygame、论坛「求测」帖；Fiverr 花 $200 买 7 个测试者 | 帖子沉得快；来的人玩了什么不知道；「上了抖音微信快手根本没人玩」。**这是最常见的一格，这一版把它当主战场** |
| **M3c · 下一版还有人来**（第二版、第三版） | 再发一遍群；再求一遍 | 上一版玩过的人找不回来；每一版都从零开始找人；第二版打开人数比第一版还少 |
| **M4 · 正式发布**（永久页面、变现） | itch、Steam、TapTap、微信小游戏 | 大平台的事，不缺我们 |
| **M5 · 带后端 / 联机的版本给人试** | 部署服务器；或 ngrok / frp | 静态托管做不到；ngrok 在大陆不稳；联机测试真正的瓶颈是让四个人同时在线 |

### 1.3 试玩者的时刻

| 时刻 | 现在 | 哪里疼 |
| --- | --- | --- |
| **P1 · 收到一张卡** | 群里一条 `https://xxx.playtest.run` | 不知道是谁发的、是什么、要不要点；微信里裸链接连标题都没有 |
| **P2 · 点开就玩** | 点开是警告页、要登录、白屏、没声音 | 每多一步就走一批人；音频没有用户手势就静音 |
| **P3 · 玩完之后** | 关掉标签页，什么都没留下 | 想说一句话没有地方；想知道下版什么时候出没有办法；不知道还有什么别的可以玩 |
| **P4 · 下一次** | 没有下一次 | 开发者发了新版，他不知道；他上次留的那句话有没有被看见，他不知道 |

### 1.4 从时刻推出来的三件事

1. **时刻决定交付方式。** M2 / M3 的产物若是静态目录，**上传**比隧道对玩家更快、不依赖开发者的电脑开着；M1 / M5 的产物是一个正在跑的进程，只能**隧道**；用 AI 写小东西的人手上常常只有跑着的进程。两条路都要，长在同一个命令、同一种链接、同一套响应头上（§3.2、§4.2、§4.3）。
2. **首次零门槛，之后自愿留下。** P2 决定了第一次玩不能有任何登录、安装、跳转。P3 / P4 决定了玩完之后必须**有地方留下**：留名进点名册、留邮箱或允许通知就是关注。留下的每一步都是可选的、都在玩之后、都不挡在「开始」前面。
3. **地方是产品，管子是供给。** M3b 与 M3c 加起来是最常见的痛，它们的解法不是一条更快的链接，是一群会回来的人。卡把人带进来（邀请环），关注把人留住（回访环），广场让一个作品的玩家成为另一个作品的观众（注意力环）。「知道结果」（§3.5）仍然是开发者留下来的理由，只是点名册上现在有名字、有关注数、有「来自卡片 / 通知 / 广场」。

## 2. 市面上已经有什么

2026-09-07 查过一遍，同日用 13 条调研线复核（`docs/research/`）。市场比「游戏托管 + 隧道」的直觉拥挤得多，分六类看。所有「几步 / 多久」除 `docs/research/2026-09-07-hands-on-tunnels.md` 外都是从文档推的，不是实测。

### 2.1 六类现有解法

| 类 | 谁 | 做得好 | 缺的 |
| --- | --- | --- | --- |
| **上传 Web 构建拿链接** | itch.io（butler）、Unity Play、The Gaming Nest、Final Parsec、**Surge**、Netlify Drop、tiiny.host、SIMMER（2025-04 死于 DDoS 账单） | 红海：免登录出链接是行业常态、有 CLI 或引擎插件、有版本回滚 | 全在境外——itch 在大陆整域屏蔽，`vercel.app` 大多被屏蔽；**没有一家在上传那一刻告诉你为什么跑不起来**；只有 itch 做真增量但后端 processing 最长 30 分钟；不做隧道；不做结果；**没有一家把「谁来玩」当自己的事** |
| **AI 单文件 HTML 托管** | Clawcade、AIGameShare、rendrd（两家有 MCP server）、ArcadeLab、localgames.fun；腾讯 EdgeOne Pages / Makers | 零门槛、单文件、agent 直接发布——打的正是 §1.1 第一类人 | 不碰引擎导出物；EdgeOne 大陆节点要备案、平台域名在大陆只给 3 小时预览链接；有的有画廊页，但玩家不能关注、开发者拿不到下一版的回访 |
| **Playtest 结果** | 按录像分钟卖（Playset、Playcocola）；按 AI credit / 席位卖（Playloop、Bugnet、LoopKit、PGPT）；按「帮你找到人」卖（The Playtest、FirstLook、Antidote、PlaytestCloud） | 「玩家零门槛」是共识；截图标配；**这一类有一半产品的价值在「帮你找到人」**，价格 $115–2,825 / 月 | 全类目没有隧道；**没有一家以命令行为入口**；没有一家做交付；找人那一半全是人工招募的高价服务，没有一个是「你的玩家自己留下来」 |
| **通用隧道（全球）** | ngrok、Cloudflare Tunnel、bore、zrok、pinggy、localhost.run；围绕 AI 编程新出的 tunr、uplink | 「分享 localhost」被做透 | 依赖境外托管网络，大陆连接差；**没有一个会补游戏响应头**；访客侧中间页是例外；没有上传路径 |
| **通用隧道（大陆）** | cpolar、natapp、花生壳、樱花 frp、飞鸽 | 大陆节点 | 免费档 0.5–10 Mbps，随机地址、签到、实名；无上传、无结果、无游戏感 |
| **正式分发** | Steam Playtest、TestFlight、微信 / 抖音小游戏、TapTap 篝火测试 | 平台，有玩家 | 是 M4 不是 M2 / M3；小游戏体验版要后台加体验成员、正式版要审核与备案 |

两个真实的替代品不在表里：录个视频发 B 站（免费、稳定、绕开一切兼容问题，代价是失去交互和行为反馈）；AI 编辑器内置分享（TRAE 已有产物链接，Lovable / bolt / v0 内建发布——GitHub Spark 2026-08 关停的教训是强制登录杀死传播）。

### 2.2 离我们最近的几家，以及我们不一样的地方

- **itch.io**：是这个位置上真正的在位者——有画廊、有 follow、有 jam、有 devlog；但大陆整域屏蔽，且它是商店（支付、成人内容、支付商压力）。我们和它的差：一条命令、大陆可达、对游戏有感的边缘、点名册式的结果、不卖游戏只卖被看见。
- **Poki / CrazyGames**：证明「有玩家的地方可以卖 playtest」——Poki Playtesting 靠 1 亿 MAU、CrazyGames 的 Basic Launch 靠 5,000 万 MAU。我们不需要那个量：几千个回访的试玩者就足够改变每个开发者的第二版。
- **Surge**：形状最像上传路径（`surge ./dir`、免登录、不可变版本、回滚、统计）。差在游戏响应头、门禁页、结果、香港、同一条命令走隧道，以及它没有观众。
- **tunr 与 uplink**：隧道侧认真的对手，已在卖反馈组件和 MCP。差别是它们不管游戏、没有上传、境外，也没有观众。它们开源免费，决定了我们也必须是（§7）。
- **Clawcade 与 EdgeOne**：AI 人群与大陆两侧的相邻对手，各占一半。Clawcade 有 agent 入口没有引擎导出物；EdgeOne 有大陆节点但要备案、默认域在大陆只给 3 小时。
- **Playset 等「结果」类**：没有一家做交付、没有一家以 CLI 为入口；「帮你找到人」那一半靶向发行商预算，$115 起步。我们把「找到人」做成玩家自己留下来，边际成本接近零。

### 2.3 缺口与风险

**缺口**：没有人同时做到「一条命令上传或隧道 + 大陆可达 + 对游戏有感 + 链接对方敢点开 + 玩家零门槛 + 点名册式的结果 + 玩家会回来 + 一个不用注册就能翻的地方」。前六项每一件都有人做得不差，我们的机会在组合；后两项在中文世界是空的——itch 被墙，TapTap 是成品商店，TRAE 的分享是死链接，机核与 GmHub 只在 jam 期间活。

**风险**：一个公开的地方意味着内容审核、举报处置、排序公平和监管正面（§4.8、§5）。2025 年那批平台的死因给了我们边界（不跑代码、要熔断、不碰支付商敏感内容），也给了我们信心（没有一家死于发现页本身）。两个人做一个地方需要一个人的时间从写代码转到供给与社区上——这是 §9 里创始人明知的代价。

## 3. 产品

### 3.1 一条链接

`https://<slug>.playtest.run`——一个 slug 就是一个作品，永远指向它最新的版本。免费随机 slug（两个词加短数字，如 `brisk-otter-41`），登录后可以改成自己的名字。同一个 slug 下上传或隧道都行，切换对玩家透明。

不用路径（`playtest.run/u/xxx`）：引擎导出物里全是绝对路径，路径式一定坏。不加多余的标签：这个域名本身就是给内容用的。

### 3.2 开发者这一侧：一个 CLI

只装一样东西：`playtest`。

```
playtest ./dist                       # 上传：静态目录 → 链接 + 二维码 + 邀请卡
playtest 5173                         # 隧道：本地端口 → 链接 + 二维码 + 邀请卡
playtest ./dist --backend 3000        # 混合：目录上传，清单外的路径走隧道到后端
playtest ./dist --watch               # 目录变了自动发新版本
playtest ./dist --public              # 放到广场上
playtest ./dist --seek "想让人看什么" --seats 10   # 标「正在找人测」，想找 10 位试玩者
playtest ./dist --summary "一句话" --cover cover.png --community https://…   # 卡片文案、封面、你的群
playtest card <slug>                  # 重新拿一张邀请卡（存成 PNG）
playtest followers <slug>             # 有多少人关注着这个作品
playtest unlist <slug>                # 从广场上拿下来，链接照常能开
playtest login                        # 浏览器里 GitHub 登录一次，之后不再问
playtest ls / rm / open / versions / rollback
playtest … --json                     # 机器可读输出、日志走 stderr、分层退出码
playtest mcp                          # 作为 MCP server 跑：Cursor / Claude Code 里一句「发给朋友玩」就出链接、二维码和邀请卡
```

第一次运行不登录也能拿到一个 24 小时的匿名链接——免登录是 M1 的要求，也是 GitHub 登录在大陆间歇失败时的兜底（§5）：第一次必须在任何登录之前就成功。终端里直接画二维码，手机扫码就是 M1。

**发布成功时打出的东西**（第一次用的人靠这几行知道接下来做什么）：链接；二维码；邀请卡存到了哪（`./<作品名>-邀请卡.png`）；放到广场了没有、标了求测没有；匿名链接什么时候失效；「来的人玩成什么样，控制台里看得见」加控制台地址；本次耗时。`--json` 模式里这些是字段（`url`、`qr_text`、`card_url`、`card_path`、`plaza_url`、`expires_at`、`console_url`、`elapsed_ms`）。

**「几秒」是数字，不是形容词。** CLI 结束时打印本次从敲命令到出二维码的耗时；验收 P50 < 5 s。这只在单静态二进制的前提下成立——不走 npm、不依赖系统 ssh（§4.7 选 Rust 的最直接理由）。

**入口不只是终端。** `playtest mcp` 暴露「分享端口、上传目录、列出作品、看这一版的结果、拿邀请卡」五个工具，把链接、二维码和**邀请卡图片**贴回对话里——MCP 的内容块支持图片，agent 可以直接把卡递给用户转发。AI coding agent 是这群用户最自然的分发渠道，也是广场最大的供给管道。

CLI 之外的形态——桌面托盘应用、引擎导出插件——开源后希望社区做。

### 3.3 门禁页就是邀请函

玩家点开链接，先看到我们渲染的一页，同一个 URL、不跳转。它和邀请卡（§3.4）是**同一个物件的两种媒介**：玩家在群里看到的图和点开后看到的页，一眼认出是一回事——同一张封面、同一句话、同一个版本号。这是信任感的来源，也顺带满足微信规范 §3.2.3 对「展示一致」的要求。

**从上到下：**

1. 封面（`--cover`；没有就用作品名排一张字卡，那是设计好的版式，不是假装的截图）。
2. **「某某 邀请你试玩《作品名》」**——识别到 Godot / Unity / Phaser / Cocos 等引擎导出物用「试玩」，其余默认「体验」（用 AI 写小东西的人多数做的不是游戏）。
3. 一句话介绍（`--summary`）；`v7 · 9 月 9 日 · 「改了新手引导」`（版本、日期、这版改了什么）。
4. 名额那一行（设了 `--seats` 才有）：「某某在找 10 位试玩者 · 已有 6 位加入」。**加入 = 留了名字的人**，不是所有打开的人；到齐之后写「10 位已到齐 · 你仍然可以玩」——不拦人，只如实说。
5. **「开始」**，旁边一个可选的输入框「你的名字（可不填）」。同一个表单、一下点击。名字进开发者的点名册（§3.5），不进任何账号。
6. 「开始」下面，弱化的三行：**「有新版本时告诉我」**（点开展开邮箱输入，或「用浏览器通知」按钮，§3.6）；**「开发者的群」**（`--community` 设了才有，去哪是开发者的事，我们对去向不承诺）；**「分享」**（公开的作品才有，打开分享页给你这张卡的图和链接，§3.4）。
7. 试玩者的话（开发者开了「让玩家看到彼此的反馈」才有，§3.5）：最多三条，署留下的名字或「一位试玩者」，带版本号。
8. 最底下：举报；免费档与匿名链接的角标「由 playtest.run 提供」，Pro 可去掉。

**它为什么值得存在，五个理由不变**：它是这条链接的**信任凭证**（M2b）；「开始」这一下是浏览器要求的**用户手势**，之后音频能播（真机记录见 `docs/spikes/2026-09-07-gate-user-activation.md`；绑 click / pointerup，不绑 touchstart）；它是**会话的起点**（种本站 cookie）；它是**版本的告示牌**；隧道那头不在线时它变成「开发者的电脑暂时不在线，上次在线 12:40」。

**三条硬线，否则它就是第二个警告页**：门禁页只在顶层文档导航上渲染（`Sec-Fetch-Dest: document`）；子资源、API、WebSocket upgrade **永不返回「200 + HTML」**；**不存在绕过它的请求头**。判据是请求语义，不是 User-Agent。

**一次点开在 24 小时内不再重复出现**（开发者可选「每次都出」或「不出」）。整页不超过几 KB、不引第三方脚本、1 秒内出现。没有 JS 也能点「开始」、能留名；关注的邮箱表单是原生表单，浏览器通知那个按钮需要 JS。分享出去时服务端直出 Open Graph 元数据：有封面用封面，没封面用横版邀请卡（§3.4）——一张写着作品名和开发者名的卡不是假截图，Discord、iMessage、Telegram 会抓；微信对未备案域名的抓取没有承诺，所以微信里靠卡（§5）。

**微信里**：门禁页给「在浏览器中打开」的提示，但「开始」始终在、始终可点——只给提示不给路径触及微信规范 §3.2.3。

### 3.4 邀请卡

**是什么。** 每个作品一张 PNG，由边缘按当前版本渲染，`/_playtest/card.png`（1080×1350，竖版，发群里用）与 `/_playtest/card-wide.png`（1200×630，横版，做链接预览的 `og:image`）。发布时 CLI 存一份到当前目录并打出路径；`--json` 与 MCP 把它交给 agent；控制台里能预览、保存；门禁页的「分享」打开一页只放这张图、「保存图片」和「复制链接」（支持 Web Share API 的浏览器直接弹系统分享）。

**上面有什么**：封面（或字卡）；「某某 邀请你试玩《作品名》」；一句话介绍；`v7 · 9 月 9 日`（匿名链接则写到期时间：「这张邀请到 9 月 10 日 20:59」）；名额（设了才有：「在找 10 位试玩者」）；二维码（指向作品链接，带 `?from=card`，点名册据此知道这个人是扫卡来的）；一条撕票线；角落「playtest.run」（Pro 可去掉，和角标同一条规则）。

**上面没有什么，为什么**：玩过人数（0 人不说是 §3.5 的规矩，卡上没有可数的东西，就一个字不放）；「限时领取」「立即抢」任何优惠券口吻；「游戏 / 体验」品类；任何我们的营销话。**硬线：卡的口吻是「某某邀请你」，不是「你获得了」。** 理由不只是审美——微信《外部链接内容管理规范》§2.5 点名的是「以游戏、测试等方式吸引用户参与互动」的营销 H5，一张长得像兑换券的卡是在往规则最针对的形态上靠。邀请函是私人递出的东西，兑换券是商家发的东西，我们只能是前者。

**它为什么值钱**：它借的是 ZCODE 那类凭证卡的**克制**——深底、一张图、一个署名、一个日期、一条撕票线，别的没有。「值钱的感觉」来自留白和真人名字，不来自更多的字。

**「分享」按钮只在公开的作品上出现。** 私测的邀请不该被转发；公开求测的作品，玩家帮开发者招玩家正是开发者想要的——这是邀请环的病毒那一半。

**它是我们在微信里唯一被看见的面。** 开发者愿意转发一张好看的卡，角落那个名字就是获客环（Carrd 创始人说过「Made with Carrd」是它的增长来源）。

### 3.5 知道结果

不做分析平台。5–50 个具体的人不构成统计，所以这里没有「流量」「留存率」「漏斗」，只有**计数和点名**：「这 3 个人停在第三关」，不是「37% 流失」。分两层：

**不用改游戏一行代码就有的**（来自门禁页与边缘）：多少人打开；多少人点了「开始」之后真的进到游戏（门禁到首帧之间掉了几个——网页游戏门户实测有四成人在加载完成前就走了，是第一层里最值钱的一条）；每个人的设备与浏览器、停留多久（只给中位数和逐条明细）、资源哪里加载失败、是不是回头的；**留了名字的人的名字**；来自哪里——`微信 / 浏览器 / Discord` 之外新增 **`广场`、`邀请卡`（扫码带 `?from=card`）、`通知`（关注通知里的链接带 `?from=notice`）**，开发者据此知道三个环各带来了几个人。

**加一行脚本才有的**（可选 SDK `playtest.js`）：JS 错误与堆栈；加载分阶段用时；自定义事件 `playtest.event("level_done", {level: 3})`——文档只教一种用法：标记进度里程碑；最后一个事件与最后一次输入的时间戳；右下角一个反馈按钮——玩家写一句话，附截图、设备、版本、进入多久；反馈提交后那一屏是**玩后的落点**（§4.6）：「谢谢」、「有新版本时告诉我」、「看看别的作品」。反馈不设必填项。

**开发者在控制台看到的不是仪表盘，是点名册。** 每版一段话：

```
v7 · 9 月 5 日 14:20 · 「改了新手引导」
8 个人打开，6 个人进到游戏（2 个在加载时走了——其中 1 个微信 Android，game.wasm 下到 61% 中断）
3 个人玩了 5 分钟以上，2 个人回来过第二次；来自：邀请卡 4 · 广场 2 · 微信 2
1 个 JS 错误撞了 3 次（TypeError: Cannot read 'x' of undefined @ main.js:412）
1 条反馈：「不知道要按哪个键」· 小雨 · 附截图 · iPhone 15 Safari · 进入 47 秒
12 人关注着这个作品，下一版发出去他们会收到通知
```

点开是这一版的会话列表，每人一行，有名字的显示名字，可按「停留最短」排序；反馈单独一条流。不画图表。手机上也能看。这段话在控制台里怎么摆、控制台整体长什么样，在 §3.13。

**反馈可以公开**（开发者每个作品一个开关，默认关）：开了之后门禁页上显示最近三条，署留下的名字或「一位试玩者」；开发者可以隐藏任何一条。它是社会证明——「这里有人」——不是讨论区：没有回复、没有点赞、没有楼层。

**不收集的**：玩家身份之外的任何东西——名字是自愿填的，邮箱只用于他自己要的通知且开发者看不到，不跨站追踪、不记 IP、不要精确位置。数据默认保留 90 天。**数据由我们收、隐私责任在我们的声明里，开发者不用自己碰 GDPR / PIPL**。

### 3.6 关注与通知

**是什么。** 玩家对一个作品说「有新版本时告诉我」，或对广场说「有新东西时告诉我」。两种渠道：**邮箱**（填邮箱 → 收到一封确认信 → 点一下 → 生效；双重确认，没人能替别人订阅）；**浏览器通知**（Web Push；Android Chrome 与桌面浏览器可用，iOS 只对加到主屏幕的站点生效——门禁页按能力检测只显示当前浏览器能用的那一种，不能用的不显示也不解释）。

**触发什么。** （1）关注的作品发了新版本：一封「《作品名》出了 v8：改了新手引导」，正文是开发者写的 `--note`，链接带 `?from=notice`；**每个作品每 24 小时最多一封**——一天发五版的开发者，关注者只收到当天最后一版的那封。（2）关注了广场：每周一 09:00（Asia/Shanghai）一封周报，「这周新出的 12 个东西」，每个一张封面、一句话、开发者名，另加「其中 5 个正在找人测」。（3）没有别的——不发「你还没玩完」、不发「好久不见」、不发我们自己的任何消息。

**身份怎么长出来。** 第一次点确认信里的链接，浏览器落在 `playtest.run/me`，根域种一个只属于根域的 cookie（`pt_me`，host-only，子域读不到，§4.1）。从此在这台设备上，根域「我的」里关注广场是一下点击，不再要邮箱（作品子域读不到这个 cookie，门禁页上仍是邮箱）；换一台设备就是再点一次确认信里的链接，或在「我的」里给自己发一封。**没有密码、没有注册页、没有「创建账号」这四个字。**

**开发者看到的是数字，不是名单。** 控制台和 `playtest followers` 只给「12 人关注」；邮箱由我们保管、我们代发；开发者退出或删除作品时关注一起消失。这不是限制，是卖点——开发者不用自己扛一份玩家邮箱的合规责任。

**退订**：每封信底部一键退订链接（一个令牌，点了就退，不问为什么）；「我的」里逐个取消。退订立即生效。

**边界**：不给玩家开发者级的「关注某个人」——那需要开发者主页，v1 没有；先按作品和广场两级走。

### 3.7 版本

每次上传就是一个版本（`v1, v2, …`），不可变；`<slug>` 永远指最新；控制台一键回滚就是把指针指回去。会话与反馈按版本归档。上传时可以附一句「这版改了什么」，门禁页上显示，**也是发给关注者的那封信的正文**——所以它值得认真写。上传按文件内容哈希增量。隧道模式没有版本概念，只有「在线 / 离线」和会话；隧道不触发通知。

### 3.8 谁能玩

三档：任何拿到链接的人（默认）；要口令；只允许邀请名单（链接带一次性令牌，或玩家填邀请码）。都在门禁页完成，玩家不需要注册。口令 / 邀请名单与 `--isolated` 的跨源隔离要对齐（itch 上开了 SharedArrayBuffer 的作品加口令后在 Safari / Firefox 弹窗里 404，这个 bug 活了两年）。私密的作品不上广场、卡上没有「分享」。

### 3.9 广场：目的地

**是什么。** `playtest.run/`——根域那一页。对玩家：「每天都有新东西可以试，点开就玩，不用注册」；对开发者：一群会回来的试玩者。它是**试玩俱乐部**，不是消费者大厅：目标是几千个会回来的人，不是百万 MAU。

**为什么是这个形态。** 三个可选形态：*itch 式的发现大厅*（默认公开、按热度排、点赞评论，观众是陌生大众，审核、排序公平、反作弊全落到两个人头上，把境外不备案的内容域推到监管正面）；*只放不排的告示板*（上一版的选择：不排名次、不点赞、玩家没有任何持续的东西——它把「被看到」做到了，把「回来」切断了，每个从微信进来的玩家都是死胡同）；**俱乐部**（选这个）：公开可翻、只放开发者主动公开的、免费流按时间排；但玩家可以关注、可以留名、可以收到周报；推广位透明限位。它拿到了「被看到」和「回来」，代价是内容审核和一个小型通知系统，两个人做得到。

**在哪。** 根域 `playtest.run/`，不是 `playtest.roviix.com`。广场的观众是玩家，根域本来就是玩家域；控制台域只放登录之后的东西（AGENTS 第 7 条）；品牌域不放用户内容（§4.1）。

**页面是两块：左边一条窄栏，右边一面墙。** 栏 76px 宽，上面从上到下：**标记**（一个暗色小方块，里面一个象牙的 p 和一个琥珀点——就是字标 `playtest.run` 里那一个点；字标本身只在手机顶条上出现，不上色）；**广场**（人在这一页时标出来）；**我的**（§3.10）；栏底一个 **发布**（加号），打开本页命令说明。每一项是一个图标加一个两字标签，竖着排。**为什么窄。** 两间房撑不起 250px：宽栏的下半截永远是空的，而墙是这一页的全部，多出来的宽该给封面。**为什么现在有图标。** 窄栏里只有两个字读不出是什么，图标是给标签配的记号，不是后台的装饰；图标是画在页面里的几笔线，不引图标字体。发布说明的眉题是「从一条命令开始」，正文三步：装好 CLI、在作品目录里跑一条（三种情形用单选标签切换）、发出去之后去哪看——控制台链接在第三步里。右边直接是网格。**没有播放键、没有「发布作品」菜单、没有面包屑、没有页脚旁白、没有口号、没有「关于」、没有版本号、没有门口那句话、没有「正在找人测 · N」那一行、没有筛选、没有排序开关、没有预览开关、没有脚本弹窗**：推广位在最前（最多两张，标「推广」，§3.11；没有推广时不占位），其后是正在找人测的，再往后按时间排。卡少的时候也从左边第一列排，不居中。手机上栏收成顶上一条：左边标记加字标，右边三个药丸（广场、我的、发布）——发布仍在，它是发布唯一的门，不能藏。

**栏上为什么只有两间房。** 「我的」是试玩者回来的抽屉：关注过的作品、邮箱、通知开关。发布是开发者出门：GitHub 登录和上传都在另一张域上，所以栏底那个「发布」打开的是说明，不是一间房。关注广场只在「我的」里办（§3.10）。俱乐部人数也不写在栏上，那是一句没有下一步的旁白。

**为什么参考稿上的包装都拿掉。** 上一版有六个筛选、两种排序、三个分段标题、每张卡上三个按钮——它们把一面「有什么可以玩」的墙排成了一张后台列表。控件仍不要。参考稿只留下「左栏 + 一面墙」这个结构；橄榄夜和酸黄绿没留下（见「长相」）。卡不跟那张大表面卡走。口号、门口、播放键、面包屑、「无需登录 / 不用安装」和墙底那句规则，都不让任何一张卡更近。字标旁的播放键看起来像会动，点了只回首页。发布只留栏底便条。说明用 `:target`，不要脚本。三条命令用单选标签切换。说明里那条控制台链接，是玩家路径上唯一去开发者域的出口（AGENTS 第 7 条）。参考稿里的预览开关和「试玩预览弹窗」要脚本，正式页没有。参考稿把「我的」写成「我的作品」并送去控制台——栏上「我的」仍是试玩者的抽屉（§3.10）。顶栏也不放第二颗「开发者控制台」。

**卡片上有什么，只有这几样**：一张贴在墙上的物件卡。上面一块**横的插画窗**（4:3）——有 `--cover` 就是封面图；没有就是一张**字卡**：按 slug 定色的色田上铺一层细网格，左下角是作品名的第一个字排成花押，右上角是 slug 的等宽小字——两样都是作品本来就有的事实，不是编出来的图。窗的左上角**最多一个标**——「推广」或「正在找人测」。求测用玩家域那一支琥珀，推广只用灰。能悬停的设备上，右下角「试玩 / 体验」悬停才出来（触屏上一直在）；整张卡仍是一个链接。窗下面：作品名（只这一处）。正在找人测时，先写「这次想测」再写那句求测的话，一行放下；没在找人就用简介。最底一行左边是开发者头像与名字，**右边是一件事实**：正在找人测且设了名额 →「6 / 10 位」；匿名作品 →「还剩 5 小时」；近 7 天有人点过开始 →「12 人玩过」；其余 →「12 分钟前」。一张卡上只出现其中一个。**卡上没有的**：常驻的「即刻试玩」、引擎名、关注、想玩、举报、第二个可点的控件、「N 人关注」、点赞、评论、名次、算法推荐、法力、规则栏、宝石。关注仍在门禁页上（§3.3）。举报入口在作品页上（`/_playtest/report`）。

**长相。** 玩家域只有一套颜色，门禁页、邀请卡、广场、「我的」共用：近黑的暖炭 `#0b0b0c` 做墙，象牙白 `#ece8e1` 做字，**唯一的一支色**是门禁页「开始」那一支琥珀 `#ffb224`——它只出现在动作、「正在找人测」的标、当前那间房旁边的一个点、键盘焦点的那一圈上。字标不上色。**为什么不再有一支品牌绿。** 一天里试过苔藓、新叶、墨、酸黄绿四支，每一支都在和封面抢颜色：亮了像游戏站的霓虹，灰了像没上色。封面是这一页唯一该有颜色的东西；一个玩家从群里那张琥珀色的邀请卡点进琥珀色的门禁页，再回到广场，不该换一种颜色。**卡是一件物件**：一块比墙亮一档的面（`#151518`），一圈发丝线（`rgba(255,255,255,.08)`）描边，上沿一道更淡的高光——像被顶灯照着的东西；插画窗（4:3、圆角）嵌在面里，四边留 6px 的边，像装裱的画心；窗下面写作品名和一行字，最底一条发丝线分出「谁 · 一件事实」。悬停时整件抬起 3px、面亮一档、底下出一团散开的影子。标和动词是压在窗上的玻璃签：半透明的近黑、一圈发丝线、等宽字，「正在找人测」前面有一个发光的琥珀点。三级面（墙 `#0b0b0d`、栏 `#0f0f12`、卡 `#151518`）之间只差一两档，靠发丝线和高光分出层，不靠对比。没封面时色田压低饱和度，像布不像霓虹。手机两列，平板三列，桌面四到五列，卡与卡之间留 20px。这一页**一行脚本都没有**。**稀疏态**：卡从左边第一列排。空墙仍说「广场上还没有作品」。

**交互的几条硬线。** 能点的东西键盘都能到，落到哪儿哪儿有一圈琥珀（`:focus-visible`），鼠标点不出这一圈。触屏上可点的地方不小于 40px 高。悬停才出现的东西（动词）在触屏上一直在。一切过渡在 `prefers-reduced-motion` 下关掉。发布说明在桌面居中、在手机从底部升起，点遮罩或右上角的 × 都能关；没有脚本，所以 Esc 关不了——这是零脚本的代价，认了。链接不带下划线，除了正文里那种「去别处」的链接。

**为什么卡回到有面、有边的物件，不再是贴在墙上的一张画。** 无框那版（2026-09-10 上午）把窗直接贴在黑墙上：窗与窗之间只剩黑，字写在黑上，没封面的作品是一块空色田，整面墙看起来像文件夹里的缩略图，谈不上质感。质感来自层：一块面、一圈发丝线、一道高光、一团影子，眼睛才知道这是一件可以拿起来的东西。参考稿那张卡比我们的好看，靠的也是这些，不是靠它多出来的播放键和引擎名。**但不是参考稿那张**：参考稿三列加大封面加常驻「即刻试玩」，一张卡占半个屏幕，墙变成货架；我们的卡上仍只有 §3.9 列出的几样，四到五列。封面仍是横窗，不回到 1:1——方窗把封面收成图标。邀请卡仍是竖的（§3.4）。不做法力、规则栏、宝石。

**谁能上。** 只有开发者主动公开的作品，默认不公开。匿名 24 小时作品可以上（到期自动下来）；登录用户的作品长期在。私密（口令 / 名单）的作品不能公开。

**举报与撤下。** 举报入口在每个作品自己的页面上（§3.3 第 8 条），广场卡片不再重复放一次。同一作品 24 小时内被 3 个不同会话举报，自动从广场撤下（作品链接照常能开），人工复核后恢复或删除。推广中的作品在上推广位之前**先人工看一眼**——我们收了钱，就要看过。

**微信是分发渠道，不是浏览渠道。** 卡片和群在微信里传播；广场在系统浏览器、Discord、Telegram、即刻里被打开。在微信里翻广场永远不可靠，我们不为它优化（§5）。

### 3.10 我的

`playtest.run/me`。和广场共用左边那条栏，当前项是「我的」；回来走「广场」。没有 `pt_me` 时：一句话说这里会放什么，一个邮箱输入（留下就是关注广场）；有能力时再加「用浏览器通知」。有 `pt_me` 时：关注的作品与广场、每一项的取消、邮箱（打码显示）、浏览器通知的开关、「换一台设备」（给自己再发一条链接）。**没有的**：头像、昵称设置、历史记录、任何像「个人主页」的东西——它是一个抽屉，不是一个 profile。

**为什么没有「登录 / 注册」。** 一个发现页上放「登录」「注册」两个按钮是平台的惯例，我们不放，理由有三。第一，试玩者侧零门槛是硬约束（AGENTS 第 6 条）：这一页的每个人都可以点开任何一张卡直接玩，账号对他没有任何用处。第二，试玩者唯一需要「身份」的场景是「下一版告诉我」，这件事一个邮箱加一封确认信就够了，`pt_me` 就是从那封信里长出来的（§3.6）——它是身份，但不是账号：没有密码、没有资料页、没有「创建账号」这四个字。第三，开发者的登录（GitHub）在开发者域上（§3.2、§4.1），发布是在终端里敲一条命令，不是在网页上点「上传」；栏底便条打开命令说明，控制台链接才把开发者送去那里，广场自己不承担登录。**也曾考虑过的**：广场上放一个「登录」只给开发者用——被否，因为它会让每个路过的人都以为这里要登录。

### 3.11 推广位

**是什么。** 开发者为一个作品买一个时间窗，窗内它出现在广场顶部的推广位上，**永远标「推广」**，每屏最多两张，超出排队（按购买顺序、按日历顺延，控制台里看得到排到哪天）。两个 SKU：**推广 3 天**、**推广 7 天**；一个附加项：**进本周周报**（周报里单列一段「推广」，最多两个）。

**规则**：免费流一个字不动——按时间排的那一列永远在，穷开发者不比没有推广位时差一点；标签永远在，颜色低饱和但一定看得见；匿名作品不能买（要有账号，责任要落到人）；上推广位前人工看一眼，拒了全额退；推广不改变「N 人玩过」的计算，推广带来的打开在点名册里标「来自广场」——开发者能看见自己花的钱换来几个人。

**为什么现在就设计、什么时候开卖**：形态现在就定，因为它决定广场页面的版式和数据结构；开卖要等境外主体与支付通道（Stripe，含支付宝）落地（§9）。在那之前控制台里「推广」一节如实写「尚未开放，主体落地后开通」，不放一个不能点的按钮；运营者可以通过管理接口**赠送**推广（冷启动期给好作品送几天推广，标签仍是「推广」）。

**为什么不是「付费排名」**：排名把首屏交给最有钱的，推广位只是多出来的两个格子。为什么不是「付费去广告」：广场上没有广告可去。为什么不卖「更多流量」：流量是成本边界不是购买动机（§6）。

### 3.12 明确不做

分两栏。左栏是**物理**：成本结构或安全边界决定的，不随产品方向变；右栏是**现在不做**：形态原因，方向变了可以再议，要先改本文。

**物理，不放：**
- 运行用户的代码——只分发静态文件、转发连接。这是安全边界，也是滥用面的上限，也是 Glitch 与 Replit 教育版的死因。
- 没有硬上限的免费——月配额加每 slug 每小时熔断（§4.8、§6），SIMMER 的死因。
- 首次游玩要登录或安装。
- 往作品画面里注入任何东西——不改写开发者的字节、不改写 URL、不改响应体；SDK 是开发者勾选的。这是一条能用哈希对拍验证的承诺。
- 画面录像——正在被开源工具白送，在网页游戏上技术上尤其贵；截图不在此列。
- 原生包分发、游戏引擎、编辑器、云端构建。
- 通用分析平台：热图、漏斗、分群、A/B、DAU / MAU / 留存曲线、AI 总结。
- 大陆境内服务器与备案（§5）。
- 地图与任何基于位置的东西。

**现在不做，理由在形态：**
- 聊天室、私信、评论区式的开放讨论——五个人、24 小时到期的链接上房间永远是空的，空房间比没有房间更伤开发者；聊天正是「挺好玩，有个 bug」这种零信息反馈的温床。公开反馈（§3.5）是开发者可控的单向展示，不是讨论区。
- 算法推荐流——排序只有三种：时间、7 天人数、透明的推广位。
- 给玩家卖东西、给开发者变现——我们卖的是被看见，不卖游戏；不碰支付商对内容的压力。
- 按名次排的榜单、「官方精选」——两个人没有编辑精力；将来若做，标签叫「我们在玩」并写明是人挑的。
- 孵化、评审、基金、付费招募测试者的双边市场——广场让玩家自己留下来，不卖测试者、不承诺人数。
- 关注开发者（而不是作品）、开发者主页——v1 没有主页，先按作品与广场两级。
- 玩家 App、微信小程序壳。
- 帐号托管、代跑。

### 3.13 控制台：开发者的工作台

**是什么。** `playtest.roviix.com/console/`，开发者登录之后看自己作品的地方。它不是仪表盘（§3.5 的规矩不变：没有图表、没有比例、没有漏斗），也不是一份报告——它是一张**工作台**：作品在上面、此刻的状态在上面、要做的几件事在手边。

**它只在四个时刻被打开**，每一个对应 §1.2 的一格，第一眼要给的东西由时刻决定：

| 时刻 | 开发者想要 | 第一眼 |
| --- | --- | --- |
| 刚发出去（CLI 打出 `console_url`） | 链接对不对、玩家看到什么、把卡拿去发 | 邀请卡、玩家链接与二维码、「在广场上 · 正在找人测」、匿名链接的到期 |
| 测试进行中（M3） | 谁在玩、出了什么事 | 「现在」那一条：近一小时几个人、最新一条反馈、有没有错误 |
| 发下一版前（M3c） | 上一版告诉了我什么 | 每版一块，数字先、句子后、来源在末 |
| 发了下一版后 | 关注的人回来了没 | 来源里的「通知 N」、关注数、和上一版比的那一行 |

外加一格**收拾**：回滚、从广场撤下、删除作品、看每版体积。

**页面是两块：左边一条栏，右边一张台面。** 和广场（§3.9）是同一套记号、同一个标记、同一种物件卡——开发者从广场点「控制台」过来，是走进同一座房子的另一间房，不是换了一个产品。栏比广场的宽（15rem）：它要放作品清单，广场的栏只放两间房所以窄。栏上：标记与字标；**作品清单**，每个作品一行，名字加一个状态点（在广场上 / 匿名快到期 / 平常）；栏底：账号（GitHub 头像与名字，或「匿名 · 24 小时」）、去广场、一张便条打开「发下一版」的命令。手机上栏收成顶上一条，作品清单进首页。

**首页是作品墙。** 一张卡一个作品：封面或按 slug 定色的色田、作品名、slug，**右下一件事实**（只出现一个）：正在找人测且设了名额 →「6 / 10 位」；匿名 →「还剩 5 小时」；近 7 天有人点过开始 →「12 人玩过」；其余 → 最近一版的时间。这一套和广场卡的规则（§3.9）是同一份。只有一个作品时直接进它，不停在墙上。**没有作品时不是一句灰字**，是一个设计好的起点：三条命令、「发出去之后这里会出现什么」的一段话、控制台地址在 CLI 输出里的那一行。

**作品页从上到下：**

1. **身份栏**：封面（或色田）、作品名、slug；玩家链接、「复制」、二维码；状态签一行：`v7 · 当前`、`在广场上 · 正在找人测`、`12 人关注`、`6 / 10 位`、匿名的到期。签是事实，不是按钮。
2. **「现在」**：一行字，说此刻——「近一小时 3 个人打开 · 最新一条反馈 12 分钟前：『不知道要按哪个键』 · 这一版 3 个错误」。没有近况就说「最近一次打开是 9 月 5 日」。这一行让控制台有当下，是它和一份报告的区别。
3. **分页签**：**结果**（默认）、**点名册**、**反馈**、**邀请卡**、**设置**。签是地址的一部分，刷新不丢。

**结果**：每版一块，块里先是四个大数字（打开 / 进到游戏 / 5 分钟以上 / 反馈；0 的不排大，退成灰字），然后是 §3.5 那段话（一句一行，0 的句子不说），然后「来自 邀请卡 4 · 广场 2 · 微信 2」，最后和上一版比的那一行（「比 v6：打开 +3，反馈 1 → 2」）。块尾两件事：「点名册」、「设为当前」（不是当前版才有）。**数字排大不是图表**——它是把句子里最要紧的两个数从行文里提出来，仍然是计数，不是比例。

**点名册**：一版一张，每人一行，停留最短在前；名字是这一行的主角，没留名字的用会话号头几位；标签说进到哪、玩到哪、来自哪、是不是回头的；展开是这个人的事件与错误。这一页不变（§3.5），只是搬进了分页签。

**反馈**：一句话是主体，署留下的名字或「一位试玩者」，版本、设备、进入多久；每条可标看过 / 处理完；开了公开反馈的作品每条可隐藏 / 恢复。

**邀请卡**：竖版和横版两张放大到能看清字；「保存图片」、「复制链接」、支持时「分享」；一句话说它去哪用（群里发竖版，链接预览用横版）。它是发出去之前最后一眼，所以单独一页，不塞进设置里。

**设置**：广场（放不放、找不找人、想让人看什么）、名额、开发者的群、公开反馈（即 §3.5 的「让玩家看到彼此的反馈」，界面上只叫公开反馈）、推广（主体落地前如实写「尚未开放」，一个按钮都没有）、版本清单（每版文件数与体积，回滚在这里）、最底下**危险区**：从广场撤下、删除作品（删除要再敲一次 slug）。

**长相。** 和玩家域（§3.9「长相」）同一套记号：墙、栏、卡三级面，发丝线与高光分层，象牙字，唯一的一支色是琥珀，只用在当前那一间房、状态点和要紧的数字上；警示用一支暗橙。数字用等宽字。手机优先，桌面两栏。结果页那四个数不装在四个小盒子里，用发丝线隔开排成一行——盒子把计数排成了仪表盘。作品的窗拿不到封面图就退成字卡，破图标不是一种状态。主要动作的按钮是象牙面、墨字（和广场栏底那个「发布」同一种），琥珀不做按钮色，它留给「此刻」与「当前」。

**文案（两域通用）。** 界面上的字只说事实，不解释为什么、不预告接下来会怎样、不安慰。一句能说完的不写两句；括号里的补充、破折号后的转折、引号包起来的自造词，都是在页面上替自己辩解，删掉。数字用「8 人打开」不用「8 个人打开了」；比较用「打开 +3，反馈 1 → 2」不用「多了 3 个人打开，反馈从 1 条升到 2 条」。按钮是一个动词或一个名词：「保存」「撤下」「点名册」，不是「让玩家看这一版」这种带宾语从句的句子——除非短了会有歧义。理由写在代码注释和本文里，不写在玩家和开发者眼前。**为什么。** 解释多的界面读起来像在道歉；一个只报事实的界面，读者才会信它报的事实。**开发者永远看不到玩家的邮箱**（§3.6），关注只有数字。

**为什么不是另一个。** *单栏、每页一列卡、卡里是段落*（上一版）——它把「每版一段话」做成了「每页一段段的话」，设置块压在结果上面，没有此刻、没有导航语境，看起来是一份文档；「点名册」是结果层的形态，不是整个控制台的形态。*仪表盘*——图表、KPI 卡、时间范围选择器，对 5–50 个人的数据是噪音（§3.5、§3.12）。*和广场不同的一套皮*（上一版的米白与琥珀）——开发者是这个产品里唯一同时进两间房的人，两套皮让他觉得是两个产品。*管理页放进控制台*——运营者用 `scripts/admin.sh`，管理页后置（§4.5）。

**现在做不到、如实写的**：隧道在线 / 离线只有边缘知道，控制面还没有这个字段，身份栏上暂不显示；「近一小时」从这一版的会话里在浏览器侧数，控制面加上专门的字段之前只对最新一版算。

## 4. 架构：从产品倒推

### 4.1 两个域名，各管一件事

- `*.playtest.run`：**只放玩家看的东西**——门禁页、邀请卡、分享页、上传的构建、隧道转发。根域是广场、「我的」、关注确认与退订，**没有登录**（`pt_me` 不是登录，是一把只开「我的」这个抽屉的钥匙）。
- `playtest.roviix.com`：开发者控制台（`/console/`）、API、文档、管理接口；SDK 由边缘在作品自己的域上同源提供（§4.6）。

为什么是 `roviix.com` 的子域而不是买一个 `playtest.sh`（2026-09-08 定）：分开的两个理由——cookie 隔离与「品牌不陪葬」——只要求「另一个可注册域」，`roviix.com` 已经满足；roviix 是制作者、playtest 是它的产品。

为什么分开：任何用户的作品都是一个能跑任意 JS 的源。登录如果也在 `playtest.run` 下，一个作品就能对父域种 cookie 去干扰控制台会话。分开之后互不相干。再申请把 `playtest.run` 提交进 Public Suffix List——但不依赖它。

**根域上的玩家身份怎么隔离。** `pt_me` 是 host-only cookie，只种在 `playtest.run` 这一个主机名上，`Domain` 属性不写，兄弟子域读不到、也种不进来；作品子域上的门禁 cookie 只认自己的 slug。子域上的门禁页要「关注」时，表单提交给自己域上的 `/_playtest/follow`，由边缘转给控制面——玩家的浏览器从不把邮箱直接交给另一个域。

**边缘对控制面只有「写」方向的调用。** 事件上报、关注登记、确认与退订，边缘同步或批量地写给控制面（`PLAYTEST_API_INTERNAL_URL`）；**从不为「读」回源**——作品、广场、邀请卡、名额与关注数，全部从对象存储里读控制面写好的文件。控制面挂了：作品照常能玩，广场照常能翻（人数旧几分钟），邀请卡照常能出，只有「关注」会得到一句如实的「现在登记不了，稍后再试」。

泛域名：一条 `*.playtest.run` 解析加一张 DNS-01 签发的泛域名证书覆盖无限个 slug。约束是 slug 只能一级，63 字符以内。

### 4.2 上传路径

```
CLI：遍历目录 → 每个文件算内容哈希 → 问 API 哪些哈希没见过 → 只传这些（并行、可续）→ 提交清单 → 得到 v7
边缘：按清单服务：路径 → 哈希 → 对象。对象不可变、长缓存；HTML 不缓存。边缘本地盘做热缓存，对象存储做源
```

对象存储放香港区域的 S3 兼容服务；Cloudflare R2 出网免费但大陆访问差，不用作玩家直连的源。

对游戏有感的地方都在边缘的响应头里：`.wasm` 给 `application/wasm`；目录里有 `.br` / `.gz` 预压缩产物就按 `Accept-Encoding` 直接给并加 `Content-Encoding`；`--isolated` 一开就加 COOP / COEP（Godot 4 线程导出需要）；SPA 回退可选；支持 Range。**同一套头对隧道路径同样生效（§4.3）。**

**上传那一刻做检查，用人话说出来。** 服务端此刻已经拿到全部文件，而全行业没有一家在这一刻做任何检查。能查而没人查的：Godot 导出物是不是线程版（是的话「这个构建需要 `--isolated`，帮你开还是你重新导出？」）；`index.html` 在不在根；Unity 的 `.br` 与 Decompression Fallback 是否冲突；`.pck` / `.data` 有没有漏；单文件是否超限；**没有封面**（提醒一句，不拦）。

单版本大小、保留版本数、每月流量按档位限制（§6）。

### 4.3 隧道路径

要求：从开发者机器只出不进；走 443 且看起来像 HTTPS；一条连接上复用很多玩家连接；WebSocket 原样过；断了自动重连；边缘要能计量；不依赖用户机器上有 ssh。

**v0.1 用 WebSocket over TLS + yamux 多路复用**；QUIC 留给 v0.2（UDP/443 在一部分网络被掐，必须保留 WSS 回退）。`ssh -R`、裸 TCP、HTTP/2、WebRTC 直连各自的淘汰理由：依赖系统 ssh 且计量做不了；公司代理只放 CONNECT；只有客户端能开流而方向反了；浏览器侧要 Service Worker 配合且复杂度高。

边缘按 Host 找到隧道会话，开一条 yamux 流，把请求以 HTTP/1.1 写进去，把响应流回玩家；101 之后双向拷贝字节。默认把 `Host` 改写成 `localhost:<port>`（Vite 6.0.9 之后默认只放行 localhost），原值放 `X-Forwarded-Host`；检测到 Vite 时打印 HMR 那一行配置。

**响应头在隧道路径上也补；响应体一个字节不动。**

生命周期：CLI 退出或电脑休眠即离线，门禁页显示离线与上次在线时间；重连 1 s → 30 s 指数退避加抖动；一个 slug 同时只绑一条隧道，新的挤掉旧的（旧连接收到关闭码 4001，旧令牌进驱逐名单，重连一律 409）；离线判定在边缘（20 秒一个 ping，60 秒没帧就离线）；令牌活不过作品。

**上传与隧道混合**：`playtest ./dist --backend 3000`，上传的清单就是分界线——清单里有的从边缘给，清单里没有的路径经隧道到开发者机器。后端离线时清单外的路径回 `503` 加 JSON（`backend_offline`），不是一页 HTML。

隧道不适合的场景要在 CLI 里说出来，而且要算出数字：「你这个目录 32 MB，隧道模式下一个玩家大约要等 45 秒，十个人同时进来会更久。建议 `playtest ./dist`。」

### 4.4 边缘放哪

玩家和开发者在哪，边缘就在哪附近。第一批用户在大陆，边缘放**香港**：不需要备案，是大陆玩家能直接到的最近的境外。这是工程手段不是卖点，文案里不出现地理。

延迟不是地理决定的，是回程线路决定的：同样标称香港，CUG / CMI 优化线全国三网平均 34–56 ms，普通国际回程 194–319 ms 且绕美欧。「大陆到香港 30–60 ms」是压测的验收目标，不是事实。选云之前压一周：三网 × 两个城市 × 家宽与 4G × 白天与晚高峰 × 微信 WebView 与系统浏览器，记 p50 / p95 / p99、丢包、30 与 100 MB 持续下载、traceroute。结果进 `docs/spikes/`，此前本文不出现供应商名和毫秒数。第二个区域等有那边的用户再加。

### 4.5 控制面

`playtest.roviix.com`，一个关系库（v0.1 SQLite，出现第二个写入节点再换 Postgres）：用户、slug、版本、对象清单、隧道授权、会话、反馈、用量；这一版新增**玩家、关注、通知、推广、名额与留名**。四类客户端：CLI（设备授权）、控制台、边缘（写方向）、管理接口（运营者，令牌鉴权）。

**控制面写文件、边缘读文件**，这是两者之间唯一的读路径：

| 文件 | 内容 | 什么时候重写 |
| --- | --- | --- |
| `sites/<slug>/v<N>.json`、`sites/<slug>/current.json` | 版本清单与当前指针（不变） | 提交版本、回滚 |
| `sites/<slug>/live.json` | 这个作品**会变的那些**：名额与已加入人数、关注数、群链接、反馈是否公开与最近三条公开反馈、开发者头像地址 | 有人留名、关注变化、开发者改设置、反馈被公开或隐藏、每 5 分钟 |
| `plaza.json` | 广场的全部内容：作品（含封面、头像、7 天人数、关注数、名额进度、求测、到期）、推广中的作品与窗口、关注广场的人数 | 公开 / 撤下 / 求测变化、新版本、推广上下线、每 5 分钟 |
| `capabilities.json` | 控制面现在能做什么：邮件是否配了、Web Push 的公钥 | 控制面启动 |

为什么不让边缘查库：边缘不认识控制面是这里的第一原则——控制面挂了，作品与广场照常，只是数字旧几分钟。

**边缘写给控制面的**：第一层事件每 60 秒批量（不变）；**关注登记、确认、退订同步转发**（玩家在等一句「确认信已发」）；留名跟着 `start` 事件一起走（名字是事件里的一个字段）。

**新增的表**：`players`（邮箱或推送订阅，确认时间，退订令牌）；`follows`（玩家 → 作品或广场，来源，时间）；`notifications`（待发队列、发送时间、渠道、结果——每作品每 24 小时最多一封在这里判）；`boosts`（作品、SKU、窗口、状态 pending / live / ended / rejected、是否赠送、订单号）；`sessions` 加 `name` 列；`sites` 加 `seats`、`community_url`、`feedback_public`；`feedback` 加 `public` 列。

**管理接口**（`/admin/*`，`PLAYTEST_ADMIN_TOKEN` 鉴权）：赠送 / 审核 / 撤下推广；手工撤下广场作品；看通知队列。运营者用 `scripts/admin.sh` 调它；控制台里的管理页后置。

### 4.6 SDK

`playtest.js`，几 KB，无依赖：捕获错误、加载用时、自定义事件、反馈按钮；只往 `playtest.roviix.com` 发，不种第三方 cookie。脚本由边缘在作品自己的域上同源提供（`/_playtest/sdk.js`），开发者加一行 `<script>`。

**反馈提交后的那一屏是玩后的落点**——这是不注入作品画面的前提下，唯一能在游戏里放社交层的位置，而且它是开发者选的。上面三样：「谢谢」；「有新版本时告诉我」（邮箱或浏览器通知，走 `/_playtest/follow`）；「看看别的作品」（去根域）。没接 SDK 的作品在游戏里什么都没有——他们的玩家在门禁页和广场上完成同样的事。

### 4.7 语言与实现选择（2026-09-07 已定：Rust）

CLI、边缘、控制面都用 **Rust**，一个 Cargo workspace（`cli/`、`edge/`、`api/`、共享类型在 `common/`）。控制台与 SDK 是 TypeScript。为什么不是 Go：两个都对，创始人的判断是**开发成本不是约束，要体验和健壮性更好的那个**，且团队近期手感在 Rust 上。

边缘 TLS：**前置 Caddy**（带 Cloudflare 插件，DNS-01 签泛域名证书，`deploy/`），边缘进程只说明文 HTTP；DNS 放 Cloudflare 但只做解析不做代理。本机开发阶段边缘走明文，Chrome 与 Firefox 把 `*.localhost` 当作安全上下文。

### 4.8 滥用与安全

公网托管用户内容天生是钓鱼与恶意软件的渠道。分层：

- **我们从不运行用户代码**：滥用上限就是「托管一个坏页面」。
- 创建长期作品要 GitHub 登录；匿名链接只活 24 小时、带角标、限流量。每账号活跃 slug、月流量、并发玩家有上限。
- **额度是双重上限**：月配额挡长期滥用，**每 slug 每小时流量熔断**挡 DDoS——在边缘本地判定，超限把 slug 转成一页静态说明。
- 门禁页本身就是反钓鱼的：多一次点击和一个写着别人名字的告示牌。
- slug 黑名单；举报 → 下架 → 令牌撤销 → 边缘立即断。
- **广场**：只有开发者主动公开的作品会上去；24 小时内 3 个不同会话举报即自动撤下；封面走那个 slug 的每小时熔断；根域页面不出用户的任何可执行内容；**推广位上的作品先人工看过**。
- **关注**：邮箱双重确认，没人能替别人订阅；登记接口按来源令牌桶限速；每封信带一键退订；发信域名配 SPF / DKIM / DMARC；退订与投诉率进运维看板，超阈值自动停发并告警——发信信誉是这条环的命。
- **留名**：名字过一遍脏词表与长度限制；开发者可以在点名册里隐藏任何一个名字；公开反馈里的名字同样。
- **推广**：匿名不能买；先审后上；付了钱被拒全额退。
- 控制台与内容域彻底分离（§4.1）；管理接口只在开发者域、令牌鉴权。
- 隧道模式提示开发者：暴露开发服务器等于暴露源码和 `/@fs/` 这类接口。

### 4.9 邀请卡的渲染

由**边缘**渲染：它手里有清单、封面 blob 和 `live.json`（名额），`/_playtest/card.png` 与 `/_playtest/card-wide.png` 按当前版本出图，`ETag` 跟版本与名额走，边缘本地缓存。渲染路径：拼一张 SVG（版式、文字、二维码矢量、封面以嵌入图引用）→ `resvg` 光栅化为 PNG。**中文字体**从系统读（`fontdb` 加载系统字体目录），服务端镜像装 `fonts-noto-cjk`，本机开发用系统自带的中文字体；不把字体编进二进制（十几 MB，且任何标题都可能用到子集之外的字）。二维码用 `qrcode` crate，内容是作品链接加 `?from=card`。渲染一张卡的目标是 100 ms 以内、一次渲染多次命中。

为什么不在 CLI 本地渲染：CLI 拿不到玩家侧的名额进度，且要在三个平台上处理字体；为什么不在浏览器 canvas 里画：匿名用户没有控制台可去，agent 路径要的是一个文件。

### 4.10 通知的投递

**邮件**：控制面里一个发信抽象，三种实现由环境变量选——`log`（本机开发，把整封信打进日志）、`resend`（托管版）、`smtp`（自托管）。发信域 `notice@playtest.run`，DNS 上配 SPF / DKIM / DMARC（Cloudflare，创始人操作）。模板中文、纯文本优先、一张封面、一个链接、一行退订。**每个作品每 24 小时最多一封**在入队时判：同一作品 24 小时内已有一封已发或待发，就更新待发那封的正文而不新建。周报周一 09:00 Asia/Shanghai 由控制面里的定时任务生成。

**Web Push**：VAPID 密钥对在控制面第一次启动时生成并存进数据目录；公钥经 `capabilities.json` 给边缘、再给门禁页；订阅对象存 `players`；发送用 `web-push` crate；订阅失效（410）即删除。iOS 只对加到主屏幕的站点生效，门禁页按能力检测决定显不显示这个按钮。

**失败形态**：邮件服务商不可用时，登记照常成功、确认信进队列重试，玩家看到的是「确认信稍后送达」，不是报错；发送失败三次进死信、运维看板可见。

## 5. 大陆特有的现实

- **微信是分发渠道，不是浏览渠道。** 《微信外部链接内容管理规范》（2025-10-23 生效）§2.5 把「H5 游戏、测试类内容」列为常见违规情形，§2.18.4 把未备案、难以追溯运营者的链接列为风险，§3.2.2 把多域名规避列为对抗，§3.2.3 把「微信内展示与其他浏览器实质性不一致」列为对抗。实际执法多针对病毒营销 H5，但规则文字给了腾讯全部裁量权。**所以「微信里点开就能玩」是待验证假设，不是承诺**；文案写「为微信分享优化」；发布前用真实微信账号在 Android ≥ 6 台、iOS ≥ 4 个系统版本上测私聊 / 群聊 / 朋友圈的门禁页与实机游戏，并向腾讯客服书面确认 §2.5 对非营销、私人 playtest 链接的适用口径，结果进 `docs/spikes/`。**邀请卡是在这个现实下最稳的形态**：图片在微信里天然可传，不被链接过滤、不依赖 OG 抓取；但卡不是规避手段——卡上的二维码指向的仍是同一条链接，微信里打开它面对的是同样的规则。我们不做域名轮换、不做短链套娃。
- **越火越容易被整域拦。** 一个安静的告示板和一个每天几万人翻的目的地，在这份规范面前的处境不同。这是方向 B 唯一没法用产品设计消掉的风险，创始人在 §9 里明知代价做了选择。能做的：只放开发者主动公开的、有真人名字和头像的东西；举报自动撤下；根域页面上没有任何作品的可执行内容；被处理后 24 小时内提交申诉；广场在系统浏览器和别的 App 里活，不为微信内浏览优化。做不到的：如果根域被微信整体拦截，作品子域是否连坐取决于腾讯。
- **封禁机制与对策。** 官方可处理单链接、域名或 IP；整域处理的明文条件是「同域名下大量链接违规，经处理后仍未及时、有效整改」。对策：内容域与品牌域分开；门禁页、举报、快速下架把违规概率压低；被处理后 24 小时内提交申诉。
- **未备案的其他代价。** 朋友圈分享未备案一级域名有频次限制；微信 JS-SDK 安全域名必须备案——分享卡片只能服务端直出 Open Graph 元数据尽力而为。
- **微信内置浏览器的能力不可靠。** 门禁页用能力检测（`crossOriginIsolated`、`SharedArrayBuffer`、`navigator.gpu`、`PushManager`）而不是 UA 黑名单；首屏不依赖 WebGPU、Wasm 线程、Service Worker、全屏、横屏锁定或摄像头。
- **整个域名被墙**是存在性风险。除了内容治理和快速响应，没有技术对策。如实写在这里。
- **不落大陆。** 境内服务器要备案、要主体、要承担内容责任。香港边缘加境外主体是唯一现实路径；付费走 Stripe，支付宝经 Stripe 接境外主体。
- **登录。** GitHub 在大陆间歇可用，且不能假设每个目标用户都有账号。匿名 24 小时链接必须在任何登录之前把第一次完整跑通；GitHub OAuth 是可失败、可重试的增强路径。微信登录要开放平台企业主体，不在 v1。玩家侧的身份走邮箱与浏览器通知，不走任何需要主体的东西。

## 6. 成本与商业

变动成本是带宽与邮件。香港出网约 $0.1 / GB 是合理的中位基线：一个 30 MB 的导出物被玩 1,000 次约 $3；邮件按托管服务商价约 $1 / 千封。

**免费档**：登录账号每月 **10 GB** 硬上限、3 个活跃 slug、保留最近 5 个版本、每 slug 并发 50 人、结果保留 30 天、关注不限、上广场不限；匿名链接 **1 GB / 24 小时**。到上限硬停、不产生账单。**双重上限**：月配额之外，每 slug 每小时流量熔断。为什么是 10 GB：1,000 个免费账号满额 20 GB 在 $0.10 / GB 下是每月 $2,000，超过「固定成本百美元」的叙事；10 GB 仍比 ngrok 的 1 GB 慷慨，足够一轮 30 人的测试。

**两个收钱的产品，两个购买时刻。**

1. **推广**（§3.11）——购买时刻是「我想让更多人来测这一版」。初始定价：推广 3 天 **$9**、7 天 **$19**、进本周周报 **$9**；支付宝按当日汇率。为什么是这个而不是卖流量：流量是成本边界不是购买动机；开发者已经在 Fiverr 上花 $200 买 7 个测试者，我们让它便宜一个量级。
2. **Pro**——购买时刻是身份变化：「从随手给朋友看，变成给发行商、客户、封闭玩家群做正式测试」。**$15 / 月或 $150 / 年**：固定可改的 slug 与去角标（门禁页与邀请卡）；口令、邮箱邀请名单、一次性邀请；180 天结果留存、版本比较、导出、3 位只读 reviewer；50 GB / 月。更多流量只卖预付包（50 GB / $10），不默认后付——开发者把链接发出去之后控制不了访问量，任何后付费都让「分享」变成财务风险。

**收款**：Stripe（信用卡 + 支付宝），要境外主体（§9）。主体落地前不收钱，两个产品在控制台里如实写「尚未开放」；「怎么活」写在 README 里——开发者对免费工具最怕的是跑路。

固定成本：一台香港边缘、控制面、对象存储、邮件服务商、两个域名，每月百美元量级。

## 7. 开源

不是预设，是三个问题的答案：**装它需要信任吗？** 需要——开发者装的是一个从自己电脑往外连的程序，这个品类全部开源客户端。**代码是护城河吗？** 不是——护城河是托管网络、域名信誉、微信申诉、滥用处置、整合体验、默认值正确，和积累下来的作品、试玩者与关注关系。**分发靠社区吗？** 靠——引擎社区做「一键发到 playtest.run」的插件，AI coding agent 通过 `playtest mcp` 直接调用。

**怎么开**：CLI、SDK、文档 Apache-2.0；边缘与控制面 AGPL-3.0（含推广与通知的代码——收款密钥、发信密钥、滥用阈值私有，部署形态公开），附一份 `compose.yaml` 自己一台机器跑通；商标政策：fork 不能叫 playtest；安全披露渠道。引擎插件只调公开协议、不链接 AGPL 服务端库；普通自托管无需商业许可；托管版与自托管版同一核心能力，日后不抽走。

**什么时候公开**：仓库从第一天按公开的标准写，但私有开发到 v1 在真机上成立再 flip public。

### 8.2 v1 的「完成」

- 一个没用过的开发者从安装到手机上打开自己的作品不到 60 秒；CLI 从命令到二维码中位不到 5 秒；发布成功的输出里有邀请卡的路径。
- Godot（线程与无线程各一）、Unity（预压缩）、Phaser、Vite 各一个真实导出物走上传路径零配置能玩，走隧道路径同样能玩；一个 socket.io 联机小游戏两台手机能对局。
- Cursor 或 Claude Code 通过 `playtest mcp` 发出一个链接，并把二维码和邀请卡贴回对话。
- 一张邀请卡在微信群里发出去，另一个人长按识别二维码进到门禁页、点「开始」、音频能播（Chrome / Safari / 微信各验一次），点名册上显示「来自邀请卡」。
- 一个玩家在门禁页留名并关注；开发者发第二版；玩家收到邮件（或浏览器通知），点进去，点名册上显示「来自通知」并标为回头的人。
- 一个玩家在广场关注广场；周一收到周报；周报里的作品点开就玩。
- 广场上一张推广位（运营者赠送）显示为「推广」，免费流顺序不受影响。
- 控制面停掉：作品、广场、邀请卡照常；关注登记得到那句如实的提示；控制面回来后队列里的确认信发出。

- 真实微信账号在 Android ≥ 6 台、iOS ≥ 4 个系统版本上，私聊 / 群聊 / 朋友圈打开门禁页并进入游戏；邀请卡在群里长按识别的成功率；腾讯对外链规范 §2.5 适用口径的书面答复。

- 发信域名的 SPF / DKIM / DMARC 通过，测试信在 Gmail、QQ 邮箱、163 不进垃圾箱。

## 9. 只有创始人能拍板的事

已定（2026-09-07）：语言选 Rust；匿名 24 小时链接进 v0.1；免费档门禁页带角标；「微信里点开就能玩」降为待验证假设并作为发布阻断；香港是工程手段不作卖点；上传与隧道一等公民；`--json` 与 `playtest mcp` 进 v0.1；免费档 10 GB + 匿名 1 GB / 24 小时 + 每 slug 每小时熔断；结果层用点名册句式。

已定（2026-09-08）：控制面用 `playtest.roviix.com`；地图与位置不进；广场进 v0.1（形态为告示板）；混合模式提前。

**已定（2026-09-09，创始人推翻上一版的三个判断，本文按方向 B 重写）：**

- **产品是一个地方，不是一根管子；不当实验推进，按完整产品交付。** 上一版的判断是「管子先做到最好，地方等私测数据再说」，理由是 2025 年五家公开平台的死法。重新看死因：Glitch 死于跑用户代码的算力成本加滥用，SIMMER 死于无熔断的分钟级账单，Replit 教育版死于算力加欺诈，itch 是支付通道对成人内容施压，Game Jolt 是审核动作粗暴——**没有一家死于发现页或社区本身**；而 playtest.run 从第一天就不跑代码、有熔断、不碰支付商敏感内容。另一边，「没人玩」是中英文社区里最常见的痛，管子解不了它，地方能。管子本身正在被 AI 编辑器内置分享商品化，五年后一根「游戏友好的管子」没有独立存在的理由。
- **玩家身份从「永远没有」改为「首次没有、之后自愿长出」。** 上一版把零门槛从「首次」外推到了「永远」，切断了关注、回访和一切网络效应。这一版的零门槛只管第一次玩；之后留名、关注都是可选的、都在玩之后。
- **「不承诺有人来」改为「我们努力带人来，并告诉你带来了多少」。** 上一版把它当作克制，它其实是在用户最痛的地方退场。广场从告示板改为俱乐部；推广位从「不做」改为透明限位；反馈从只给开发者看改为开发者可选公开。
- **代价明知**：微信整域风险随成功放大（§5）；内容审核从「举报即撤」变成日常运营；两个人里要有一个把时间从写边缘转到供给与社区上；商业化要等境外主体。

**还没定 / 只有创始人能给的**（缺一条，对应的那一环只能在本机绕着走）：

1. **境外主体与 Stripe 账号**（含支付宝）——决定推广与 Pro 什么时候开卖；此前控制台如实写「尚未开放」，运营者只能赠送推广。
2. **邮件服务商账号与发信域名的 DNS**（`notice@playtest.run` 的 SPF / DKIM / DMARC 在 Cloudflare）——决定关注通知在线上什么时候能发；本机用 `log` 实现验证全链路。
3. **GitHub OAuth App 的凭据放到服务器**（compose 已支持，空着就是不提供登录）——决定开发者头像、长期作品、推广购买资格什么时候可用。
4. **香港哪家云**（压测后定）。
5. **推广对大陆用户的法律判断**——境外主体向大陆开发者收费推广未备案的网页作品，需要一次真正的法律意见，不是产品能设计掉的。
6. **一个人的时间**转到供给与社区：每天有新东西上广场、举报有人看、周报有人读一遍再发。
