# playtest · 产品推演与设计

> 一条命令，把你手上这个能玩的版本放到别人面前，然后知道他们玩成了什么样。

> 2026-09-07 起草。本文是唯一产品定义。推演过程保留在文中，因为每个结论都要能回答「为什么不是另一个」；
> 方向变了直接重写本文，不留 changelog。市场调研的证据在 `docs/research/`，真机记录在 `docs/spikes/`。

## 0. 结论

先读这一节，其余各节是它的出处。

1. **起点是场景，不是隧道。** 开发者手上有一个能玩的版本，想立刻放到别人面前、并且知道结果。「隧道」只是把版本送过去的几种方式之一。
2. **交付两条路都做，都是一等公民。** **上传**（引擎导出的静态目录）与**隧道**（本地开发服务器、带后端或联机的游戏）。上传对玩家更快、笔记本合盖也在；隧道解决「不想构建、有后端」的那一部分。哪条路占多数不预判：游戏开发者手上多是导出目录，用 AI 写小东西的人手上多是 `npm run dev`；T4 在私测第一周就看。两条路共用同一种链接 `https://<slug>.playtest.run`、同一套对游戏有感的响应头。
3. **玩家零门槛，开发者一条命令。** 玩家不登录、不装东西、点开链接就能玩；开发者 `playtest ./dist` 或 `playtest 5173`，几秒钟拿到链接和二维码——「几秒」是写进验收、CLI 里打出来的数字，不是形容词。为微信分享优化，但「微信里点开就能玩」是待验证的假设（§5），不是承诺。
4. **名字里的 playtest 兑现在「知道结果」。** 多少人打开、多少人真的进到游戏、什么设备、加载哪里失败、玩到哪停下、说了什么。这是它和「静态托管」「隧道工具」的分界。**开发者因为托管来（本地能跑、传上去白屏，是十年不愈的高频痛），因为结果留下（送出去之后是黑箱，是近一年爆发的最深的痛）。**
5. **第一批用户在大陆，所以第一个边缘在香港；全球可用是底线。** itch.io 在大陆已被整域屏蔽，Vercel、ngrok、Cloudflare 以及 2025–2026 年新出的 Playset、The Gaming Nest、tunr 这一批全部架在境外托管网络上，微信里没有一家能用——这是缺口。但香港是工程手段不是卖点：用户只在乎「朋友点开卡不卡」，文案不说地理。产品不依赖任何需要备案的东西，英文可用。
6. **开源。** CLI 与 SDK 用宽松许可，边缘与控制面 AGPL 且可自托管；托管服务是生意。这是 §7 推出来的，不是预设。
7. **生死线。** 私测 14 天，若一半以上开发者不回来发第二个版本、或每个版本平均打开人数不到 5，说明「放到别人面前」这个痛不够痛，停。

**推演改变了最初设想的三件事**：最初想的是「游戏版的隧道 / 组网工具」，推出来隧道和上传是同一条命令的两条路；最初想的核心动词是「发布」，推出来是「知道结果」——发布是平台的事，我们做的是一次 playtest；最初边缘是为隧道而建，现在边缘首先是一个对游戏有感的分发点，两条路都从它出去。

**市场调研（`docs/research/`，13 条线）又改了四件事**：香港从卖点降为手段；「谁玩了」改为「玩成了什么样」——开发者要的是一面镜子，不是一份名单；时刻表里补上「让对方敢点开」；命令行与 AI coding agent 的入口被确认为「结果」这一类里唯一空着的格子。

**市面比直觉拥挤**（§2）：「上传构建拿链接」是红海，免登录出链接是行业常态；「结果」这一类有十几家，但没有一家以命令行为入口、没有一家做交付；「分享 localhost」围着 AI 编程用户冒出一批，认真的只有两家。每个零件都有人做，我们的机会在**组合**（同一条命令走上传与隧道，结果和交付是同一件事）和**几件没人做好的具体事**（上传时告诉你为什么跑不起来、改一行三秒上线、两条路都补游戏响应头、门禁页接手音频手势、点名册式的结果），不在任何单点。

## 1. 起点：人和时刻

### 1.1 谁

四类人，痛点相近、工具不同：

- **用 AI 写小东西的人。** 拿 Cursor、Claude Code 之类做出一个浏览器里能玩的东西——Three.js 场景、Phaser 小游戏、p5 草图、几个人联机的小房间。很多人不是游戏开发者，甚至不是职业开发者。手上是一个 `npm run dev` 跑着的目录，不一定知道怎么「构建」。他们的作品多数不是游戏（抽样里工具、微型 SaaS、生成器占近八成），不认「试玩」这个词；他们未必开终端，但一定在跟模型对话——AI coding agent 正在成为这群人的分发渠道。
- **Game Jam 参与者。** 48 小时做完，要上传给评委和别人玩。国外默认 itch.io，但 itch 在大陆已被整域屏蔽；国内 jam 用自己的站（机核 BOOOM、CiGA 的 GmHub），多要求 Windows / Mac 包、WebGL 可选。
- **独立与业余游戏开发者。** Godot、Unity、Cocos、Construct、GDevelop、PICO-8、Twine、Bitsy……导出一个 Web 目录，想发给几个人试。
- **创意编码与互动体验作者。** shader、生成艺术、WebXR、数据可视化玩具、课堂演示。

共同点：**产物是浏览器里跑的东西**；观众是具体的人（朋友、测试者、评委、学生），不是匿名大众；想要的是「现在就给你看」，不是「上架」。

### 1.2 六个时刻


| 时刻                         | 现在怎么做                              | 哪里疼                                                                                                             |
| -------------------------- | ---------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| **M1 · 手机上试一下**（开发中，自己一个人） | `--host` 后在手机上敲 `192.168.x.x:5173` | 手机和电脑不在一个网（公司访客 Wi‑Fi 隔离、手机走流量）；WebXR、陀螺仪、摄像头、WebGPU、Service Worker 都要 HTTPS，局域网 IP 是 HTTP；Windows 防火墙拦端口；每天都发生 |
| **M2 · 现在发给朋友看**（几个人，几分钟）  | 打包 zip 发过去；或临时部署                   | zip 对方不会跑；部署要注册、要 git、要配置、要等构建，流程一断就放弃，最后录个视频了事；链接在微信里点不开或很慢                                                    |
| **M2b · 让对方敢点开**（同一条链接，对方那一侧） | 发 exe / zip / 裸隧道链接                 | Windows SmartScreen 拦 exe；社交平台上的钓鱼 PSA 教人只点浏览器里能玩的 web build；ngrok 一类免费域名弹警告页、被公司和学校网络整域封。这一格在 2026 年还在恶化，而它正是 exe 和裸链接给不了、一个写着真人名字和作品名的页面能给的 |
| **M3 · 找一批人测**（5–50 人，几天）  | itch.io 加密码 + 表单 / Discord 收反馈     | 不知道多少人真的打开了、玩到哪、在什么设备上坏的；收回来的话是「挺好玩，有个 bug」，没有信息量；反馈散落、对不上版本；itch 在大陆打不开                                       |
| **M4 · 正式发布**（永久页面、被发现、变现） | itch、Steam、TapTap、微信小游戏            | 大平台的事，不缺我们                                                                                                      |
| **M5 · 带后端 / 联机的版本给人试**    | 部署服务器；或 ngrok / frp                | 静态托管做不到；ngrok 在大陆不稳、还给玩家弹警告页；frp 要自己有 VPS；联机测试真正的瓶颈是让四个人同时在线，没人解                                                 |


### 1.3 从时刻推出来的三件事

1. **时刻决定交付方式。** M2 / M3 的产物若是静态目录（引擎导出物），**上传**比隧道对玩家更快、不依赖开发者的电脑开着；M1 / M5 的产物是一个正在跑的进程，只能**隧道**；用 AI 写小东西的人手上常常只有跑着的进程。一个只做隧道的产品把 M2 / M3 做差了；一个只做上传的产品做不了 M1 / M5。两条路都要，而且要长在同一个命令、同一种链接、同一套响应头上；哪条路用得多由私测决定。
2. **玩家永远零门槛。** 六个时刻里玩家都是「被邀请的具体的人」，让他们注册或装软件就是在替开发者赶走他们。M2b 说的是零门槛的另一半：不光不用装，还得敢点。
3. **「知道结果」是产品，「送过去」是手段。** M3 是名字的来处：一次 playtest 的产出是「他们玩成了什么样」。托管和隧道工具都停在「链接能开」，我们从「链接能开」开始。开发者因为「链接能开」来，因为「不是黑箱」留下。

## 2. 市面上已经有什么

2026-09-07 查过一遍，同日用 13 条调研线复核（`docs/research/`）。这个市场比「游戏托管 + 隧道」的直觉拥挤得多，分六类看。所有「几步 / 多久」除 `docs/research/2026-09-07-hands-on-tunnels.md` 外都是从文档推的，不是实测。

### 2.1 六类现有解法

引擎自带的真机预览（Cocos、Godot、Unity Remote）只在局域网，HTTPS 问题依旧，只有自己能看——它们是 M1 的现状，不是解法。**两个真实的替代品不在表里**：录个视频发 B 站（免费、稳定、绕开一切兼容问题，代价是失去交互和行为反馈）；AI 编辑器内置分享（TRAE 已有产物链接，Lovable / bolt / v0 / Replit 内建发布——GitHub Spark 2026-08 关停的教训是强制登录杀死传播）。

### 2.2 离我们最近的几家，以及我们不一样的地方

- **Playset**：同一个愿景（一键 playtest），以**录像**为核心按分钟收费。它没有隧道、没有 CLI；在 HN、Product Hunt、Reddit、itch 论坛上找不到任何一条用户声音——它证明有人给这条路标了价，没证明有人在买。我们不做录像，但理由不是「重、贵、隐私敏感」：录像正在跌价到零（Slaytester 开源自托管、PGPT 免费 alpha、LoopKit beta 免费），卖它的人自己都在解决「录像太长」，网页游戏里技术上尤其贵（PostHog 在 WebGL 上禁用 replay）。**不做录像不是护城河，是不进泥潭。** 我们的角度也不是「比 Playset 轻」——Playloop、Bugnet、LoopKit 的免费档已经占了那个位置——而是「**在同一条命令里 + 不改一行代码就有第一层**」：他们全都不做交付，他们的第一层全以接 SDK 为前提。
- **Surge**：形状最像我们的上传路径（`surge ./dir`、免登录、不可变版本、回滚、统计），存在多年。差在游戏响应头、门禁页、结果、香港、同一条命令走隧道。任何对外表述都要能正面回答「我们和 surge 差在哪」。
- **tunr 与 uplink**：隧道侧认真的对手。tunr 已在卖反馈组件和 MCP，uplink 的命令行是给 agent 设计的。差别是它们不管游戏、没有上传、境外。它们开源免费，这一点决定了我们也必须是（§7）。
- **Clawcade 与 EdgeOne**：AI 人群与大陆两侧的相邻对手，各占一半。Clawcade 有 agent 入口没有引擎导出物；EdgeOne 有大陆节点但要备案、默认域在大陆只给 3 小时。
- **The Gaming Nest**：同形态小团队案例，不是威胁。约旦两人团队的阿拉伯语游戏社区，托管是获客功能、靠卖课变现；五步流程、整包重传、明说不配 COOP/COEP，HN / PH / Reddit 上零发布帖。对比它，哈希增量 + 一条命令到可玩链接是可度量的、明显的更好。

### 2.3 缺口与风险

**缺口**仍然存在，但要说准：没有人同时做到「链接对方敢点开 + 上传与隧道同一条命令 + 两条路都对游戏有感 + 玩家零门槛 + 点名册式的结果 + 命令行与 agent 入口 + 大陆可达」。**每一个零件都有人做得不差，我们的机会在组合和几件没人做好的具体事，不在任何单点。**

由此推出三条：

1. **上传这一路要做到最好，而不是当作已经输掉的入场券。** 具体落点全是可度量的空格：上传时说出为什么跑不起来、改一行三秒上线、终端二维码、门禁页接手音频手势、`--isolated` 一个开关就对且不打坏口令。
2. **「知道结果」的角度是「在同一条命令里 + 零接入的第一层 + 点名册句式」。** 录像、AI 总结不做（跌价到零，PlaytestCloud 全档白送 AI，Playloop 免费档自带 key 即可全开）；截图是标配要做。
3. 「playtest」是个描述性词，Playset、PlaytestCloud、Steam Playtest 都在用。我们的名字是完整的 **playtest.run**，不指望独占这个词，也不做 SEO 上的正面竞争。**这个品类在开发者社交平台上是隐形的**——`playtesting tool` 在 Hacker News 全部历史里只有 38 条命中，Playset、Playloop 等无一留下发布记录；冷启动渠道在 Discord、itch 社区、Godot / Unity / Cocos 论坛、国内 Jam 社群和 AI coding agent，不在 Show HN。

**缺口不等于需求。** 大陆做开放 Web 游戏的人比做小程序和原生的少得多，且没有规模数据（Cocos Web 导出使用率、国内 Jam 的 Web 提交占比都查不到）；「用 AI 写小东西的人」多，但作品多数不是游戏；Playset 的存在证明有人标了价，没证明有人在买；「结果」这一类有一半产品的价值在「帮你找到人」，而本文默认开发者已经有 5–50 个具体的人——「没人玩」在中英文社区里都比「发不出去」更常见，这个前提要在 §8 里直接问。所以 §8 的验证是产品的一部分，不是上线之后的事。

## 3. 产品

### 3.1 一条链接

`https://<slug>.playtest.run`——一个 slug 就是一个作品，永远指向它最新的版本。免费随机 slug（两个词加短数字，如 `brisk-otter-41`），登录后可以改成自己的名字。同一个 slug 下上传或隧道都行，切换对玩家透明。

不用路径（`playtest.run/u/xxx`）：引擎导出物里全是绝对路径，路径式一定坏。不加多余的标签（`xxx.play.playtest.run`）：这个域名本身就是给内容用的。

### 3.2 开发者这一侧：一个 CLI

只装一样东西：`playtest`。

```
playtest ./dist            # 上传：静态目录 → 链接 + 二维码
playtest 5173              # 隧道：本地端口 → 链接 + 二维码
playtest ./dist --watch    # 目录变了自动发新版本（配合引擎的导出）
playtest login             # 浏览器里 GitHub 登录一次，之后不再问
playtest ls / rm / open    # 我的作品
playtest … --json          # 机器可读输出、日志走 stderr、分层退出码——给脚本和 agent 用
playtest mcp               # 作为 MCP server 跑：Cursor / Claude Code 里一句「把这个发给朋友」就出链接和二维码
```

第一次运行不登录也能拿到一个 24 小时的匿名链接——免登录是 M1 的要求，手机上试一下不该先注册；要保留、改名、看结果才登录。它同时是 GitHub 登录在大陆间歇失败时的兜底（§5）：第一次必须在任何登录之前就成功。终端里直接画二维码，手机扫码就是 M1。

**「几秒」是数字，不是形容词。** CLI 结束时打印本次从敲命令到出二维码的耗时；验收 P50 < 5 s（§8）。这只在单静态二进制的前提下成立——不走 npm、不依赖系统 ssh：npx 一族的第一次都花在下包上（`bore-cli` 解包 10 MB，`localhostvibe` 一条命令拉 130 个包），kshare 把「Thirty seconds later」当卖点写在 README 第一屏。§4.7 选 Rust 单二进制，这是它最直接的理由。

**入口不只是终端。** 用 AI 写小东西的人未必开终端，但一定在跟模型对话；tinyfi.sh 把自己做成 agent skill、uplink 的命令行是给 agent 设计的、tunr 带 MCP server、Clawcade 让人从 Claude 里直接发布——AI coding agent 正在成为这群人的分发渠道。所以 `--json` 和 `playtest mcp` 进 v0.1：MCP 只是一个 stdio 壳，暴露「分享端口、上传目录、列出作品、看这一版的结果」四个工具，把链接和二维码贴回对话里。

CLI 之外的形态——桌面托盘应用（给不用终端的人）、引擎导出插件（Godot / Unity 的后构建钩子）——开源后希望社区做，我们先把 CLI、MCP 和文档做好。

### 3.3 玩家这一侧：门禁页

玩家点开链接，先看到我们渲染的一页，同一个 URL、不跳转：**「某某 邀请你试玩《作品名》· v7」** 和一个「开始」按钮。它不是 ngrok 那种警告页，它是产品的一部分：

- 它是这条链接的**信任凭证**（M2b）：一个写着真人名字和作品名的页面，正是 exe、zip 和裸隧道链接给不了的东西。2026 年递出去的东西越来越难被点开——SmartScreen 拦 exe、钓鱼 PSA 教人只点 web build、免费隧道域名被公司和学校网络整域封；门禁页是对方敢点开的理由。
- 「开始」这一下点击就是浏览器要求的**用户手势**，之后游戏的音频能播——网页游戏最常见的坑（有作者的两个游戏「在每一台 iPhone 上都是静音的，没有一个玩家报告过」）。前提待 spike：user activation 按文档记，如果点击之后是导航到新文档或跨源 iframe，手势不一定带得过去；验证不过就改成同文档 DOM 替换。
- 它是**会话的起点**：种一个本站 cookie，从这里开始算「这一次打开」；
- 它是**版本的告示牌**：玩家知道自己在玩第几版，反馈就对得上版本——「testers paste screenshots into Discord with "it crashed lol", you can't tell which build they were on」；
- 它是**举报入口**，也是能力检测失败时「这个作品需要在系统浏览器里打开」之类提示的位置；
- 隧道那头的电脑不在线时，它变成「开发者的电脑暂时不在线，上次在线 12:40」，而不是超时。

**三条硬线，否则它就是第二个警告页**：门禁页只在顶层文档导航上渲染（`Sec-Fetch-Dest: document`）；子资源、API、WebSocket upgrade **永不返回「200 + HTML」**，要么给资源本身要么给 403；**不存在绕过它的请求头**——如果需要一个 `X-Playtest-No-Gate`，说明门禁站错了位置。判据是请求语义，不是 User-Agent。反面教材是 pinggy：靠 UA 猜访客是不是浏览器，对每个没带确认 cookie 的路径都回 200 + 15 KB HTML；一个 Phaser 导出物入口 HTML 843 字节、真东西是 1.2 MB 的 JS，拿到 HTML 的浏览器不报网络错，最好是一个看不懂的语法错，最坏是白屏加沉默——在游戏里 200 比 404 坏得多。

标题按作品类型切换：识别到 Godot / Unity / Phaser / Cocos 等引擎导出物用「邀请你试玩」，其余默认「邀请你体验」——用 AI 写小东西的人多数做的不是游戏，不认「试玩」。开发者可以在命令里改这个词。

一次点开在 24 小时内不再重复出现——这是实验参数不是结论（ngrok / zrok 是 7 天一次，itch 移动端是每次 launch），私测里量 `门禁页 → 开始 → 首个资源 → 首帧` 各段的转化后再定；开发者可以选「每次都出」（正式测试要认人）或「不出」。整页不超过几 KB、不引第三方脚本、1 秒内出现，像作品封面不像安全告警。分享出去时服务端直出标题、描述与封面的 Open Graph 元数据——Discord、iMessage、Telegram 会抓；微信对未备案域名的抓取没有承诺，尽力而为（§5）。

免费档与匿名链接的门禁页底部带一行小字角标「由 playtest.run 提供」，付费档可去掉。为什么带：它是这个产品唯一一处能被玩家看见的名字，也是将来最自然的收入杠杆（ngrok 的路）；为什么只在门禁页不进游戏里：不改开发者的 HTML，作品画面里永远没有我们的东西。

### 3.4 知道结果：最小集

不做分析平台。5–50 个具体的人不构成统计——200 个玩家的数据仍充满噪声，A/B 每变体要 200–300 人。所以这里没有「流量」「留存率」「漏斗」，只有**计数和点名**：「这 3 个人停在第三关」，不是「37% 流失」。开发者要的是一面镜子，不是一份名单——他们已经在土法自建这面镜子（「I log a few events (first click, time to first real action, where ppl drop)」），而没有一条原话要求知道玩家是谁。围绕「这一版有人玩了之后我想知道什么」列最小集，分两层：

**不用改游戏一行代码就有的**（来自门禁页与边缘）：多少人打开；多少人点了「开始」之后**真的进到游戏**——门禁到首帧之间掉了几个（网页游戏门户实测有四成人在加载完成前就走了，这是最大的一段流失，边缘看得见，是第一层里最值钱的一条）；每一个人的设备与浏览器（网页游戏里「每个平台上的每个浏览器本质上是一个独立平台」）、停留多久（只给中位数和逐条明细，不给平均值）、资源哪里加载失败（404、中断的下载、错的 MIME）、是不是回头的；来自哪里（微信 / 浏览器 / Discord）尽力而为——referrer 本身脏，微信常不发；而且会话从「开始」那一下算起，那一下的 Referer 永远是门禁页自己，所以真正的来源要由门禁页放进表单带过去（2026-09-08 实测才发现，此前所有人都「来自其它」）。

**加一行脚本才有的**（可选 SDK `playtest.js`，上传模式里可以勾选自动注入）：JS 错误与堆栈（第一优先，WebGL 崩溃自己复现不出来）；加载分阶段用时；开发者自定义事件 `playtest.event("level_done", {level: 3})`，文档只教一种用法——标记进度里程碑；**最后一个事件与最后一次输入的时间戳**——「开始了但没做完」是 5 个人身上就能数出来、且能代理一份问卷的指标（Zachtronics 的实证：玩家 bounce 掉的谜题恰好是通关者自述「太难」的谜题）；右下角一个反馈按钮——玩家写一句话，附当前画面截图、设备、版本、进入多久。截图：上传模式由边缘注入时可以在游戏脚本之前强制 `preserveDrawingBuffer`，默认能截到；隧道模式开发者自己加 SDK，尽力而为。反馈不设必填项——每加一个必填字段填写率就掉一截。

开发者在 `playtest.roviix.com/console/` 看到的**不是仪表盘，是点名册**。每版一段话：

```
v7 · 9 月 5 日 14:20 · 「改了新手引导」
8 个人打开，6 个人进到游戏（2 个在加载时走了——其中 1 个微信 Android，game.wasm 下到 61% 中断）
3 个人玩了 5 分钟以上，2 个人回来过第二次
1 个 JS 错误撞了 3 次（TypeError: Cannot read 'x' of undefined @ main.js:412）
1 条反馈：「不知道要按哪个键」· 附截图 · iPhone 15 Safari · 进入 47 秒
```

点开是这一版的会话列表，每人一行，可按「停留最短」排序——排在最前面的人就是你要看的人；反馈单独一条流。不画图表：5–50 个点的柱状图只会显得空。手机上也能看。

不收集的：玩家身份（昵称是自愿填的）、跨站追踪、精确位置。数据默认保留 90 天，写在隐私声明里。**数据由我们收、隐私责任在我们的声明里，开发者不用自己碰 GDPR / PIPL**——itch 用户想要分析的原始诉求就是「接 GA4 就要自己扛合规，小团队扛不起」，这是卖点，不只是合规。

### 3.5 版本

每次上传就是一个版本（`v1, v2, …`），不可变；`<slug>` 永远指最新；控制台一键回滚就是把指针指回去。会话与反馈按版本归档。上传时可以附一句「这版改了什么」，门禁页上显示。上传按文件内容哈希增量——改一行代码只传一个文件，几秒完成。隧道模式没有版本概念，只有「在线 / 离线」和会话。

### 3.6 谁能玩

三档：任何拿到链接的人（默认）；要口令；只允许邀请名单（链接带一次性令牌，或玩家填邀请码）。都在门禁页完成，玩家不需要注册。这三档是入场券（itch 有四档，已包装成「Limited Playtests」）。**口令 / 邀请名单与 `--isolated` 的跨源隔离要在设计阶段对齐**：itch 上开了 SharedArrayBuffer 的作品加口令后在 Safari / Firefox 的弹窗里 404，这个 bug 活了两年。

### 3.7 明确不做

- 发现、榜单、商店、给开发者的变现——那是 itch / Steam / TapTap 的事。我们做「把这个版本给这些人」，不做「让世界找到它」。2025 年的反例够多：Glitch 关停托管、SIMMER 死于 DDoS 账单、Replit 砍掉 Teams for Edu 与 Bounties、itch 被支付通道逼着下架内容、Newgrounds 25 年后仍亏损——公开大厅的审核、排序公平、反作弊、支付商压力不是两人团队能扛的，而且会把境外不备案的内容域推到监管正面。
- 孵化、评审、招募测试者的双边市场——「帮你找到人」是另一个产品。
- 原生包分发（APK / IPA / TestFlight）。
- 游戏引擎、编辑器、云端构建。
- 通用分析平台：热图、漏斗、分群、A/B、DAU / MAU / 留存曲线——只做 §3.4 那个最小集。
- 画面录像：正在被开源工具白送，在网页游戏上技术上尤其贵；截图不在此列。
- AI 总结：PlaytestCloud 全档免费送，Playloop 免费档自带 key 即可——不构成护城河，5–50 人的量也没东西可总结。
- Mesh VPN、点对点组网、任何要玩家装客户端的东西。
- 给玩家的评论区、社区、账号体系。
- 地图与任何基于位置的东西（2026-09-08 定）。位置回答不了 §1.2 五个时刻里的任何一个问题：开发者知道朋友在哪、不知道也改不了游戏；§3.4 的「来自哪里」指的是微信 / 浏览器 / Discord 这种他能行动的渠道，不是坐标；玩家零门槛意味着不能弹定位授权，§3.4 已承诺不收集精确位置。曾有把一张真实地球夜水图带进来的想法，那张图成立的前提是「位置就是内容」，在这里不成立。边缘选址（§4.4）要看玩家国家分布，那是控制面的一张内部统计表，从边缘连接侧按国家计数，不进玩家数据也不进产品。
- 大陆境内服务器与备案（§5）。
- 帐号托管、代跑、任何要执行用户代码的东西——我们只分发静态文件和转发连接，**从不运行用户的代码**。这一条同时是安全边界和滥用面的上限。
- 改写开发者的字节：不注入、不改写 URL、不改响应体（SDK 是开发者勾选的，不是我们塞的）。这是一条能用哈希对拍验证的承诺，写进 README。

## 4. 架构：从产品倒推

### 4.1 两个域名，各管一件事

- `*.playtest.run`：**只放玩家看的东西**——门禁页、上传的构建、隧道转发。根域只放一页介绍和跳转，**没有登录**。
- `playtest.roviix.com`：开发者控制台（`/console/`）、API、文档；SDK 由边缘在作品自己的域上同源提供（§4.6）。

为什么是 `roviix.com` 的子域而不是买一个 `playtest.sh`（2026-09-08 定）：分开的两个理由——cookie 隔离与「品牌不陪葬」——只要求「另一个可注册域」，`roviix.com` 已经满足；roviix 是制作者、playtest 是它的产品（KICKOFF §1 2b），子域恰好是这个关系的字面表达；`.sh` 一年 600 元只买到一个短一点的名字。控制面的主机名是配置层面的事，将来要换不影响任何玩家链接。

为什么分开：任何用户的作品都是一个能跑任意 JS 的源。登录如果也在 `playtest.run` 下，一个作品就能对父域种 cookie 去干扰控制台会话，SameSite 也把兄弟子域当同站。分开之后互不相干。再申请把 `playtest.run` 提交进 Public Suffix List——**但不依赖它**：PSL 对新域名有「数千活跃用户」量级的门槛，pico.sh 被拒过；进不去之前，兄弟子域之间的隔离靠自己做（内容域不种父域 cookie，门禁页只认自己 slug 的 cookie，控制台不在内容域）。另一个原因见 §5：内容域在微信里的风险比品牌域高得多，品牌域不能陪葬。

泛域名：一条 `*.playtest.run` 解析加一张 DNS-01 签发的泛域名证书覆盖无限个 slug，不用逐个建记录、逐个签证书。约束是 slug 只能一级（`a-b.playtest.run` 可以，`a.b.playtest.run` 不行），63 字符以内。

### 4.2 上传路径

```
CLI：遍历目录 → 每个文件算内容哈希 → 问 API 哪些哈希没见过 → 只传这些（并行、可续）→ 提交清单 → 得到 v7
边缘：按清单服务：路径 → 哈希 → 对象。对象不可变、长缓存；HTML 不缓存。边缘本地盘做热缓存，对象存储做源
```

对象存储放香港区域的 S3 兼容服务；Cloudflare R2 出网免费但大陆访问差，不用作玩家直连的源。

对游戏有感的地方都在边缘的响应头里：`.wasm` 给 `application/wasm`（流式编译需要）；目录里有 `.br` / `.gz` 预压缩产物就按 `Accept-Encoding` 直接给并加 `Content-Encoding`（Unity 导出物默认这样，服务器不配就白屏）；`--isolated` 一开就加 `Cross-Origin-Opener-Policy: same-origin` 与 `Cross-Origin-Embedder-Policy: require-corp`（Godot 4 线程导出需要 SharedArrayBuffer，没这两个头直接报错；Godot 4.3 起官方推荐单线程导出，这个需求在下降但没消失——线程版能把加载从 30 秒降到 5 秒并消除音频卡顿）；SPA 回退可选；支持 Range。这些是开发者自己配 Nginx 时最烦的部分，也是通用托管不管的部分。**同一套头对隧道路径同样生效（§4.3）。**

**上传那一刻做检查，用人话说出来。** 服务端此刻已经拿到全部文件，而全行业没有一家在这一刻做任何检查——Unity Play 给「Network Error: Unknown Error」和裸 500，itch 的官方回复是「open the browser console」，有人为此「spent 4 hours on this」。能查而没人查的：Godot 导出物是不是线程版（是的话「这个构建需要 `--isolated`，帮你开还是你重新导出？」）；`index.html` 在不在根；Unity 的 `.br` 与 Decompression Fallback 是否冲突（一个要服务器配头、一个要服务器不配，二选一）；`.pck` / `.data` 有没有漏；单文件是否超限。这一格是「一条命令」之外最大的体验差距。

单版本大小、保留版本数、每月流量按档位限制（§6）。

### 4.3 隧道路径

先列要求：从开发者机器**只出不进**（家里、公司、校园都在 NAT 后面）；走 443 且看起来像 HTTPS（公司代理、校园网只放这个）；一条连接上复用很多玩家连接；WebSocket 要原样过（浏览器联机几乎都是 WS）；断了自动重连；边缘要能计量；不依赖用户机器上有 ssh。

候选与取舍：

- `**ssh -R**`：依赖系统 ssh、每个用户占端口、按 Host 复用做不了、计量做不了。淘汰，虽然 localhost.run 就是这么起家的。
- **裸 TCP + TLS + 多路复用**：公司代理只放 HTTP CONNECT 时要多做一层；收益不比 WSS 大。淘汰。
- **HTTP/2**：只有客户端能开流，而这里是边缘要为每个玩家连接向开发者机器开新流，方向反了。淘汰。
- **WebSocket over TLS + yamux 多路复用**：凡是 HTTPS 能通的地方都能通；每个玩家连接一条 yamux 流。缺点是单条 TCP 上有队头阻塞——一个 50 MB 的 wasm 下载和联机消息挤一条 TCP 会互相拖累。**v0.1 用它**，因为上传路径已经把大文件从隧道里拿走了，隧道上剩下的多数是小请求和 WS。
- **QUIC**：双向开流、没有队头阻塞、笔记本切 Wi‑Fi 时连接迁移不掉线；但 UDP/443 在一部分网络被掐，必须保留 WSS 回退。**v0.2 加**。
- **WebRTC 直连玩家**：省我们的带宽，但浏览器侧要 Service Worker 配合、联机流量还是要走信令、复杂度高。不做。

边缘处理 HTTP：按 Host 找到隧道会话，开一条 yamux 流，把请求以 HTTP/1.1 写进去，把响应流回玩家；收到 101 之后就是双向拷贝字节，WebSocket 天然透传。CLI 收到流后连 `127.0.0.1:<port>` 双向拷贝。默认把 `Host` 改写成 `localhost:<port>`，原值放 `X-Forwarded-Host`——Vite 6.0.9 / 5.4.12 之后默认 `server.allowedHosts` 只放行 localhost，带着 `xxx.playtest.run` 进来直接 403；Next、webpack-dev-server 同理。HMR 的 WebSocket 需要一行配置（`server.hmr.clientPort = 443`），CLI 检测到 Vite 时打印出来。

**响应头在隧道路径上也补。** 边缘对隧道回来的响应做和上传路径同样的修正：`.wasm` 没给 `application/wasm` 就补；`--isolated` 加 COOP/COEP；预压缩按 `Accept-Encoding` 处理。dev server 不发这些头（Vite 不发 COOP/COEP，`python3 -m http.server` 一个都不发），而真机试用的十个竞品隧道没有一个会补——Godot 4 的开发者敲 `playtest 5173` 和上传一样会白屏。**除响应头之外，响应体一个字节不动**：不注入、不改写 URL（kshare 对 HTML / CSS / JS 做原始文本替换，对 1.2 MB 的 bundle 和 `.wasm.br` 是灾难）。

生命周期：CLI 退出或电脑休眠即离线，门禁页显示离线与上次在线时间；重连 1 s → 30 s 指数退避加抖动，网络切换立即重连一次；一个 slug 同时只绑一条隧道，新的挤掉旧的。保活走 WSS 控制通道，不往 `127.0.0.1:<port>` 打探测——有的隧道每 30 秒往开发者的 dev server 发一个 `HEAD /`，污染他自己的日志。

实现时补定的三条（2026-09-07，`common/src/tunnel.rs`）：**被挤掉要能分辨**——旧连接收到 WebSocket 关闭码 4001，旧令牌进边缘的驱逐名单，拿它重连一律 409，CLI 据此退出而不是重试，否则两个进程会互相挤到天亮；**离线判定在边缘**——CLI 每 20 秒一个 ping，边缘 60 秒没收到任何帧就当离线并记「上次在线」，边缘重启则 CLI 那边 1 秒后重连、链接不变；**令牌活不过作品**——匿名作品到期前签出的令牌，`exp` 被截到作品到期时间，因为边缘只验签不回源，否则作品到期后隧道还能开一小时。作品既上传过又开过隧道时，隧道离线就退回上传的版本而不是离线页——对玩家更有用。

隧道不适合的场景要在 CLI 里说出来，而且要算出数字：大体积静态资源经隧道，瓶颈往往先出在隧道服务商而不是家宽（免费隧道实测 5.9 Mbps，30 MB 一个玩家等 41 秒）；我们不限速，但家宽上行仍是上限。CLI 看到目录体积就按实测吞吐算给开发者看：「你这个目录 32 MB，隧道模式下一个玩家大约要等 45 秒，十个人同时进来会更久。建议 `playtest ./dist`——上传一次，玩家从边缘直接拿。」没有一家把免费档的真实吞吐写在首页，这本身就是差异。

### 4.4 边缘放哪

玩家和开发者在哪，边缘就在哪附近。第一批用户在大陆，边缘放**香港**：不需要备案，是大陆玩家能直接到的最近的境外。这是工程手段不是卖点，文案里不出现地理。

延迟不是地理决定的，是回程线路决定的。2026 年的公开测速里，同样标称香港：CUG / CMI 优化线全国三网平均 34–56 ms，普通国际回程（TATA / Arelion）全国平均 194–319 ms 且绕美欧；有用户对阿里云香港轻量实测「就是个展示网页 ping 300~400ms」，云商工单答复峰值带宽不作承诺。**「大陆到香港 30–60 ms、上传路径接近国内 CDN」是压测的验收目标，不是事实**；隧道路径联机流量绕两次边缘的额外延迟同样待测（休闲和回合制大概够用，竞技射击不够——这是工程推断，不是用户研究）。

所以选云之前压一周：电信 / 联通 / 移动 × 至少两个城市 × 家宽与 4G × 白天与 20:00–23:00 晚高峰 × 微信 WebView 与系统浏览器；每分钟记 TCP / HTTPS 的 p50 / p95 / p99、丢包、首字节、30 与 100 MB 持续下载；隧道单独记玩家→边缘→开发者的 WebSocket 往返；保存 traceroute 看有没有绕日本、新加坡、美欧。「全国 p95 < 80 ms、丢包 < 1%」这类写成待实测的 SLO，达不到就如实写进文档。结果进 `docs/spikes/`，此前本文不出现供应商名和毫秒数。第二个区域（新加坡或东京服务东南亚与日韩，美西服务北美）等有那边的用户再加，加法是控制面记住 slug 在哪个边缘、GeoDNS 就近。

### 4.5 控制面

`playtest.roviix.com`（控制面 API 与控制台同一主机），一个关系库：用户、slug、版本、对象清单、隧道授权、会话、反馈、用量。三类客户端：CLI（设备授权流程——终端给一个码，浏览器里确认，像 `gh auth login`）、控制台、边缘。

库在 v0.1 用 **SQLite**（单文件、进程内、`compose.yaml` 里少一个容器），换 **Postgres** 的条件是出现第二个写入节点或需要托管备份与并发写入——按 20 个开发者的私测和一台香港机器的规模，这两个条件都不会在 v0.1 出现。为什么不一开始就 Postgres：自托管的人一台机器跑通是 §7 的承诺，多一个数据库服务就多一处会坏的地方；代价是 SQL 只用两边都有的子集，迁移时改的是连接层不是查询。但自托管是背书不是约束：目标用户几乎没人会自建，不为它牺牲托管版的任何功能。清单本身不在库里：控制面把每个版本的清单和「当前版本」指针写进对象存储，边缘只读对象存储（§4.2），控制面挂了已有链接照常能开。

边缘和控制面之间尽量松：CLI 拿到的是控制面签发的**短期签名令牌**（含用户、slug、档位、配额、有效期），边缘只验签名不回源；用量在边缘按会话累计，每 60 秒批量上报；撤销由控制面推给边缘（发布订阅或短周期拉取），不能只等令牌过期。这样边缘可以多地部署、单独扩，控制面挂了已有的链接照常能开。

### 4.6 SDK

`playtest.js`，几 KB，无依赖：捕获错误、加载用时、自定义事件、反馈按钮；只往 `playtest.roviix.com` 发，不种第三方 cookie。脚本由边缘在作品自己的域上同源提供（`/_playtest/sdk.js`），开发者加一行 `<script>` 即可；上传模式的自动注入留给 v0.2，因为它要改开发者的 HTML。SDK 的存在与否不影响 §3.4 第一层数据。

### 4.7 语言与实现选择（2026-09-07 已定：Rust）

CLI、边缘、控制面都用 **Rust**，一个 Cargo workspace（`cli/`、`edge/`、`api/`、共享类型在 `common/`）。控制台与 SDK 是 TypeScript。

为什么不是 Go：两个选项都对，性能在这个规模下不是判据；Go 的优势是开工速度和国内基础设施贡献者池，Rust 的优势是更小的二进制与内存占用、更强的类型约束。创始人的判断是**开发成本不是约束，要体验和健壮性更好的那个**，且团队近期手感在 Rust 上。隧道生态在 Rust 这边同样够用：tokio、hyper、quinn（QUIC）、`yamux` crate（libp2p 维护）、rustls-acme。三平台交叉编译 Rust 也能做，只是比 Go 多几步。

边缘 TLS（2026-09-07 已定：**前置 Caddy**）：泛域名证书只能走 DNS-01，需要 DNS 服务商的 API；`rustls-acme` 只做 TLS-ALPN-01，签不了 `*.playtest.run`，进程内做要换 `instant-acme` 自己实现挑战。v0.1 用带 Cloudflare 插件的 Caddy 挡在边缘前面自动签发与续期（`deploy/`），边缘进程只说明文 HTTP；DNS 放 Cloudflare 但只做解析不做代理（代理才是大陆访问差的原因）。什么时候收回进程内：有第二个边缘区域、或 QUIC 上线要自己拿证书时。本机开发阶段边缘走明文——Chrome 与 Firefox 把 `*.localhost` 当作安全上下文，HTTPS 才有的 API 在本机也能试。

### 4.8 滥用与安全

公网托管用户内容天生是钓鱼与恶意软件的渠道，ngrok、trycloudflare 都被用烂过。分层：

- **我们从不运行用户代码**（§3.7）：没有服务端执行面，滥用上限就是「托管一个坏页面」。
- 创建作品要 GitHub 登录；匿名链接只活 24 小时、带角标、限流量。每账号活跃 slug、月流量、并发玩家有上限。
- **额度是双重上限**：月配额挡长期滥用，**每 slug 每小时流量熔断**挡 DDoS——在边缘本地判定，超限把 slug 转成一页静态说明，不依赖控制面回源（控制面被打满时正是最需要熔断的时候）。SIMMER.io 2025-04 是被分钟级 DDoS 账单打死的，有 billing alert 也没来得及，创始人删掉自己的存储桶止血；月配额在那个时间尺度上完全无效。
- 门禁页本身就是反钓鱼的：钓鱼页最怕多一次点击和一个写着别人名字的告示牌（packetriot 运营者原话：给免费账号加一个门户页「very effective at preventing abuse」）。但门禁页只拦顶层导航、不拦资源（§3.3）。
- slug 黑名单（`login`、`admin`、`wechat`、`alipay`、品牌词与常见钓鱼词）；举报 → 下架 → 令牌撤销 → 边缘立即断；处理时限写进服务条款。
- 控制台与内容域彻底分离（§4.1）；PSL 申请但不依赖。
- 隧道模式提示开发者：暴露开发服务器等于暴露源码和 `/@fs/` 这类接口，正式测试请用上传。

## 5. 大陆特有的现实

- **微信是第一批用户最可能的分发渠道，也是最大的不可控——而且比最初想的更直接。** 《微信外部链接内容管理规范》（2025-10-23 生效）§2.5 把「H5 游戏、测试类内容：以游戏、测试等方式，吸引用户参与互动的……网页小游戏」列为常见违规情形，**没有「诱导分享」的限定**；§2.18.4 把「未按照法律法规规定履行备案手续或难以追溯网站运营者真实身份的网站链接」列为风险链接；§3.2.2 把多域名规避列为对抗行为；§3.2.3 把「微信内展示效果和其他浏览器实质性不一致」列为对抗。实际执法多针对病毒式营销 H5，但规则文字给了腾讯全部裁量权。**所以「微信里点开就能玩」是待验证假设，不是承诺。** 文案写「为微信分享优化」；v0.1 发布前用真实微信账号在 Android ≥ 6 台、iOS ≥ 4 个系统版本上测私聊 / 群聊 / 朋友圈的门禁页与实机游戏，并向腾讯客服书面确认 §2.5 对非营销、私人 playtest 链接的适用口径——这是 §8 的发布阻断条件，结果进 `docs/spikes/`。「微信是主渠道」本身也是假设，由 T5 验证。
- **封禁机制与对策。** 官方可处理单链接、域名或 IP；整域处理的明文条件是「同域名下大量链接违规，经处理后仍未及时、有效整改」，不是一次举报连坐根域。对策：内容域与品牌域分开（品牌不陪葬；PSL 不能指望）；门禁页、举报、快速下架把违规概率压低；被处理后 24 小时内提交申诉（官方阶梯：半年内第二次违规 12 小时、第三次 1 天、第四次起 1 周；没有恢复 SLA，「24 小时」是我们提交的时限不是恢复的承诺）；**不做域名轮换、短链套娃**，那是对抗行为。门禁页在微信里给「在浏览器中打开」的提示，但不能只给这个——必须先给可玩的路径，否则触及 §3.2.3。
- **未备案的其他代价。** 朋友圈分享未备案一级域名有频次限制，达到次数后再分享仅自己可见；微信 JS-SDK 安全域名必须备案且不接受短链——分享卡片只能服务端直出 Open Graph 元数据尽力而为，不能承诺微信会抓标题和封面。
- **微信内置浏览器的能力不可靠。** Android 是 XWeb（版本与 Chromium 的对应没有官方资料），iOS 是 WKWebView。SharedArrayBuffer、WebGPU、全屏、横屏锁定都不能假设可用（iPhone 不支持全屏 API 和横屏锁定）。门禁页用**能力检测**（`crossOriginIsolated`、`SharedArrayBuffer`、`navigator.gpu`）而不是 UA 黑名单，检测失败才提示换浏览器；文档建议 Godot 用无线程导出。首屏不依赖 WebGPU、Wasm 线程、Service Worker、全屏、横屏锁定或摄像头。
- **整个域名被墙**是存在性风险：内容出问题可能在国家层面被封，那时大陆玩家全部打不开。除了内容治理和快速响应，没有技术对策。如实写在这里，不假装能解。
- **不落大陆。** 境内服务器要备案、要主体、要承担内容责任，用户内容平台的备案基本不可能。香港边缘加境外主体是唯一现实路径；付费如果做，支付宝可以接境外主体。
- **登录。** GitHub 在大陆是**间歇可用**（GreatFire 2026-09：最近 55 次有效测试 67% 受干扰；OONI 2026-07 至 09 中国探针 76 条里 41 anomaly、7 failure），且不能假设每个目标用户都有账号——AI 新手、Cocos / Construct 作者未必有。所以匿名 24 小时链接必须在任何登录之前把第一次完整跑通；GitHub OAuth 是可失败、可重试的增强路径，失败时已上传的作品不消失、错误信息说清楚。微信登录要开放平台企业主体，手机号要短信费——都不在 v0.1。

## 6. 成本与商业

变动成本是带宽。香港出网约 $0.1 / GB 是合理的中位基线（Bunny 亚洲 $0.03 到阿里云香港 ECS 直出 $0.153 之间；协议开销与重传再加 5–15%）：一个 30 MB 的 Unity 导出物被玩 1000 次约 30 GB、3 美元——未计回源、存储、请求、滥用。

**免费档**：登录账号每月 **10 GB** 硬上限、3 个活跃 slug、保留最近 5 个版本、每 slug 并发 50 人、结果保留 30 天；匿名链接 **1 GB / 24 小时**（约等于 30 MB 构建完整打开 33 次）。到上限硬停、不产生账单，玩家看到的是一页说明不是超时。**双重上限**：月配额之外，每 slug 每小时流量熔断在边缘本地判定（§4.8）。为什么是 10 GB 不是 20 GB：1,000 个免费账号满额 20 GB 在 $0.10 / GB 下是每月 $2,000，超过「固定成本百美元」的叙事；10 GB 仍比 ngrok 的 1 GB 慷慨，接近 Netlify 新免费档（约 15 GB），足够一次 jam 或一轮 30 人的测试。邀请制私测期给 20 GB 观测真实利用率（每账号 GB 的 p50 / p90 / p99、匿名链接被爬取率、缓存命中率），公开前再定。免费托管的死法已经演示过两次（SIMMER、Glitch），The Gaming Nest 把它写成了自己的文案：「Free hosting without a hard per-account ceiling is not a business model — it is an open invoice.」

**收钱的是「认真做测试的人」**——从「随手给朋友看」变成「给发行商、客户、封闭玩家群做正式测试」这一个身份变化：固定可改的 slug 与去角标（专业）；口令、邮箱邀请名单、一次性邀请（私密）；180 天结果留存、版本比较、导出、几位只读 reviewer（可追溯）。更多流量只卖预付包，不默认后付——开发者把链接发出去之后控制不了访问量，任何后付费都让「分享」变成财务风险（Netlify 的 $104,500 账单、Replit 的计费事故都是这一类）。自定义域名后置（Surge 免费给，证书与客服成本高）。**v0.1 不收钱**——先验证 §8，有人主动问价再接支付；但「怎么活」要写在 README 里：开发者对免费工具最怕的是跑路（「I'd rather pay a few dollars for a service that will be around 5 years from now, than pay nothing and have to deal with churn」）。

固定成本：一台香港边缘、控制面（v0.1 SQLite）、对象存储、两个域名，每月百美元量级。

## 7. 开源

不是预设，是三个问题的答案：

1. **装它需要信任吗？** 需要。开发者装的是一个从自己电脑往外连、把本地端口暴露出去的程序。这个品类（cloudflared、frpc、rathole、bore、zrok）全部开源客户端，闭源反而是异类。
2. **代码是护城河吗？** 不是。frp 十万星没有妨碍 ngrok 收钱（ngrok 融资前已有 3 万付费客户）。护城河是托管网络（香港边缘、域名信誉、微信申诉、滥用处置）、整合体验（上传、隧道、门禁页、结果在一条命令里）、默认值正确（两条路的游戏响应头、上传时的检查）、和积累下来的作品与用户。护城河也不是「不做录像」——那是正在被开源工具白送的东西。
3. **分发靠社区吗？** 靠，而且不止一个社区。独立开发者在 GitHub 找工具；引擎社区（Godot / Unity / Cocos）自己做「一键发到 playtest.run」的导出插件，是花钱买不到的分发；AI coding agent 通过 `playtest mcp` 直接调用，是另一条。

**怎么开**：CLI、SDK、文档 Apache-2.0（宽松许可才能被嵌进引擎插件）；边缘与控制面 AGPL-3.0（欢迎自托管，拿去做托管服务的必须开源修改），附一份 `compose.yaml` 自己一台机器跑通；商标政策：fork 不能叫 playtest；安全披露渠道。托管部署的密钥、域名配置、滥用阈值私有，部署形态公开。**边界写清楚**：引擎插件只调公开协议、不链接 AGPL 服务端库，不受 AGPL 影响；普通自托管无需商业许可；托管版与自托管版同一核心能力，日后不抽走（Cal.com 2026 年转闭源的反弹说明回撤承诺比一开始不承诺更伤信任）。

**什么时候公开**：仓库从第一天按公开的标准写（无密钥、无内部引用、提交信息能读），但**私有开发到 v0.1 私测通过再 flip public**——不为省事，是为了公开那一刻 README 里说的每句话都已经在真机上成立。

## 8. 分期与验证

### v0.1 · 私测：一条命令到链接，两条路都通

- CLI：`playtest <dir>` 与 `playtest <port>`，终端二维码，匿名 24 小时链接，GitHub 登录，`ls / rm / open`；`--json` 与分层退出码；`playtest mcp`；上传时的导出物检查与人话报错；隧道模式对大目录按实测吞吐给出等待时间与上传建议；结束时打印本次从命令到二维码的耗时。
- 边缘：一个香港节点（云在压测后定）；`*.playtest.run` 泛域名证书；响应头逻辑（wasm、预压缩、`--isolated`、Range）对上传与隧道两条路都生效；隧道路径 WSS + yamux、Host 改写、WS 透传、离线页、响应体零改写；用量计量；每 slug 每小时熔断。
- 门禁页：标题（按作品类型切「试玩 / 体验」）、开发者、版本、开始、举报、离线态；只拦顶层导航、子资源永不 200 + HTML；能力检测与换浏览器提示；服务端直出 Open Graph 元数据。
- 控制面：设备授权、slug、版本与回滚、令牌签发、用量、举报入口。
- 结果第一层（含门禁到首帧的掉队人数）；错误上报与反馈按钮（只收文字）作为 SDK 的第一个版本。
- 控制台：作品时间线（每版一段话）、会话点名册、反馈流。手机可看。

**完成** = 一个没用过的开发者从安装到手机上打开自己的作品不到 60 秒，且 CLI 从命令到二维码中位不到 5 秒；Godot（线程与无线程各一）、Unity（预压缩）、Phaser、Vite 各一个真实导出物走上传路径零配置能玩，走隧道路径同样能玩；一个 Colyseus 或 socket.io 的联机小游戏走隧道路径两台手机能对局；Cursor 或 Claude Code 通过 `playtest mcp` 发出一个链接并把二维码贴回对话；门禁页点「开始」后音频能播（Chrome / Safari / 微信各验一次，记进 `docs/spikes/`）。

**发布阻断**（不满足不对外）：真实微信账号在 Android ≥ 6 台、iOS ≥ 4 个系统版本上，私聊 / 群聊 / 朋友圈打开门禁页并进入游戏的结果写进 `docs/spikes/`，并取得腾讯对外链规范 §2.5 适用口径的书面答复（§5）；香港边缘三网晚高峰一周压测记录写进 `docs/spikes/`（§4.4）。

### 留门但不推进

能力或结论留在这里，不打磨、不进一级导航，要做先改本文：

- **联机 playtest 的并发问题**：做浏览器多人游戏的开发者原话——「The bottleneck in multiplayer playtesting is never getting the build out — it is getting four people into the same lobby at the same time. A tester who turns up alone doesn't give you a weak signal, they give you a misleading one.」他愿意买的是「约定 20 分钟窗口、N 人承诺到场、同一 build、多视角时间对齐的回放」。这是隧道路径上唯一被用户明确说出「我今天就买」的需求，但它是一个完整产品，不是一个功能。只有 T4 隧道占比超过 30% 且出现两个以上联机作品时再评估。
- **作品简历页**：一个只读分享链接（`playtest.roviix.com` 下、带 token），展示版本、多少人玩过、中位时长、设备分布、反馈摘要，给发行商 Scout、jam 评委、老师看。发行侧已把数据化 playtest 当硬前置（Poki Playtesting、CrazyGames 两周 Basic Launch、Kepler「Demo > Video > Concept Art > Words」、TapTap 聚光计划要「以往玩家的测试反馈」）。受众仍是具体的人，不与 §3.7 冲突；v0.2 评估。
- **受控测试者池**：如果 §8 的定性问题显示多数开发者找不到 5 个人，「帮你找到人」是另一个产品，要另开假设验证，不是在这个产品里加一个大厅。
- **引擎导出插件**（Godot 导出预设、Unity 后构建钩子）：开源后优先让社区做，我们维护接口文档。
- **原生构建分发**：明确不做（§3.7），除非 Web 路径验证成立后有清晰的需求证据。

### 验证：14 天私测，20 个开发者

从 jam 社群、AI 编程社群和身边找 20 个真的在做东西的人（这个品类在 HN / PH 上是隐形的，别去那里找）。看八个数和一个问题：


| 指标                          | 目标        | 说明            |
| --------------------------- | --------- | ------------- |
| T1 安装到第一个链接                 | 中位 < 60 s；命令到二维码中位 < 5 s | 没做到就是 CLI 的问题 |
| T2 发过第二个版本的开发者占比            | ≥ 50%     | 回头才说明有用       |
| T3 每个版本的打开人数中位数             | ≥ 5       | 「放到别人面前」有没有发生 |
| T4 隧道 : 上传                  | 第一周就看     | 决定两条路的资源分配    |
| T5 来自微信的打开占比                | 记录        | 决定 §5 的优先级；也决定「微信是主渠道」这个假设成不成立 |
| T6a 反馈数 / 打开人数              | ≥ 8%      | 测反馈按钮本身。基准：网站挂件中位 7.6%、in-app 27%（都是通用 SaaS 非游戏）；对照 itch 小 jam 有 44% 的作品零反馈 |
| T7 发新版前看过上版结果页的开发者占比         | ≥ 60%     | 「知道结果」有没有被用——这才是结果层的直接判据。60% 是拍的，全网无公开基准，只作内部相对比较 |
| T8 门禁到首帧的掉队率                | 记录        | 若稳定 > 20%，第一层单独就能撑起结果层，SDK 优先级可再降 |
| Q 「你把链接发给了谁？从哪找到这些人？」        | 访谈        | 决定 §1.2「开发者已有 5–50 个具体的人」这个前提是否成立 |


**停的条件**：T2 < 25% 或 T3 < 3——他们试了一次就走，说明痛不够痛，这个产品不该独立存在。**改的条件**：T4 里隧道低于 10%，隧道降为附属功能、资源全投上传与结果；T6a 长期低于 3%，砍掉反馈按钮（错误上报无论如何保留——它的价值不依赖玩家配合）；Q 里多数人答不上来，重写 §1.2。

## 9. 只有创始人能拍板的事

已定（2026-09-07）：语言选 Rust（§4.7）；匿名 24 小时链接进 v0.1（§3.2，分发更顺比滥用面更大更重要，滥用靠角标、限流量、24 小时到期兜底）；免费档门禁页带角标（§3.3）。

1. 香港哪家云（压测后定）。
