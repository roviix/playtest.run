# 2026-09-14 合集设置弹窗化、面包屑对齐与投稿舱冗余消除记录

## 1. 用户反馈与问题剖析

用户实测后进一步反馈：
1. **左侧一半表单样式呆板、枯燥**：「不如做成一个钛白 之类的 弹窗设置也行？ 现在这个一半左边的表单，感觉有点丑，而且表单都是一些呆板的title 和输入框，很枯燥的表单样式」。
2. **投稿舱区域严重多余、反客为主**：「这个部分的区域 感觉也很多余？把我的作品放进来 参与本次创作挑战，将你已发布的公开作品提交至本合集。先发布并公开一件长期作品，再回来选择。已有作品不需要重复上传。[回到我的作品 →]」。
3. **面包屑未对齐且设计不够克制精致**：「我的合集 / 鹈鹕骑单车 这个地方返回 和 斜杆 以及 合集名称 没有对齐，而且返回按钮的样式设计 不太好看，不够克制 精致」。

## 2. 工程与交互重构

1. **合集设置与新建弹窗化（CollectionDialog）**：
   - 移除详情页中生硬占位的「资料与设置」选项卡与左侧半宽面板。
   - 在详情页右上角为所有者提供优雅的「设置」按钮；点击后调起黑曜石微晶钛白弹窗（`<dialog class="overlay">` + `.collection-dialog-sheet`）。
   - 弹窗居中展示、支持 ESC/点击蒙层关闭；内含 BrandMark 字标、字段、公开状态卡片与危险操作区，点击保存自动关闭并刷新状态。
   - 列表页「+ New Collection」亦统一复用此弹窗，彻底移除了过去展开的抽屉卡片。
2. **投稿舱冗余清除与作品收录弹窗化（WorkSubmitDialog）**：
   - 彻底删除一直常驻在作品列表正上方的「把我的作品放进来」大面板。
   - 在「收录的作品」标题右侧提供轻量主按钮「+ 添加作品」；若 0 件作品，则在空状态卡片内提供「+ 添加作品」引导。
   - 点击后呼出轻量弹窗 `<WorkSubmitDialog>`，仅在用户有明确添加意图时才展开作品下拉列表或无公开作品引导，主页面彻底回归作品画廊本身。
3. **面包屑纯排版居中微调（Typographic Alignment）**：
   - 移除原先类似独立按键的盒模型边框、内边距与 min-height。
   - 采用纯排版导航：`<a class="breadcrumb-item">`（带微细矢量 chevron 图标） + 居中斜杠 `<span class="breadcrumb-sep">/</span>` + 当前标题 `<span class="breadcrumb-current">`。
   - 统一步伐、字号、高度及 `align-items: center`，彻底消除垂直基线偏斜，达到像素级居中对齐与克制极简质感。
