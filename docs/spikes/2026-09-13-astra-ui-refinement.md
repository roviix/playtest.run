# 2026-09-13 Astra 设计与实现打磨

## 模型与范围

本轮按用户要求，三个子代理均以 `model=gpt-6-astra`、`reasoning_effort=high` 显式调用，工具接受调用；后续审阅继续使用原代理，没有切换其他模型或执行降级。分别负责品牌与卡片、关注与邀请函、发布说明，根代理负责先更新 DESIGN、整合、浏览器检查与记录。

设计依据为 DESIGN §3.3、§3.9、§3.10、§3.13–3.14；域名判断补充在 §4.1。只修改当前仓库，不复制其他项目，不增加依赖，不改变玩家首次进入作品的要求。保留工作区其他任务已有改动。

## 实现与取舍

- 卡片最小列宽 260px，标题 16px、简介 14px，均允许两行。1280px 的模拟广场实际三列、每张约 308px 宽；不再为了四列把信息压成一行。无简介不预留两行空白，控制台现在也显示已有简介或求测说明，slug 与事实留在底部。
- 840px 以下侧栏折成顶栏；768px 检查得到两列约 342.5px 卡片，避免中间宽度出现单张近 500px 的大卡。560px 以下单列，375px 下实际卡宽 324px，无横向溢出。
- 品牌与主操作使用明亮长春花紫，状态辅以冷蓝；底色、侧栏和卡面采用冷墨色层次。`.run` 与原有图形标记染色，字卡恢复清透颜色。作品封面仍保留自己的颜色，没有增加全页光效。
- 发布说明宽 672px、外留白 20px；命令为浅蓝紫底、深色 15px 等宽字。三种模式与复制同处一个组件，运行提示 14px，参数按两列对齐。桌面最长示例命令保持单行；手机只在代码内横向滚动，亮面使用亮色系统滚动条。
- 关注页移除左右介绍布局，主体只保留关注列表；顶部打码邮箱与通知设置。未连接设备的找回入口使用 `/me/action` 的 `send_link`，不顺带订阅广场。周报独立选择；邮箱和浏览器通知同时可用时，主页面只有一个周报入口。
- 邀请函把关注、群、分享与举报收进同一底栏，首次邮箱输入在卡外原生对话框内。顶部复用品牌 SVG 与字标作为回广场链接，版本与到期时间仍并排显示。关注前后卡片高度保持约 614px（375px 模拟样本）。
- 通用 dialog 增强独立成 `ui/dialog.js`，邀请函无需携带发布复制逻辑。保留原生表单、锚点兜底、关闭与焦点归还；同时修复通用隐藏属性被 display 样式覆盖的问题。
- 交叉检查补齐举报表单 select/textarea/label 样式、错误与确认页 14px 正文、品牌实心中心点。没有通过提高既有体积限制隐藏开销。

## 本机浏览器检查

2026-09-13，macOS 上 Codex 内嵌 Chromium。分别读取 `innerWidth` 核对 1280、768、375、320px；这些是浏览器视口覆盖，不是手机真机。

- 模拟页面由 `edge/examples/design_preview.rs` 调用生产渲染器生成，八件虚构作品覆盖长标题、长作者名、无简介、求测与到期。5280 只提供布局样本，不能用来提交真实关注、举报或运行这些虚构作品。
- 广场桌面与手机、平板列数、作者事实对齐、标题与简介两行、导航和紧凑搜索均检查。控制台通过隔离模拟 API 检查作品墙与发布说明；使用的是无真实权限的模拟令牌，没有读取真实令牌。
- 发布三种命令可切换，桌面最长命令代码区域 `clientWidth=scrollWidth=628`，不需横向滚动。375px 下代码区域宽 300、内容宽 540，页面本身不溢出。复制后的图标与成功状态可见；未独立核对系统剪贴板内容。Escape 关闭后焦点回到「发布作品」。
- 邀请函打开关注后，邮箱在独立 dialog 中，main 内邮箱输入数量为 0，卡片高度未变。Escape 关闭后焦点回到「关注更新」。首次找回关注在 320px 下无横向溢出；没有真的寄出确认信。
- 去除脚本的临时样本中，关注仍通过 `#notification-settings` 展开并保留 `/follow` 表单；发布通过 `#publish-dialog` 打开，radio 可切换命令，复制按钮隐藏。没有用这些静态样本假称真实投递成功。
- 最新构建的真实本机 `localhost:8444` 广场与 `/p/ivory-beaver-33` 邀请函显示新色彩、卡片及底栏。作品子域的举报入口实际返回「暂时无法检查流量额度」503，未将该内容路径记为通过。另用生产 `pages::report_form()` 生成样本检查表单：375px 下 select/textarea 均宽 309px、字号 16px、无横向溢出；未提交举报。

## 域名判断

产品视觉与导航应统一，作品执行源与发布权限仍应隔离。当前保留 `playtest.run` 和 `playtest.roviix.com` 的既有职责。如果未来把广场与控制台合到同一个品牌主域，应先迁移不受信任的作品执行域，并独立验收旧链接、Cookie、隧道和分享记录，不能仅添加 `/console` 路由。依据与取舍已写入 DESIGN §4.1，本轮没有据此自动改变账号或 DNS。
