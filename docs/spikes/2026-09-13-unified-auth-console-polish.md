# 2026-09-13 控制台统一弹窗登录、文案收敛与关注订阅精简

## 本轮依据

针对用户反馈的四项体验与视觉问题进行系统性打磨：
1. **控制台登录分散**：此前各未登录页面各自嵌入大段登录说明或整页替换，体验割裂。重构为外壳层统一受控的紧凑登录弹窗，包含 GitHub 首要登录与访问令牌手风琴，登录成功后自动回跳到原意图页面（如合集、特定作品等）。
2. **文字冗余与克制**：侧边栏品牌区移除「控制台」副标题，仅保留准星图形与字标；账号页去除本地路径（`~/.config/...`）、实现原理与长篇使用说明，撤销令牌危险操作收纳至折叠中。
3. **玩家端关注与订阅重构**：移除空态中多余的「去广场看看 →」（左侧导航栏已有常驻入口）；周报订阅从关注空态中移出，统一收拢进右上角「通知设置」弹窗的折叠项中；邮箱登录仅保留必要提示「使用关注时的邮箱。」。
4. **发布弹窗徽标与文案优化**：Web 控制台与边缘广场双端同步去除「CLI 模式」文字，命令行图标统一替换为左上角品牌准星 Logo（`BrandMark` / `crate::html::MARK`），移除冗长参数表格，底部改为下载 CLI 与使用方法直达链接。

产品定义先行更新至 `docs/DESIGN.md` §3.10、§3.13。

## 改动与实现

- **统一登录弹窗 (`console/src/auth.tsx`)**：
  - 抽出 `LoginDialog` 弹窗与 `LoginRequired` 占位组件。
  - 点击需鉴权菜单（我的作品、合集与挑战、特定作品等）原地呼出弹窗，通过 `sessionStorage` 与路由状态保持 `target`，Esc / 点击遮罩关闭后焦点返回触发项。
  - GitHub 登录保留 OAuth 回程跳转；访问令牌输入通过 `validateToken` 校验成功后才持久化保存并跳转目标页，失效或网络异常留在弹窗提示错误。
  - 监听 `AUTH_EXPIRED_EVENT`，令牌失效自动清理并唤起重登。
- **文案与品牌精简 (`console/src/app.tsx`, `console/src/pages/token.tsx`)**：
  - 侧栏品牌区删除 `<span class="brand-sub">控制台</span>`，仅保留无障碍 `aria-label`。
  - 账号页重构：仅保留当前身份头像与名称、切换账号与退出登录按钮，访问令牌撤销放入 `<details>` 折叠且带二次确认，删去所有说明长文。
- **发布用法弹窗同步 (`console/src/publish.tsx`, `edge/src/plaza.rs`)**：
  - 标题左侧统一使用准星图标，移除「CLI 模式」标签。
  - 移除高级参数对照表，命令面板保持 `playtest ./dist`、`playtest 3000`、`playtest ./dist --backend 8000` 三种直观用法。
  - 底部提供「下载 playtest CLI」与「使用方法」直链。
- **关注页与订阅打磨 (`edge/src/follow.rs`, `ui/follow.css`)**：
  - 关注空态仅保留简洁的「登录后查看关注」与「邮箱登录」入口，移除重复的「去广场看看」。
  - 订阅周报统一归并入右上角「通知设置」原生弹窗内，默认折叠，不打扰首次查看关注的用户。
  - 邮箱登录统一使用 `/me/action` 恢复链接，提示语明确为「使用关注时的邮箱。」。

## 本机浏览器观察

在 macOS 桌面环境及视口模拟（1280px 桌面、375px 移动端、320px 极端窄屏）下进行交互与 DOM 验证：

- **控制台导航与弹窗交互**：
  - 未登录状态下从使用文档点击侧栏「合集与挑战」和「我的作品」，页面原地升起登录弹窗，URL 保持当前位置；按 Esc 或点击遮罩，弹窗关闭且焦点返还至原导航按钮。
  - 展开「使用访问令牌」，输入错误令牌点击登录，弹窗显示「令牌无效或已失效，请检查后重试。」且不跳转；输入有效令牌验证通过后，自动关闭弹窗并跳转至「合集与挑战」页面。
- **关注与通知设置验证**：
  - 320px 视口下查看关注页未登录状态，文档宽度 305px（含 15px 滚动条），无横向溢出。
  - 点击「邮箱登录」，呼出原生对话框，输入框字号 16px，满足防缩放规范；提交按钮高 44px。
  - 点击右上角「通知设置」，在弹窗内可见广场周报订阅折叠，展开后为邮箱输入表单；已订阅状态下显示退订操作。
- **发布用法弹窗**：
  - 标题前准星图形清晰对齐，无「CLI 模式」文本；复制命令按钮带有点击反馈与状态变化，底部外链满足 44px 触控标准。
