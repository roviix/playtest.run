# 控制台使用文档：阅读与操作入口

日期：2026-09-12。环境：本机 macOS、Chrome headless，控制台 Vite 开发服务 `http://127.0.0.1:5283`。无真实账号、无生产发布。

## 产品与视觉

先补 DESIGN §3.13，再提供 `#/docs/start` 等六个章节地址。文档在登录判断之前渲染；从侧栏、发布弹窗、空作品页、作品页、账号页、错误提示可以进入。发布弹窗的默认命令不带上广场选项，空态不重复 `--public --seats`，不再承诺自动保存邀请卡。

沿用现有冷灰底、钛白文字和细边界，以窄正文、宽留白、章节编号和少量灰绿色强调建立阅读层级。桌面右侧固定目录，手机可展开目录位于控制台顶栏下方。没有引入 CMS、外部字体或新依赖。代码块独立横向滚动，复制按钮具有反馈与手动复制降级；重要限制用侧线说明，不将所有内容装进卡片。

## 实际检查

用独立临时 Chrome 配置、空 localStorage 访问，运行浏览器脚本检查：

- 无登录状态可以阅读全部六章。
- 桌面逐章点击更新 hash，焦点移到相应标题；直接刷新最后一章，仍定位在该章。
- FAQ 原生 details 可展开。
- 复制成功与拒绝两种分支都有提示。剪贴板测试使用注入的成功 / 失败实现，未操作用户真实剪贴板。
- 发布弹窗默认显示 `playtest ./dist`，点击完整说明关闭弹窗并定位发布章节。
- 320、390、768 CSS 像素宽度无整页横向溢出；展开手机目录、切换章节后收起，焦点到达标题。
- 过程中未捕获 JavaScript 运行异常。

首轮截图发现手机控制台顶栏遮挡目录和章节标题。通过测量顶栏高度，修正目录 sticky 偏移与章节 scroll-margin，重新执行浏览器检查并目视确认。命令块移除继承自全局 inline code 的小边框，避免代码块内出现重复框线。

- `npm --prefix console run build`：TypeScript 检查与 Vite 生产构建通过；整个控制台 CSS gzip 9.88 kB、JS gzip 30.43 kB。

## 边界

这是本机浏览器与响应式模拟，不是真手机 Safari / 微信验收。没有验证外部 Releases 下载和系统安装流程，没有访问生产账号，也没有部署控制台。CLI 用法检查证明示例可由指定二进制解析，不替代完整发布集成测试。文档明确区分当前项目约定与用户已安装版本，避免将源码变更写成已发布安装包的能力。
