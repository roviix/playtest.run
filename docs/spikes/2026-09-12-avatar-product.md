# 2026-09-12 · ODD FOLK 2.0 在产品里的头像验收

## 对应判据

DESIGN §1.2 M2b、§3.3、§3.9：玩家能看清是谁邀请，默认头像不留白、不增加请求。此次交付是 `common/src/avatar.rs` 的生产 SVG 生成器，以及邀请页和广场的调用，不是把 `docs/avatar-concept.html` 当产品。

## 实现范围

- 仍是六种原创角色。可选特征由 43 项增加到 62 项：12 组配色、10 种头饰、8 种服装、8 种眼神、4 种表情、8 种配饰、6 种背景。新增贝雷帽、牛仔帽、耳机、水手帽、皮衣、工装、度假衫、三款眼镜／眼罩、相机、徽章、领结等；组合数不等于独立画作数。
- 新增轮廓光、局部阴影与刻线；移除头像里的签名、版号和装饰角标；耳环、创可贴跟随脸部旋转。
- 生产两处调用 `svg_for_creator`：具名作者按公开显示名；空名和「匿名开发者」按作品 slug。此前占位名字会让所有匿名作品用同一张脸。当前数据没有公开作者 ID，不保证匿名跨作品同脸，也不保证同名作者不同脸。
- 广场由 16px 调整到 24px，邀请页由 22px 调整到 32px；GitHub 图片与算法头像使用相同尺寸。维持圆形裁切、固定占位，不新增可点击控件。邀请页头像微投影仍在卡页样式 6KB 的预算内。
- UTF-8 种子、空白裁切、八维特征与签名由 Rust／JS 共用测试向量约束；新增素材目录与概念页的内嵌副本有一致性测试。SVG class 属性转义，秘密不作为头像种子。
- 生成器版本为 `odd-folk/2.0.0`：旧版本种子会换脸；概念页明确拒绝无法复现的旧版配置，不伪装兼容。

## 本机真实页面

环境：本机 macOS、Codex 内置浏览器、本机编译的 `playtest-edge`。先观察原有 `localhost:8443` 的广场与邀请页，再以隔离临时存储启动新版边缘在 `localhost:8844`。没有重启原有服务、修改原有 `.data`、写线上数据或配置控制面回源。

验收数据是 8 个明确标注「本机隔离测试作品 · 非线上数据」的作品，经真实对象存储格式、真实 Router、真实 Rust 模板与生产 CSS 渲染；不是手写页面截图，也不是 HTML 头像工作室。两个匿名作品分别得到树蛙、兔；同名「小林🎨」的两个作品得到相同角色。

观察结果：

1. 广场八张头像 DOM 实测均为 24×24px，`border-radius: 50%`，版本标记均为 2.0。匿名作品不再因占位名字共用同一角色。
2. 从广场点进 `/p/avatar-study-1`，同一个角色出现在邀请人的名字旁，实测 32×32px；不是重新抽一位。主要按钮、作品名、可选名字输入和举报入口仍是原来的产品结构。
3. 桌面和 390×844 的窄视口均检查过；邀请页内容宽 390、广场内容宽 375（预留滚动条），都没有横向溢出。窄视口上的头像不被挤小，测试结束已恢复浏览器视口。
4. 默认头像直接内联 SVG，不使用图床或 `<image>`。保留现有 GitHub 头像优先与 referrerpolicy 行为；不修改 CSP 来迁就新素材。

## 自动化结果

以下命令均在本机执行通过：

- `cargo test -p playtest-common --test avatar`：9 项。含匿名取种、显示名跨作品稳定、中文／Emoji、属性转义、素材副本一致性与 500 张渲染批次的耗时上限。
- `cargo test -p playtest-common --lib avatar::tests`：4 项。覆盖全部物种、配色与每种素材的分层渲染。
- `node --test common/tests/avatar-preview.cjs`：5 项。含全部权重／配色对齐、黄金向量、素材选项与脸部配饰层级。
- `cargo test -p playtest-edge --test social`：18 项。新增真实广场和邀请路由的头像一致性测试，分别覆盖匿名、空名和中文／Emoji 作者；原有邀请卡、关注、分享回归仍通过。
- `cargo test -p playtest-edge --lib`：173 项。曾因新增头像阴影超过卡页 CSS 6KB 上限而失败；删去多余的外圈阴影后恢复预算，没有放宽测试阈值。
- `cargo build -p playtest-edge`、相关 Rust 文件 `rustfmt --check`、`git diff --check`：通过。

## 不声称的部分

这里只完成本机真实产品渲染与桌面浏览器窄视口验收；窄视口不等于手机真机。没有上线部署，没有验证 iOS／Android／微信里的显示，没有穷举所有特征组合，也没有把「对标收藏级头像」当作已达到某个艺术水准的客观结论。头像工作室的导出／导入不是这次产品场景验收的覆盖范围。
