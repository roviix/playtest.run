# 控制台交互打磨：本机浏览器检查

日期：2026-09-12。

## 范围与环境

本机 Chrome 与 Codex 内置浏览器；控制台 production build，独立本机模拟 API（端口 5274）。六个虚构作品，详情结果延迟 700ms；输入的令牌是无权限的测试字符串，未读取真实令牌，未连接生产账号。截图中的人数、作品和版本都是模拟数据。

## 本轮观察

- 作品墙能打开作品；已有标题、封面、版本身份先呈现，结果独立加载，不先清空整个工作区。
- 结果尚未返回时，「现在」显示正在获取动态，不提前断言没人打开。已有打开人数但缺少时间时显示人数，不留一条没有时间的「上次打开」。
- Chrome 中从详情切到反馈、浏览器后退回结果、返回作品墙，页面与地址一致，身份栏保留。检查期间没有捕获到应用级 error / warn。
- 内置浏览器 1440×960 和 375×812 检查布局；375px 详情没有横向溢出，数字改为两列，避免「点了开始」「5 分钟以上」被截断。分页签保留完整标签。
- 移除分页签意外出现的竖向滚动条；移除「现在」状态点的循环呼吸。

## 自动检查

- `cd console && pnpm build`：通过；TypeScript 检查和 production bundle 构建成功。
- `cargo test -p playtest-edge --lib --quiet`：173 项通过。保留卡页 CSS 6KB、整页 CSS 15KB 的现有预算，不放宽测试。
- `git diff --check`：通过（提交前工作区检查）。

## 边界，不算已经验收

- 这不是手机真机、微信内置浏览器或生产端到端测试；没有执行登录、真实发布、通知、回滚、删除或支付。
- 原生封面转场的名字、同步渲染和减少动态效果降级已实现；本轮工具没有记录转场中间帧或帧率，不能据此宣称所有浏览器的动画都已流畅验收。快速连续导航、减少动态效果的系统开关、长列表滚动恢复仍需专项实测。
- edge 本轮调整了卡页主按钮高度、广场触控目标和鼠标按压反馈，只有 Rust 回归测试；未替换正在运行的本地 edge 进程，不把旧进程画面当成本轮新样式的证据。
- 无新依赖、无后端协议改动；使用清单中已有 Site 信息缩短打开路径，详情请求仍以服务端为准。
