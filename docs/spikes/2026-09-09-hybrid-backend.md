# 2026-09-09 · 混合模式：空投站的静态文件上传、后端走隧道，本机与香港各走一遍

**结论**：`playtest ./web --backend 8894` 在香港真域名上一次通过——门禁页和静态文件由边缘给（v1），
`GET /api/now`、`POST /api/open`、`/new` 这些上传目录里没有的路径穿隧道回到我这台电脑，真实 Chrome 里页面完整；
Ctrl-C 之后页面照常能开，清单外路径回 `503` + `{"code":"backend_offline",…}`。
中途改了一次设计：从「`/api/` 与 `/socket.io/` 走隧道」的路径约定，改成「**上传的清单就是分界线**」，
理由和代价写进了 DESIGN §4.3。用的是本机构建的 `target/debug/playtest`（`d7787af`），边缘与控制面是同一提交在香港构建的 `20260909-081949`。

夹具还是昨天 dogfood 的**空投站**（`imagination-space/experiments/airdrop`）：`web/` 是 9 个文件 346.8 KB 的静态前端，
`server/dev.mjs` 是零依赖 Node 后端，原生在 `/api/*` 上应答、`/new` 出一页 HTML、根路径也能出首页（这次不该被玩家看到）。
mofish 没用：它的 dev 后端挂在根路径（`/now`），前端却请求 `/api/now`——这正是「路径约定」方案对不上的那类项目，第一节说它。

## 一、设计改了一次

第一版让令牌带 `only_paths`，默认 `["/api/", "/socket.io/"]`，可用 `--tunnel-path` 改。创始人一眼看出这是「某种特殊处理或约定」：
它是从 Vite `server.proxy` 借来的习惯，不是产品里长出来的规则；mofish 这种后端挂在根路径的项目要多学一个参数。
改成：清单里有的文件从边缘给，清单里没有的（不论方法，WebSocket 也算）交给后端——`express.static` 放在路由前面就是这个组合。
令牌里只剩一个 `hybrid` 布尔；`--tunnel-path`、路径校验、`MAX_ONLY_PATHS` 整个删掉。代价（打错的静态路径会到后端、扫描器探测也会到后端）在 DESIGN 里如实写了。

边缘的一处顺序也跟着变：以前 `serve_file` 先拒 `POST` 再查清单，现在**先查清单再看方法**——`POST /api/score` 得能过去，`POST /game.js` 仍是 405。

第一遍跑完看到两句在混合模式下说错的话，当场改了：结束语「已停止，链接现在显示离线」（并没有离线）→
「已停止。页面照常能开，目录里没有的路径现在回「后端不在线」」；上传前检查的「index.html 要用 2 个目录里没有的文件，玩家那边会加载失败：new、.」
→ 有后端时降为一句说明「它们会交给你的后端」。第二遍两句都对了。

## 四、这次真的验到了什么

| DESIGN 的说法 | 这次 |
|---|---|
| §4.3 混合模式：清单里有的从边缘给，没有的交给后端 | 对，GET / POST / 后端自己的 404 都按边界走；WebSocket 只在集成测试里验了（`edge/tests/tunnel.rs`），线上没验 |
| §4.3 失败形态：后端离线回 503 JSON 不是 404 HTML | 对，本机与线上都是 `backend_offline`，`no-store` |
| §4.3 门禁页按上传的版本说话 | 对，「· v1」，没有隧道模式的「在线」 |
| §4.5 控制面只在有上传版本时签 `hybrid` 令牌 | 集成测试验了；线上路径天然满足（先传后接） |
| §3.2「几秒」 | 上传 + 接后端共 5.7 s，但**分段只解释了 1.1 s**（见五） |

## 五、撞到的

1. **计时那一行对不上账**：「本次 5.7 秒（哈希 0.0 · 上传 0.9 · 提交 0.2）」，剩下 4.5 s 在拿令牌、建作品、问「缺哪些文件」、探本地端口这些没被计时的段里。
   DESIGN §8 盯的是句首那个数，分段是为了知道慢在哪——现在知道不了。要把「准备」那段加进去，让分段之和等于总数。
2. `index.html 引用了 … new、.`——那个 `.` 是 `href="."` 被当成引用了，两种模式下都会出现，检查器该跳过它。
3. 匿名链接还是那 24 小时：这条链接 22:31 失效，测试形态却是「发到群里玩几天」。登录仍是最大的缺口。

## 六、没验的

真手机没点；WebSocket 穿混合模式的隧道只有集成测试（线上夹具没有 WS）；`--spa` 与后端同时开的组合没在真机上走；
后端不在线时游戏前端会怎么呈现那个 503（空投站进 error 态是从代码读出来的，没截图）；扫描器打到后端的量没有观测数据；仍然只有我一个玩家。
