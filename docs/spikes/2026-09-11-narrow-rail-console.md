# 2026-09-11 广场改窄栏、发布说明排成三步、控制台跟上玩家域

接着 `2026-09-10-plaza-object.md`。用户拿来一张参考图：左边一条只有图标和两字标签的窄栏，右边直接是墙；问栏该保持 250px 还是改窄，另外要求把发布说明和整个控制台「全面打磨」。DESIGN §3.9、§3.13 同日先改。

## 栏：广场改窄，控制台保持宽

**为什么广场改窄。** 广场栏上只有两间房。上一版 15.5rem 的栏下半截永远是空的，便条被顶到最底下像一张贴纸；而墙是这一页的全部，多出来的 170px 该给封面。改成 76px：顶上一个标记，两间房各是图标加两字标签竖着排，栏底一个「发布」加号。当前那间房贴着栏的左边沿一竖琥珀。1440 宽下仍是四列，卡从约 265px 长到约 310px；1920 下仍是五列（`img/2026-09-11-narrow-rail-wide.png`），六列要到 2080 以上。

**为什么控制台不跟着窄。** 控制台的栏要放作品清单（§3.13），名字不能收成图标；两条栏用同一个标记、同一套面与线、同一种项，宽度不同是因为装的东西不同。

**标记。** 一个暗色小方块，里面象牙的 p 和一个琥珀点——点就是字标 `playtest.run` 里那一个点。字标本身在桌面上只留给读屏，手机顶条上才显示。没有引图标字体，三个图标（格子、书签、加号）都是画在页面里的几笔线；CSP `default-src 'none'` 下 `<use href>` 不能用，所以直接内联。

## 发布说明

三步：装好 playtest（Releases 链接——这是 GitHub 的公开发布页，不是开发者域）；在作品目录里跑一条（三种情形仍用单选标签切换，命令框前一个琥珀 `$`）；发出去之后去哪看（控制台链接在这一步里，仍是玩家路径上唯一去开发者域的出口）。眉题「从一条命令开始」是琥珀等宽小字，关闭是一个有面的 32px 方钮。手机上从底部升起。

## 控制台

`console/src/style.css` 整份重写，橄榄夜与酸黄绿全部换成玩家域的记号：墙 `#0b0b0d`、栏 `#0f0f12`、卡 `#151518`；发丝线 + 上沿高光；琥珀只给当前那间房、状态点、「此刻」的点和结果里第一个数；暗橙说坏消息。

标记结构几乎没动，只改了四处：栏顶加标记；作品墙的卡和身份栏的窗用新的 `Cover` 组件（`pages/cover.tsx`），封面图拿不到就退成字卡——上一版 mock 下是一个白边破图标；字卡按 §3.9 改成花押 + slug（`hue.ts` 加 `monogram()`，和边缘同一条规则）；栏底便条的命令改成带 `$` 的命令框。

结果页四个数不再各装一个小盒子，用发丝线隔开排成一行，第一个数琥珀，0 退成灰；「玩家看到的」那一版是一圈很淡的琥珀线。主要动作（去 GitHub 授权、放上去找人测）是象牙面墨字，和广场的「发布」同一种。反馈卡左边一根琥珀细线说「还没看」，看过变灰，处理完消失。
