# 2026-09-13 广场、发布说明与邀请函收敛

## 依据与改动

依据 DESIGN §3.9、§3.13，以及用户对卡片偏大、搜索与解释抢占空间、发布说明和邀请函操作分散的反馈。本轮继续现有设计，不引入新页面、依赖或玩家步骤。

- 广场与控制台共用紧凑作品卡片。1280px 浏览器下，广场由约 296×350px 的三列卡片变为约 226×252px 的四列卡片；封面比例为 16:10。375px 下保留两列，作者与状态分行对齐。
- 搜索收进标题行，桌面整体宽 280px；移除广场及控制台的装饰性副标题。近 7 天排序的统计口径放进按需展开的说明。点击开始的去重会话写成「次开始」，不称真人或访问次数。
- 最新列表保留推广标记与位置，其余按更新时间排列，征集状态不再覆盖时间顺序；增加较旧征集作品与较新普通作品的排序回归检查。
- 发布说明保留一个命令组件，模式切换与复制按钮合在组件顶部。缩短标题和首屏提示，参数解释按需展开；控制台与玩家页保持各自原有命令语义。
- 邀请函宽度收至 420px，名字与开始按钮并排；版本与到期时间合并在信息行。关注、开发者的群与分享集中在开始区下方；邮箱表单由关注入口展开。头像仍为 32px，邀请函操作保留 44px 点击区域。

## 本机浏览器观察

2026-09-13，macOS 上通过 Codex 内嵌 Chromium 检查。窄屏覆盖后读取 `innerWidth` 核对为 375，不将浏览器视口模拟当作手机真机。

- 最新源码构建的 edge 在 `localhost:8444` 运行，读取本机已有数据。广场进入 `ivory-beaver-33` 邀请函，实际看到新版版本/到期行、名字与开始区、关注和分享工具行；没有修改该作品。
- `edge/examples/design_preview.rs` 调用生产渲染器生成八个虚构作品，包含长标题、长作者名、无简介、征集和到期状态。`localhost:5275` 仅提供临时生成页面。1280px 下四列等高；375px 下两列，无水平溢出。统计说明在窄屏内展开，没有超出屏幕。
- 发布说明在桌面与窄屏检查三种模式及命令切换。点击复制后成功图标和状态可见；未独立读取系统剪贴板来核对内容。Escape 关闭后 `dialog.open=false`，焦点回到发布入口。
- 临时去除脚本的预览中，发布入口通过片段标识打开说明，radio 模式切换仍显示对应命令，复制按钮隐藏。
- 模拟邀请函分别检查未关注与已关注状态、邮箱展开，以及开发者的群和分享同时出现的布局。未实际发送订阅邮件或执行取消关注。
- 控制台通过隔离模拟 API 检查两张作品卡片及发布对话框；最终 TypeScript/Vite 构建通过。模拟 API 和专用 Vite 服务已关闭。
