# 2026-09-14 合集质感重塑、生成式微徽章与表单体验打磨记录

## 1. 背景与用户反馈

用户在全流程实测合集创建（以「鹈鹕骑单车」自选合集与创作挑战为例）时指出：
1. **合集管理页面过于粗糙、表单拉伸失控**：在桌面超宽屏下表单无上限展开，形成长达 1920px 的巨大空白文本框；字段上方充斥着微说教与官僚式提示（如「最多 80 字」「介绍合集的亮点或主题」「公开展示前必填」）。
2. **顶栏面包屑与导航错乱**：`我的合集 / 鹈鹕骑单车` 缺乏层级质感、悬停微交互与语义区隔。
3. **封面机制疑惑与列表卡片空态粗糙**：
   - 疑问：「不能设置封面么？还是封面是依赖里面作品的？」
   - 列表卡片（控制台卡片与广场 Discovery 合集卡片）在没有收录作品时呈现光秃秃的文本框或粗糙的裸露「＋」号，缺乏视觉张力与美感。

## 2. 设计与工程解法

1. **封面机制定位与生成式艺术（Generative Artwork）**：
   - **设计定位**：根据 DESIGN §3.13 与 §3.15，合集是「作品的汇聚与专题组织」，其核心视觉内容由收录的作品共同构成（收录作品的前 3 个封面形成纵深叠放画廊）。因此合集无需作者额外制作/上传单独的 2MB 封面图，极大降低创建门槛。
   - **初始与空态生成式微徽章**：针对合集未收录作品或初始草稿状态，统一引入平台级 FNV-1a 色相扩散算法 `hue(slug)` 与字符花押 `monogram(title, slug)`：
     - **控制台合集卡片**：顶部 16:9 生成式画布（`.collection-card-art`），以合集专属色相微光渐变、极细点阵网格与磨砂玻璃徽章（`.collection-card-art-medallion`）居中承托花押；右上/左上分别浮动状态与类型玻璃胶囊。
     - **详情页顶栏 Identity Emblem**：64px 圆角微浮雕黑曜石徽章，内嵌大写首字花押与类型小角标（🎯 / 📚），并带有色相边缘微光。
     - **广场 Discovery 卡片**：无作品收录时不再呈现生硬的纯文本灰框加「＋」，而是渲染带有专属色相渐变与首字花押的 `.collection-empty-medallion`。
2. **面包屑导航现代升级**：
   - `.collection-breadcrumb`：采用内嵌 SVG 矢量箭头回退按钮，增加动态 translateX 微动效与半透明微质感药丸胶囊，平滑链接至合集大厅。
3. **设置表单容器与暗色黑曜石输入框约束**：
   - 新增 `.collection-settings-container`，将资料与设置表单宽度硬性约束在 `max-width: 680px`，居左对齐，彻底终结 1920px 宽屏拉伸变形。
   - 移除所有啰嗦说教提示词，保留清爽的单行标签与清晰的 placeholder。
   - 输入框与文本域升级为半透明暗晶质感（`background: rgba(0, 0, 0, 0.35)`），聚焦环呈现翡翠聚焦辉光（`0 0 0 3px var(--accent-soft)`）。
