# 2026-09-10 字标 `.run` 从苔藓改成新叶

上一版（`2026-09-10-plaza-night.md`）`.run` 用 `#8fad7a`。夜里墙上它灰得发闷，和 `playtest` 几乎糊成一色。这一版按 DESIGN §3.9（同日改过）换成 `#9aed62`：更亮、略偏黄。

为什么不是另一个：再压饱和就是苔藓；微信那一号绿大陆用户太熟；薄荷青是控制台的默认「在线」。新叶是 `.run` 该有的动作——刚发芽，不是已经长好的。

## 看过的

Chrome 152 `--headless=new`，`scripts/headless-check.mjs`。稠密态对着同一份手写 `plaza.json`。控制台无报错。
