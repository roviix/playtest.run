# 2026-09-13 控制台根域 CSS 变量缺失修复与点名册、反馈流克制设计归位

## 动机与排查

用户反馈控制台「样式好像都坏了，现在看不懂东西了」。经无头浏览器全量真机巡检发现：
1. **根本原因：`:root` 基础变量缺失导致全站黑字隐形**：
   - 控制台 `console/src/main.tsx` 依赖 `console/src/style.css` 声明的 `:root` 变量；
   - 之前改动中，`console/src/style.css` 中的 `--bg`、`--fg`、`--soft`、`--dim`、`--faint`、`--accent`、`--accent-ink`、`--accent-soft`、`--accent-line`、`--mono`、`--rail`、`--rail-w` 未在 `:root` 中声明；
   - 浏览器将未定义的 `var(--fg)`、`var(--dim)` 回退为默认文本颜色 `#000000`（黑色），在深色背景（`#09090b` / `#0c0c0e`）上造成文字全盲、完全无法阅读；
   - 按钮 `var(--accent)` 回退为透明，文字与图标失去所有高亮和对齐对比度。
2. **过度设计清理与 DESIGN 规范归位**：
   - 清理未在 DESIGN §3.5、§3.13 定义的非标组件：点名册中的伪头像（如 `SE` 首字母圈）、反馈流中的非标字头像（如 `言`）及多重内嵌标签与过度按钮；
   - 恢复点名册与反馈流原本极简清晰的排版节奏：时间序/停留序、一行一人、原声一句话是主角；
   - 恢复作品页「现在」状态条为轻量克制的文本状态行，移除笨重的卡片外框。
