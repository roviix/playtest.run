# 2026-09-10 广场收成一面墙

对照 [openAstra](https://openaestra.cc) 的发现页重做了根域。上一版（`2026-09-09-edge-card-gate-plaza.md`）是三段标题 + 六个筛选 + 两种排序 + 每张卡三个按钮，看起来像后台列表。这一版按 DESIGN §3.9 / §3.10（同日改过）做成：左边一条栏，右边一面网格，卡上只有一件事实，一行脚本都没有。

## 看过的

Chrome 152 `--headless=new`，`scripts/headless-check.mjs`。稠密态对着一份手写的 `plaza.json`（6 张卡，控制面那一端没联调，避免它把文件写回去）；稀疏态对着本机正在跑的那一个作品。

- 稠密桌面 `img/2026-09-10-plaza.png`（1440×900）：左栏 01 / 02 / 03 + 「有新东西时告诉我」+「128 人关注着这里」；墙三列六张，推广两张在最前且带灰字标，正在找人测带琥珀标，其余没有标；每张卡右下角一个动词（试玩 / 体验），底下一件事实（名额 / 人数 / 还剩多久）；没有筛选、没有「想玩 / 关注 / 举报」。
- 稠密手机 `img/2026-09-10-plaza-phone.png`（420×860）：栏收成顶上一条，编号藏掉，卡一列。
- 稀疏桌面 `img/2026-09-10-plaza-sparse.png`：介绍段在卡前面，卡从左边第一列排，不居中。本机真实数据，作品名是 `vite-vanilla`。
- 「我的」`img/2026-09-10-me.png`：没有「想玩」列表，一句「你关注的作品会出现在这里」+ 邮箱。页上没有「登录 / 注册 / 账号」。

根域 CSP 仍是 `default-src 'none'`，`img-src` 只多 `https://avatars.githubusercontent.com`。广场页没有 `<script>`。

## 登录 / 注册为什么没有

试过「发现页惯例上放两个按钮」。没放，三个理由在 DESIGN §3.10：玩家第一次玩不能要账号（AGENTS 第 6 条）；试玩者唯一要身份的场景是「下一版告诉我」，邮箱确认信就够，`pt_me` 不是账号；开发者的 GitHub 登录在 `playtest.roviix.com`，栏上「03 发布作品」把人送过去，广场自己不承担登录。

## 测试

`cargo test -p playtest-edge`：全绿（lib 含广场 14 条重写过的单测 + social / serving 里对着新 HTML 的那几条）。

## 真机上才改的

没封面的卡如果把作品名印在上半张、再在下面写一遍标题，看起来像印了两遍（09-09 见过）。这一版上半张只放头一个字当记号。字卡的色相地板抬过一次，避免某些 slug 的封面几乎是黑的。

## 没验的

- 控制面写入的 `plaza.json` 与这一页的联调（稠密截图是手写的）。
- 真封面图（本机夹具没有 `--cover`，墙上全是字卡）。广场好不好看八成仍取决于封面。
- 微信里打开这一页（不为它优化，DESIGN §3.9）。
