# 2026-09-13 邀请函宽屏左对齐与独立反馈区

## 取舍

按 DESIGN §3.15，邀请函不引入广场或控制台侧栏。分享链接的接收者先看作品与开始入口，返回合集仍走顶栏，不增加登录或必经跳转。

桌面取消 1040px 居中容器：品牌与邀请卡贴齐页面左边距，卡宽在 380–480px 之间，封面保留 16:10。右侧反馈区使用剩余宽度，只用竖向分隔线，不再与卡片等高、同圆角、同阴影。消息按内容宽度排布，阅读宽度最多 640px；消息流独立滚动，输入区不随消息增长被挤出视口。去掉状态点的呼吸动画，不暗示实时在线。

960px 以下回到单卡，自愿点击原声入口展开全屏反馈。返回合集的长文字截短显示，不再继承旧的 400px 块级样式挤占顶栏。通用错误、举报等卡页保留原本的窄卡约束，不套用邀请函的宽屏页面边距。

## 本机实际验证

- 环境：macOS、本机 Chrome headless、实际 API / edge 二进制、临时 SQLite 数据库与本地演示作品；不是静态概念稿。
- `cargo test -p playtest-edge --lib --quiet`：190 项通过，包括邀请函页面标识、无公开反馈入口时不渲染反馈面板、卡页样式字节预算。
- `cargo build -p playtest-edge -p playtest-api`：通过。
- `node scripts/check-collections.mjs`：通过，浏览器异常列表为空。
- 新增几何断言覆盖 1920×1080、960×800、860×800、390×844、320×740：无横向溢出；桌面卡片与顶栏左边界相同、卡宽在规定范围内、右侧反馈区延伸至页面右侧且输入区在视口内；窄屏默认不展示反馈面板。
- 额外注入 30 条长消息检查排版压力，只用于浏览器 DOM，不伪装成真实玩家反馈：消息流可滚动，输入区仍可见。
- 既有端到端操作继续通过：返回合集、文字反馈发送、贴纸发送、390px 全屏反馈打开与返回、合集搜索与控制台投稿。
- 本轮涉及的代码与文档通过 `git diff --check`；仓库其他已有改动未纳入本次排版修复。
