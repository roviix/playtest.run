# 2026-09-13 黑曜表面与冷绿反射：减轻视觉重量

## 本轮依据

用户认为上一轮仍显笨重，发布按钮缺少黑曜冷萃绿质感，并提供了一份邀请函 HTML 参考。观察当前真实页面后，问题集中在容器重复框线、标题与控件的视觉重量，以及按钮整个面被灰绿色染满。圆角是其中一项，不能仅靠缩小全部字号解决。

先修订 DESIGN §3.9 / §3.14，再在现有样式中逐项调整。参考只用于判断黑底、局部冷绿反射与纵向操作的关系；没有引入参考中的 CDN、字体库、假在线状态、呼吸灯或模拟成功交互。

## 修改

- 品牌绿仍为 `#75cdb5`。主动作底面采用中性黑曜渐变 `#191b20 → #101115`，顶部小范围使用冷绿反射，棱边为局部 `#71e8bf` 高光；四周保持弱中性边线，避免整圈绿色粗框。发布、开始、通知表单与控制台主按钮共用材质变量。
- 发布入口保持 44px 点击区，伪元素表面上下各内收 3px，实际可见厚度为 38px；文字与加号仍居中。反射与边缘均不拦截点击，没有常驻动画。
- 常规边线从白色 8% / 16% 收为约 7% / 12%；仍用完整 1px，保留清晰键盘焦点。主图标线宽 1.4，卡片外角 12px，内面板 10px，主要控件 7px。
- 当前导航移除额外外框；控制台身份栏改为底部分隔线，结果卡仍有明确边界。适量缩小标题字重和内部间距，正文与辅助信息保留既有可读字号。
- 邀请函上限 400px，作品标题 20px，默认字卡为 20:9，真实图片封面继续 16:9。可选姓名与开始按钮上下排列，避免开始被挤到输入框旁边。姓名输入仍为 16px，主动作仍高 44px。
- 发布说明仍为 672px 上限，减少模式选择区的套框、内阴影和圆角，保留 15px 命令、14px 提示和局部滚动。
