# 控制台使用文档质感与阅读体验打磨验证

日期：2026-09-13。环境：本机 macOS、无头 Chrome、Node 22。无生产环境访问，验证控制台 `#/docs/<section>` 免登录文档阅读流。

## 改进内容

1. **终端代码块质感重塑**：
   - 顶部集成 macOS 风格红黄绿微点与终端标签。
   - 复制按钮升级为精致交互胶囊：点击后平滑过渡至 `已复制 ✓`，无任何垂直抖动或撑爆布局。
   - 代码区域增加 `$` 终端前缀（设置 `user-select: none`，手动拖拽复制亦不会误复制 `$`）。
2. **排版层次与心理模型重构**：
   - 章节内移除与大标题混淆的 `01 /` 等子编号，改为清晰的「步骤 1、步骤 2、步骤 3」阶梯向导卡片。
   - 三种发布方式（静态目录、端口穿透、前后端混合）改用清晰的对照表格呈现，明确参数与离线行为。
   - 双域名体系（邀请函主域与游玩沙箱子域）采用双卡片对照展示。
   - 关键原则（Note）升级为黑曜石质感半透明提示卡（左侧青绿微光，带原则标签）。
3. **常见问题 FAQ 升级**：
   - 移除生硬的原生 `＋`/`−` 字符，改用平滑旋转 180° 的矢量箭头指示。
   - 展开内容采用微上边框与宽松间距，行内命令高亮清晰。
4. **右侧粘性目录（TOC）与移动端支持**：
   - 桌面侧边目录提供当前激活章节的高亮胶囊背景，序号等宽点缀。
   - 移动端 390px 视口下优化文本折行规则，杜绝汉字单字孤行。
