# 2026-09-10 `.run` 品牌色与标签样式调整：回归单色，标签去底色

上一版（`2026-09-10-plaza-ink.md`）尝试了渐变字标和带底色的纸签标签。这一版按用户的反馈进行了调整：

1. **品牌色回归单色**：去掉了 `#86eeb4 → #2bb86c` 的渐变，直接使用 `#58d98a` 作为 `.run` 的品牌色。渐变在字标上显得不够纯粹，单色更符合夜间模式下的点缀。
2. **标签去底色**：卡片上的标签（“正在找人测”、“推广”）去掉了实体的 `#f3eee4` 纸签底色。既然已经用了颜色来区分（求测用绿色，推广用灰色），就不再使用填充背景。
   - 求测标：绿色文字，带极淡的绿色半透明背景和边框，加上模糊效果（`backdrop-filter`）。
   - 推广标：灰色文字，带极淡的白色半透明背景和边框，同样加模糊效果。

为什么不是另一个：实心底色的纸签在深色卡片上显得过于突兀，像贴上去的膏药。去掉底色，改用带边框的半透明玻璃态，既能融入深色背景，又保留了标签的边界感，不会因为封面图太亮而看不清字。
