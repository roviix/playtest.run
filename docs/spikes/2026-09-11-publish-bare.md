# 2026-09-11 发布说明：拆掉所有内框

接着 `2026-09-11-publish-tip.md`（同一天，隔了几分钟）。用户看了那一稿说还是乱：行太多、容器太多、内边距太多；三种情形该做成更克制的切换。

## 拆了什么

- 标签：分段控件（槽 + 药丸）拆成三个词，横排，间距 18px。亮的是当前的（`--fg`），其余 `--dim`。没有任何边线。
- 命令：拿掉近黑的框和它的 20px 内边距，直接落在面上。字号 14，亮字，`$` 琥珀。
- 「?」和关闭：拿掉 32px 的方框，只剩两枚 28px 的裸图标。
- 「?」点开：拿掉框，两行暗字，上距 18px。
- 面：拿掉左上那点琥珀光和顶部那条高光，只留一圈 1px 边线；宽 30rem → 28rem；标题 20px/650 → 17px/600。

面里现在只有：一行标题、一行三个词、一行命令。点开「?」多两行字。
