# 2026-09-12 · 四种原生角色，不靠换装的头像

## 产品判据

对应 DESIGN §1.2 M2b、§3.3、§3.9。让默认头像的形象本身更可辨认，而不是继续用帽子和眼镜增加排列数。玩家仍不用登录、选择角色或多点一步。交付对象是 `common/src/avatar.rs` 的生产生成器；概念页只同步同一份画稿。

## 画稿与生成规则

保留原来的六种角色，增加四种各自独立的身体、眼睛和嘴巴画稿：

| 角色 | 核心轮廓与材质 | 与原有胸像的差别 |
| --- | --- | --- |
| 蘑菇居民 | 歪菌盖、菌褶、短茎、根脚、自然斑点 | 五官在菌盖下的短茎上，不是给动物戴蘑菇帽 |
| 玻璃幽灵 | 非对称漂浮体、透明渐变、反光边、悬浮五官 | 没有肩膀、脖子或衣服；材质仅用矢量渐变与描边，不使用滤镜 |
| 陶土精灵 | 缺口、釉面流边、金色接缝、不对称耳部、刻纹 | 是整体陶偶；眼睛大小和位置不复用动物模板 |
| 毛团野兽 | 无脖子身体、不对称耳朵、连续毛簇、露齿、短爪 | 大轮廓就是毛团，五官与身体连成一体 |

新增画稿存于 `common/src/avatar-assets.json` 的 `creatures`，生产 Rust 和概念页内嵌副本受一致性测试约束。每种有 3 种眼神、4 种嘴部表情；12 组配色与背景继续可用。总共 10 种角色，不把新增形象包装成 NFT 或价值承诺。

四种原生角色不套旧帽子、服装、配饰和眼镜。相关不绘制维度规范化为 0，眼神规范化为三种适配画稿；签名也使用有效特征，换一个不可见的衣服参数不会被计算成不同形象。概念页禁用不适用的选择和锁，显示「原生造型 · 不参与换装」，导出描述不写根本没画出的服饰。切回原来的六种角色，换装和八种眼神恢复。

本次版本为 `odd-folk/3.0.0`。新增物种改变采样，所以旧版种子会换脸；旧 1.0／2.0 配置不伪装兼容。具名作者按公开名字、匿名作者按 slug 的规则不变。

## 本机画稿检查

用本机编译的 Rust 共享库直接调用 `svg_for_seed` 输出 SVG，而不是拿 JS 概念页充当生产结果。检查用的四个公开种子：

| 角色 | 种子 | 完整 SVG 大小 |
| --- | --- | --- |
| 蘑菇居民 | `native-6-988` | 3143 字节 |
| 玻璃幽灵 | `native-7-3335` | 2808 字节 |
| 陶土精灵 | `native-8-9622` | 2971 字节 |
| 毛团野兽 | `native-9-19` | 2935 字节 |

四张均做 XML 解析、局部 ID 唯一性检查，并在本机浏览器查看大图与 24／32／48px 圆形缩略图。蘑菇的宽菌盖、幽灵的漂浮下缘、陶偶的不对称耳部和毛团的锯齿轮廓都保留下来；不声称在 24px 可以看清全部刻线、菌褶或面部细节。图稿与尺寸检查见[生产 SVG 检查图](img/2026-09-12-avatar-native-characters.png)。

概念页实际切换检查：蘑菇的换装被禁用；切到街头猿时恢复头饰、服装和八种眼神；再切到陶土精灵时只保留三种眼神，并确实渲染陶土精灵。没有只换名称、不换画稿的空选择。

首轮 `cargo build -p playtest-edge` 成功。以该生产二进制、隔离的临时对象存储和 4 个标注「本机隔离验收作品 · 非线上数据」的作品，在 `localhost:8846` 检查真实 Router：

- 广场出现四种原生头像，版本标记全部为 3.0；点「蘑菇森林」进入 `/p/native-6-988`，同一蘑菇出现在邀请人的名字旁。
- 幽灵邀请页在实测 390px 的窄视口下没有横向溢出；视口检查后已恢复。首个窄屏设置没有作用到目标标签，实测仍为桌面宽度，未算作窄屏通过；改在新标签检查后才得到 390px。
- 没有连接控制面、修改原有 `.data`、重启原有服务、部署线上或新增玩家页面。画稿检查 HTML 在临时目录，仅包裹 Rust 直接输出的 SVG。

首轮二进制使用工作区当时的共享样式：广场实测 20px、邀请页 26px，而不是 DESIGN 定义的 24／32px。随后已把 `ui/workspace.css` 和 `ui/invitation.css` 中这两条头像规则恢复到 24／32px，并在产品路由测试中加入 CSS 尺寸断言。**这两处最终样式还没有通过最新生产构建重新验收**，原因见后面的编译阻塞；不把首轮截图说成最终 24／32px 的产品截图。
