- 已有作品数量 / 上传大小限制与每小时熔断，不应低报为「什么配额都没有」；但本次没有找到账号月流量结算、重置、超限执行和 Pro 权益的完整闭环，不能据计划表宣称已经覆盖。
- 文件清单与公开资源 URL 不等于面向受限作品的完整 owner-authenticated 文件读回；访问控制施工应同时验证字节读取、旧版本、预览、封面、Range、缓存与 SDK 入口。
- 上传提交有串行锁，不能简单说存在版本号争抢；但本次检查的发布请求没有看到与 `baseVersionId` 等价的过期基线保护。串行处理并不阻止旧工作副本覆盖新内容。
