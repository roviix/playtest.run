# 2026-09-11 发布说明：一个命令舱

接着 `2026-09-11-publish-bare.md`。全拆掉那一稿用户说不行：命令要有一个组件承载，而且要够精致。中间用一页单文件 HTML 打了样，方向认了，再落进边缘。

## 形态

面（27rem）里只剩：一行标题（15px）、右上两枚裸图标（「?」、关闭）、一个命令舱。

命令舱是唯一的实体：`#08080a`，1px `#ffffff12` 边、顶部 1px 高光、往下一层深影。顶栏 6px 内边距放三个词，当前那个 `#ffffff10` 底、亮字、1px 描边加一点投影；其余暗字，悬停中灰。栏下一条 `#ffffff0e` 的线。舱体 16px 内边距一行命令。

命令按词上色（`plaza.rs` 里四个 span：`k` / `a` / `f` / `s`）：`$` 琥珀、`playtest` 亮字 600、参数 `--soft`、旗标 `--dim`、引号里那句 `#e8c98a`（琥珀往浅一档——那是要开发者自己填的字）。选中底色是琥珀 20%。`user-select:all`，点一下整条。

「?」点开：舱底下两行 12.5px 暗字，链接中灰下划线。
