# 2026-09-10 广场再收一层：字卡只排作品名

上一轮（`2026-09-10-plaza-wall.md`、`2026-09-10-plaza-content-poster.md`）骨架已经对：左栏、一面网格、卡上只有一件事实。看起来仍像模板，是因为字卡上还堆着 `PLAYTEST`、版本号、简介复述，底上有点阵，卡会浮起来。这一轮按 DESIGN §3.9（同日改过）把这些去掉。

## 看过的

Chrome 152 `--headless=new`，`scripts/headless-check.mjs`。稠密态对着一份手写的 `plaza.json`（6 张卡，其中 3 张带真封面图，控制面那一端没联调）；稀疏态对着本机正在跑的那一个作品。控制台无报错。

- 稠密桌面 `img/2026-09-10-plaza-quiet-desktop.png`（1440×900）：左栏 01 / 02 / 03；墙三列六张，图卡与字卡混排；字卡只排作品名，底下不再写一遍；桌面上动词不出现（悬停才浮）。
- 稠密宽屏 `img/2026-09-10-plaza-quiet-wide.png`（1920×1080）：四列。
- 稠密手机 `img/2026-09-10-plaza-quiet-phone.png`（420×860）：栏收成顶上一条，「N 人关注着这里」藏掉；触屏上动词按 CSS 会一直在（这张截图是无头 Chrome，`(hover:hover)` 仍按桌面算，动词没画出来）。
- 稀疏桌面 `img/2026-09-10-plaza-quiet-sparse.png`：介绍段在卡前面，卡从左边第一列排。本机真实数据，作品名是 `vite-vanilla`。

## 设计结论

- 作品名在卡上只出现一次。有封面时在图下面；没封面时它就是封面。
- 字卡上不盖水印、不写版本、不复述简介。色相由 slug 决定，饱和度压低——像书脊，不像霓虹。
- 底是平的。卡不浮、不投影，悬停只亮边、图轻微放大。
- 动词是悬停时才出现的那一下。整张卡本来就是链接。
- 墙好不好看仍八成取决于封面。夹具里三张图是手画的，不是开发者上传的。
