# 2026-09-14 广场单行工具栏（分段胶囊）、热度排序与搜索体验打磨真机验证

## 背景与痛点

在原设计中，广场（`https://playtest.run/`）主内容区顶部存在严重的视觉杂乱与概念混淆：
1. **维度混淆与双层 Tab 堆叠**：
   - 上一行是「作品 / 合集」下划线 Tab（内容主体维度）；
   - 下一行紧接着又是「最新 / 近 7 天」下划线 Tab（列表排序维度）；
   - 两排同样带有 `border-bottom: 2px solid var(--accent)` 绿边的下划线垂直贴在一起，视觉臃肿笨拙，层次严重失衡。
2. **文案表达**：「近 7 天」表意不够直观，用户希望换成更符合直觉的「热度」；
3. **搜索框体验欠缺**：缺少视觉线索（无前置搜索标识）、缺少快捷键呼出支持、聚焦状态粗糙、清空体验生硬。

## 改动与实现

1. **统一单行工具栏（Unified Discovery Toolbar）**：
   - 彻底删除粗笨的垂直堆叠下划线 Tab。
   - 引入黑曜石微浮雕**分段胶囊控制器（Segmented Control）** `[ 作品 | 合集 ]`（`nav.discovery-segmented`），位于工具栏左侧；
   - 将排序切换收纳在工具栏右侧：`排序  最新 / 热度 ⓘ`；
   - 切换到「合集」视图（`/collections`）时，自动隐去作品专属的排序选项，杜绝无效控件；
   - 工具栏在桌面端维持完美的单行水平对齐，手机端自适应折行。

2. **「最新」与「热度」样式打磨**：
   - 文案由「近 7 天」改为「热度」；
   - 彻底摆脱下划线，改用现代化精简单选胶囊；
   - 激活项微高亮（冷萃绿微底高光 `#71e8bf` 500 字重与细腻内嵌圆角），未激活项呈现克制的低调灰度；
   - 统计口径说明图标改为微型克制问号，hover/点击按需弹出，不破坏单行平整感。

3. **搜索框体验全面升级**：
   - **前置标识**：输入框左侧常驻微光搜索放大镜图标，聚焦时与外边框同步冷萃绿高亮；
   - **快捷键**：未聚焦且输入为空时展示微型 `<kbd>/</kbd>` 提示，全局按下 `/` 键自动聚焦并选中搜索内容；
   - **清除体验**：有搜索内容时动态展示微型圆润 `×` 清除按钮；
   - **视觉质感**：黑曜微深色背景搭配半透明微光细边框，聚焦时呈现冷萃绿光环与柔和弥散阴影；
   - **响应式**：桌面端宽度扩展至更开阔的 300px，移动端全宽自适应。
