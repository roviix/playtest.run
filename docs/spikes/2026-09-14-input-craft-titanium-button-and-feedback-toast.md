# 2026-09-14 表单输入框工艺打磨、钛白主按键与无抖动轻提示落地记录

用户在体验合集设置与操作流时提出以下 5 个关键打磨点：
1. **输入框工艺与组件质感**：「输入框是不是没有细节设计样式和组件？ 有点粗糙？」
2. **输入框标题字体样式**：「输入框的标题字体的样式对么？」
3. **保存按钮与开关设计**：「保存设置要钛白么？开关按钮要更加精致 克制么？」
4. **顶栏操作按钮布局、顺序与色彩**：「设置、打开玩家页面，复制链接这几个的布局 顺序 和样式对么？ 尤其是打开页面的颜色样式适合么」
5. **复制题目提醒体验**：「复制题目， 要顶部出现这个复制提醒么， 或者是一个 tips 弹出来的？」

## 2. 交互与设计重构实现

1. **输入框黑曜石微浮雕质感（Input Craft & Inset Shadows）**：
   - 摒弃简陋的半透明单色背景，采用深黑曜石质感底色（`rgba(12, 14, 18, 0.75)`）配合细腻内凹阴影 `box-shadow: inset 0 1.5px 3px rgba(0, 0, 0, 0.5), 0 1px 0 rgba(255, 255, 255, 0.03)`，营造出精密铣削的内嵌景深。
   - 输入框圆角统一为 `8px`，聚焦态加入 `box-shadow: inset 0 1px 2px rgba(0, 0, 0, 0.4), 0 0 0 3px rgba(255, 255, 255, 0.08)` 微白光晕。
   - 自定义地址前缀条目（`.collection-slug-preview`）与输入框融为一体，并启用 `color-scheme: dark;` 确保系统原生日期/时间选择器呈现纯正暗色模式。

2. **标签字体层级清晰化（Field Label Typography）**：
   - 将 `.field-label` 字号微调至 `12px`，字重 `500`，字色从过亮的高对比色收敛为 `var(--dim)`，字间距 `-0.01em`。
   - 标签与输入框之间的层级主次分明，标签静谧引导、输入内容清晰聚焦，彻底消除杂乱竞争感。

3. **钛白主按钮与克制微开关（Titanium CTA & Apple-grade Micro Switch）**：
   - **保存设置 / 创建合集主按键**：升级为纯白钛光按键（`.button.titanium`），纯白底色 `#ffffff`、深黑文字 `#09090b`、600 字重，辅以微立体投影与悬停微光，赋予弹窗决定性操作以最高质感权重。
   - **公开状态开关**：从过于厚重的 44×24px 缩减为 36×20px 的微开关（`.collection-switch-pill`），关闭态为细腻暗灰（`#a1a1aa` 滑块），激活态为钛白底盘（`#ffffff`）搭配黑曜石滑块（`#09090b`），滑行动画平滑克制。

4. **顶栏操作逻辑重组与色彩平衡（Header Actions & Removal of Dominant Accent）**：
   - **色彩去噪**：将原先极度抢眼的荧光翡翠绿「打开玩家页面 ↗」去除，统一收敛为黑曜石玻璃风格操作按键（`.collection-action-btn`，统一 34px 高度、微边框、矢量图标）。
   - **逻辑次序**：按照「传播分享 → 玩家预览 → 管理配置」的自然认知路径排列：
     1. `[复制链接]`（带链接矢量图标，复制后短时呈现勾选态）
     2. `[打开玩家页面 ↗]`（带外部跳转矢量图标）
     3. `[设置]`（带齿轮矢量图标）

5. **无布局抖动交互（Zero-CLS Copy Feedback & Floating Bottom Toast）**：
   - 移除原先在页面顶栏插入的硬性横幅 `<p class="collection-notice">`，彻底解决点击复制导致整个页面瞬间下移 50px 的严重排版跳动（CLS）。
   - **按键局部状态反馈**：点击「复制题目」后，按钮立即在原位变为「已复制 ✓」并带绿色微高亮，2 秒后自动恢复。
   - **全局底部浮动轻提示（Toast）**：合集链接复制、题目复制、保存合集、作品加入等轻操作，统一在屏幕正底部弹出悬浮玻璃胶囊（`.collection-toast`），自带毛玻璃模糊与轻微上浮动效，2.8 秒后自动淡出消失。
