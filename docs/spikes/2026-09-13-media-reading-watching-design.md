# 2026-09-13 文章阅读与视频观看的交互设计检查

## 性质与范围

这是 DESIGN §3.16 的设计稿检查，不是正式页面、媒体发布链路或手机真机验收。本轮只更新产品定义并制作独立的可切换交互稿，没有修改 edge 的文章渲染器、播放器或真实反馈行为。文章、视频海报、作者与原声均为明确标识的设计示例；视频没有加载真实素材，反馈只在当前设计稿内预览，没有向 API 发送。

## 设计结论

- 分发卡只显示标题、作者、摘要与可选封面；进入作品页直接阅读全文或点击播放器播放，不增加摘要门禁与默认新标签页。
- 网页沿用窄邀请卡；文章用宽松的文字排版，视频用大画面。内容占主列，反馈退为 320–360px 的辅助栏。
- 专注模式收起反馈；窄屏先给内容，反馈由用户主动展开。无封面时不把大字卡插进文章首屏，不在视频前重复封面。
- 纸感阅读仅供设计对比，未加入正式产品设置；段落批注、时间码反馈、阅读进度统计均不在本次能力声明中。

## 本机检查

环境为 macOS 的本机 Chrome headless，对独立交互稿执行 DOM 交互与截图检查，不连接生产服务。使用渲染工具生成的同一页面内容检查，不依赖线上账户。

通过的检查：文章 / 视频切换；桌面内容与反馈栏分工；专注模式切换保持阅读滚动位置；纸感与默认配色切换；390px 反馈打开和关闭后回到原位置；反馈预览明确提示未发送；320px 无横向溢出；浏览器 JavaScript 异常为零。
